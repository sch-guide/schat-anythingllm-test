# 화면 변경 확인 방법

화면을 바꾼 뒤에는 다음 내용을 확인합니다.

1. PC 화면에서 SCHC·SCHAT 표시가 잘 보이는지 확인합니다.
2. 모바일처럼 좁은 화면에서도 로고와 메뉴가 겹치지 않는지 확인합니다.
3. 다크모드 버튼이 밝은 화면과 어두운 화면을 정상적으로 바꾸는지 확인합니다.
4. 관리자에게만 설정 버튼이 보이는지 확인합니다.
5. 답변, 출처와 관련 이미지 화면이 그대로 보이는지 확인합니다.

## 자동 검사 파일

`frontend/src/components/SchatShell.ui.node.test.mjs`

이 검사는 로고, 다크모드, 숨겨진 모델 정보와 관리자 설정 버튼이 의도한 상태인지 확인합니다.

마지막으로 frontend production build와 `git diff --check`를 실행합니다.
