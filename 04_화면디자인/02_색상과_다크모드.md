# 글꼴·색상과 다크모드 바꾸기

## 전체 화면 글꼴

SCHAT의 일반 글자는 다음 순서의 깔끔한 산세리프 글꼴을 사용합니다.

`Pretendard → Inter → 운영체제 기본 글꼴 → Segoe UI → sans-serif`

- 한글과 영문·숫자는 사용할 수 있는 첫 번째 글꼴로 자연스럽게 표시됩니다.
- 코드 블록과 고정폭 문자는 기존 전용 글꼴을 그대로 사용합니다.
- 외부 폰트 사이트를 연결하거나 새 폰트 파일을 추가하지 않았습니다.

실제 전역 설정은 `frontend/src/index.css`와 `frontend/tailwind.config.js`에 있습니다. 개별 화면마다 글꼴을 따로 지정하지 않습니다.

## 화면에서 보이는 부분

- 채팅 설정 메뉴의 `다크모드` 글자
- 켜짐·꺼짐 스위치 모양
- 스위치의 밝은색과 어두운색

## 실제 프로그램 파일

`frontend/src/components/WorkspaceChat/ChatContainer/ChatSettingsMenu/DarkMode/index.jsx`

SCHAT은 기존 테마 기능을 사용합니다. 버튼을 누르면 밝은 화면과 어두운 화면이 전환되고 선택은 브라우저에 저장됩니다.

전체 화면 색상은 여러 공용 스타일이 함께 사용되므로, 이 파일 외의 색상을 바꿀 때는 개발자의 확인이 필요합니다.
