# 검색 점수 읽는 법

SCHAT이 질문에 맞는 문서 조각을 고를 때 계산하는 점수의 뜻을 정리함. 비개발자도 검색 결과가 왜 그 순서로 나왔는지 이해할 수 있게 하는 설명 문서임.

> 이 문서는 설명만 담음. 실제 질문의 점수는 이 화면에 나오지 않음. 현재 점수는 서버 기록(로그)에만 남고 직원·관리자 채팅 화면에는 표시하지 않음.

## 한눈에 보기

| 값 | 쉬운 뜻 | 범위 | 높을수록 |
|---|---|---|---|
| 문서명 | 근거가 나온 PDF 이름 | - | - |
| 페이지 | 근거가 나온 PDF 쪽 | - | - |
| vectorScore | 질문과 문서 조각의 **뜻**이 얼마나 비슷한지 (코사인 유사도) | 0 ~ 1 | 뜻이 더 비슷함 |
| bm25Score | 질문의 **단어**가 문서 조각에 얼마나 들어 있는지 | 0 이상 (상한 없음) | 같은 단어가 더 많이, 더 드물게 나옴 |
| vectorRank | 뜻 검색에서 몇 등인지 | 1, 2, 3 … | 숫자가 **작을수록** 좋음 |
| bm25Rank | 단어 검색에서 몇 등인지 | 1, 2, 3 … | 숫자가 **작을수록** 좋음 |
| fusionScore | 두 등수를 75:25로 합친 최종 점수 | 0 ~ 1 | 최종 순서에서 더 앞에 옴 |

## 1. vectorScore (뜻 검색 점수)

- Gemini Embedding이 질문과 문서 조각을 숫자 목록(벡터)으로 바꿈.
- ChromaDB가 두 벡터의 방향이 얼마나 같은지 코사인 방식으로 계산함.
- SCHAT은 이 값을 `1 - 거리`로 바꿔 0~1 점수로 사용함.
- **0.25보다 낮은 조각은 처음부터 후보에서 뺌.**
- 단어가 달라도 뜻이 비슷하면 점수가 높음. 예: "피 넣기"와 "수혈".

## 2. bm25Score (단어 검색 점수)

- 질문의 단어가 문서 조각에 그대로 들어 있는지 셈.
- 여러 문서에 흔하게 나오는 단어보다 드문 단어(예: PTNB, HD catheter)가 맞을 때 점수가 더 큼.
- 관리자 화면의 동의어 사전과 띄어쓰기 차이 보완은 이 단어 검색에만 적용됨.
- 점수에 상한이 없어서 **다른 질문끼리 점수 크기를 비교하면 안 됨.** 같은 질문 안의 등수만 의미 있음.

## 3. vectorRank, bm25Rank (등수)

- 뜻 검색 결과와 단어 검색 결과를 각각 점수 순으로 줄 세운 등수임.
- 한쪽 검색에서만 찾은 조각은 다른 쪽 등수가 비어 있음(`null`). 이상한 값이 아님.

## 4. fusionScore (최종 합산 점수)

SCHAT 버전 3은 **점수를 직접 더하지 않고 등수를 합침.** 두 점수의 크기 단위가 달라서 등수를 쓰는 편이 공정함.

```
fusionScore = 0.75 ÷ vectorRank + 0.25 ÷ bm25Rank
```

- 뜻 검색(Vector) 75%, 단어 검색(BM25) 25% 비율임.
- 한쪽 등수가 없으면 그쪽 몫은 0으로 계산함.
- fusionScore가 같으면 뜻 검색 등수가 앞선 조각을 먼저 둠.

### 계산 예시 (가상 숫자)

| 조각 | vectorRank | bm25Rank | 계산 | fusionScore | 최종 순서 |
|---|:---:|:---:|---|:---:|:---:|
| 가 | 1 | 3 | 0.75 ÷ 1 + 0.25 ÷ 3 | 0.833 | 1 |
| 나 | 2 | 1 | 0.75 ÷ 2 + 0.25 ÷ 1 | 0.625 | 2 |
| 다 | 3 | 없음 | 0.75 ÷ 3 + 0 | 0.250 | 3 |
| 라 | 없음 | 1 | 0 + 0.25 ÷ 1 | 0.250 | 4 |

- "다"와 "라"는 점수가 같지만 "다"가 뜻 검색 등수를 가지고 있어 앞에 옴.
- vectorScore가 아주 높아도 등수만 반영되므로 fusionScore는 최대 0.75 + 0.25 = 1임.

## 5. 합산 뒤에 한 번 더 거르는 단계

fusionScore 순서가 곧 답변 근거는 아님. 합산 뒤에 아래 거르기를 거쳐 보통 상위 4개 정도만 답변 근거로 씀.

- 질문 단어가 충분히 들어 있지 않고 뜻 점수도 낮은 조각을 뺌.
- 질문 의도(예: 사진 요청인지 글 설명 요청인지)에 맞지 않는 조각을 뺌.
- 문서·쪽·목차·글 내용이 완전히 같은 조각이 겹치면 하나만 남김. 비슷하기만 한 조각은 합치지 않음.

그래서 fusionScore가 높아도 최종 근거에서 빠질 수 있음.

## 점수를 볼 때 주의할 점

- 점수는 "관련이 있을 가능성"이지 "내용이 맞다"는 보증이 아님. 최종 판단은 원본 PDF 쪽으로 확인함.
- bm25Score는 질문마다 크기가 달라서 숫자 자체보다 등수를 봄.
- 검색 방식(75:25 비율, 0.25 기준, 거르기 조건)을 바꾸려면 승인과 회귀검사를 먼저 거쳐야 함.

## 실제 점수를 확인하는 방법 (현재)

- 질문할 때마다 서버 기록에 `SCHAT hybrid retrieval summary`라는 줄로 선택된 근거의 vectorRank·vectorScore·bm25Rank·bm25Score·fusionScore가 남음.
- 이 기록은 서버 관리자만 볼 수 있고 문서명·페이지는 함께 적히지 않음.
- 관리자 화면에서 문서명·페이지와 함께 보는 기능은 아직 없음. 필요하면 버전 4 이후 개선사항으로 따로 검토함.
