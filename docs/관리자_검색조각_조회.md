# 관리자 검색 조각 조회

## 무엇을 보는 화면인가

문서를 검색에 쓰기 위해 나눈 작은 본문을 ‘검색 조각(청크)’이라고 함. 관리자 설정의 **검색 조각 조회**에서 읽기만 할 수 있음. 이 화면에 조각 수정·삭제 기능은 없음.

## 문서별 확인

1. 관리자 계정에서 검색 조각 조회를 엶.
2. 작업 공간과 문서를 선택함.
3. 검색어를 넣거나 조각 제목을 눌러 내용을 펼침.
4. ‘다음 목록’으로 이어서 확인함. 한 화면은 최대 50개임.

PDF가 페이지별로 등록된 자료라면 같은 PDF의 여러 페이지가 별도 선택 항목으로 나옴. 문서명과 페이지로 구분함. 이번 단계에서 원본 PDF를 묶는 새 저장 구조는 만들지 않음.

직접 조각 조회는 현재 Chroma 연결을 지원함. 검색 순위나 임베딩을 새로 계산하지 않으므로 Gemini 호출이 발생하지 않음. 많은 조각에서 검색하면 한 번에 최대 1,000개를 확인하고 다음 목록으로 이어감.

## 질문별 근거 확인

‘질문별 답변 근거’ 탭에서 질문을 누르면 그 답변에 저장된 출처 발췌를 확인함. 원본 조각까지 현재 조회할 수 있으면 별도로 표시함. 직원 이름·계정은 표시하지 않으며 질문의 전화번호·긴 숫자는 기존 가림 규칙을 적용함. 이 규칙이 모든 개인정보를 자동으로 알아내는 것은 아니므로 관리자에게만 허용함.

- **저장된 발췌**: 답변 당시 기록에 남은 일부 본문임. 전체 원문이 아닐 수 있음.
- **실제 검색 조각**: 현재 저장소에서 해당 식별자로 읽어 온 본문임.
- **이전 버전**: 이전 자료로 보관 표시된 문서임. 현재 검색 대상과 구분함.
- **원본 확인 불가**: 현재 등록 자료인지, 삭제됐는지 등을 확실히 연결하지 못함. 이름이 같다고 새 문서로 바꾸어 연결하지 않음.

문서·페이지·등록 시각과 명시된 버전을 표시함. 버전이나 페이지 정보가 없으면 확인 불가로 표시하며 번호를 임의로 만들지 않음. 아주 긴 조각은 앞부분만 보여주고 잘렸다는 안내를 표시함.

## 검증과 반영 상태

로컬 구현, 가짜 자료 자동 검사 38개, 화면 build 및 별도 코드 검토를 완료함. 운영 서버와 실행 중인 Docker 3001 반영은 아직 하지 않았음. 진행 결과와 남은 제한은 [6단계 작업일지](01_작업일지/2026-10-11_6단계_청크조회_진행.md)를 확인함.
