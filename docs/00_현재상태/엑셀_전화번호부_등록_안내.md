# 엑셀 전화번호부 등록 안내

문서 등록 화면에서 PDF와 엑셀 `.xlsx`·`.xls`를 선택하거나 끌어다 놓을 수 있습니다. 이 안내는 기능 비교용 테스트 저장소 기준입니다.

## 권장 입력 방법

첫 행에 열 이름을 적고, 한 사람을 한 행에 입력합니다. 아래는 가짜 예시입니다.

| 성명 | 부서 | 단축번호 | 내선번호 |
|---|---|---|---|
| 가나다 | 가상부서 | 0123 | 5678 |

- 단축번호와 내선번호는 다른 열에 넣습니다.
- 번호 열은 가능하면 엑셀의 `텍스트` 형식으로 저장합니다. 표시 형식으로 앞에 붙인 0도 읽을 때 보존하지만, 엑셀에서 이미 없어져 보이지 않는 0은 복원할 수 없습니다.
- 이름·번호가 있는 행의 셀은 합치지 않는 것이 좋습니다. 빈칸이나 합쳐진 칸을 다른 사람의 값으로 채우지 않습니다.
- 시트가 여러 개면 각 시트를 읽고 출처에 시트 이름을 남깁니다. 빈 시트는 건너뜁니다.
- 등록 후 문서를 선택해 기존 방식대로 검색 자료에 추가합니다. 파일 업로드만으로 검색 등록까지 완료됐다고 보지 않습니다.

## 현재 지원 범위

- 검색에 쓰는 각 행에 `성명: … | 단축번호: … | 내선번호: …`처럼 열 이름을 함께 붙입니다. 이는 번호 종류가 문서 조각에서 떨어지는 문제를 줄이기 위한 처리이며, AI 답변 전체의 정확성을 보장하는 것은 아닙니다.
- 엑셀의 같은 이름 자동 업데이트는 지원하지 않습니다. 이름이 겹치면 올리지 않고 안내합니다. 새 이름으로 올리는 경우에도 예전 자료가 함께 검색될 수 있으므로, 새 자료를 확인한 뒤 기존 문서를 검색 등록에서 빼 주세요.
- 매크로 전용 `.xlsm`은 등록 화면에서 허용하지 않습니다. `.xlsx`·`.xls`를 읽을 때 매크로나 수식을 실행하지 않고 저장된 표시값을 읽습니다. 수식 결과는 엑셀에서 계산·저장한 뒤 올려 주세요.
- 채팅 답변의 `원본 보기`에서 엑셀 근거 텍스트 중 답변에 사용한 인용 부분을 연두색으로 표시합니다. PC와 모바일에서 같은 방식으로 표시하며, 엑셀 파일 자체의 셀 서식을 바꾸지는 않습니다. 인용이 없거나 같은 문구가 반복되어 위치를 확정할 수 없으면 임의로 칠하지 않습니다.
- 원본 PDF의 쪽 보기와 PDF 체크리스트 추출은 PDF 전용입니다.

## 엑셀 원본 표 보기

원본 표 보기 기능을 추가한 뒤 새로 등록한 엑셀은 파일 자체도 별도로 보관합니다. 새 질문의 출처에서 `근거 원문 보기`를 펼치면 시트를 선택하고 원래 행·열과 병합 셀 배치로 값을 확인할 수 있습니다. 한 번에 100행씩 보며, 답변 근거 행이 있는 구간부터 엽니다.

- 같은 시트·행·열 순서·빈칸·셀 값이 인용 내용과 일치할 때만 연두색 표시를 합니다. 다른 시트로 바꿨다고 같은 행 번호를 임의로 칠하지 않습니다.
- 값과 배치는 원본 기준이지만 글꼴·색·그림은 엑셀 프로그램과 다를 수 있습니다. SCHAT 안에서는 읽기 전용 표로 확인하며 원본 파일 다운로드는 제공하지 않습니다. 수식이나 매크로를 실행하지 않습니다.
- 표는 앞 80열까지 표시합니다. 원본이 20MB를 넘으면 표 미리보기를 제공하지 않으므로 관리자에게 문의합니다.
- 원본은 로그인한 사용자가 해당 작업공간에 등록된 문서인 경우에만 접근할 수 있습니다. 외부 문서 보기 서비스로 보내지 않습니다.
- **기능 추가 전에 올린 엑셀은 원본이 남아 있지 않습니다.** `통합전화번호부_원본.xlsx`처럼 새 이름으로 다시 올리고 검색 자료에 등록한 뒤 새 질문으로 확인합니다. 기존 답변의 출처를 자동으로 새 파일에 연결하지 않습니다. 이전 파일이 함께 검색되지 않도록 새 파일을 확인한 뒤 이전 파일을 등록 목록에서 빼 주세요.

## 전화번호로 질문하기

`이름 전화번호`, `부서 전화번호`, `이름 내선번호`, `이름 연락처`처럼 질문할 수 있습니다. 전화번호부나 제목에 단축·내선·직통번호·연락처가 명시된 엑셀에서는, 일반적인 연락처 표현 대신 이름·부서가 정확히 있는지 확인해 자료를 선택합니다. 번호 종류는 문서에 적힌 열 이름을 기준으로 읽으며 다른 사람 이름의 일부를 같은 이름으로 취급하지 않습니다.

운영 서버 반영 여부와 검증 기록은 [작업일지](../01_작업일지/2026-10-13_엑셀_문서등록.md)를 확인합니다.

## 읽기 전용 원본 보기

- 문서 등록 화면에서 원본이 보관된 사용 중 엑셀은 PDF와 같은 `원본 보기` 버튼으로 엽니다.
- 직원 답변 출처의 `원본 보기`를 누르면 긴 설명이나 변환 텍스트 없이 원본 표를 보여줍니다. 답변 근거 첫 행부터 열고 확인된 근거 행은 연두색으로 유지합니다.
- 시트가 하나면 표를 바로 보여주며, 여러 시트일 때만 이름 선택 상자를 표시합니다. 이전·다음 버튼으로 행 범위를 바꿀 수 있습니다.
- 관리자·직원 모두 엑셀 다운로드 버튼을 제공하지 않습니다. 직접 다운로드 API 요청도 거부하며, 원본 파일 자체는 서버에 그대로 보존합니다. PDF 보기는 기존 방식입니다.
- 원본 보관 기능 추가 전에 등록한 엑셀은 원본이 없어 볼 수 없습니다. 이미 원본이 보관된 파일을 다시 올릴 필요는 없습니다.

## 원본 배치와 근거 셀 강조

XLSX는 원본의 병합·열 너비·행 높이·정렬·배경·테두리·글꼴을 반영해 보여줍니다. SCHAT이 만든 `행 / A / B / C / D` 좌표 헤더는 붙이지 않습니다. 설치된 글꼴과 화면 환산에 따라 Excel 프로그램과 조금 다를 수 있으며 그림·차트·조건부 서식은 지원하지 않습니다. XLS는 기존 셀·병합 보기 수준입니다.

직원 답변 출처에서는 직접 인용·원본 값·현재 답변에 사용된 글자만 연두색 형광펜으로 표시합니다. 셀 전체 배경은 바꾸지 않습니다. 원래 셀 색을 지우지 않으며, 인용이 모호하면 임의로 강조하지 않습니다. 문서 등록에서 단순 원본 열기는 강조하지 않습니다. 다운로드는 계속 차단합니다.

## 보기 크기와 형광펜

엑셀은 화면 폭에 맞춰 65~80%로 축소합니다. 작은 화면에서 글자가 지나치게 작아지지 않도록 하한을 두므로, 넓은 표는 뷰어 안에서 가로·세로로 스크롤해 봅니다.

직원 답변에서는 실제 답변 항목에 쓰인 문자열 뒤에만 연한 연두색을 표시합니다. 한 셀의 일부 문구만 쓰였다면 그 부분만 칠합니다. 원래 셀 배경·테두리·글자색은 유지하며 문서 등록에서 원본만 열 때는 칠하지 않습니다.

## 가운데 정렬과 유사명칭

축소한 원본 표는 화면 가운데에 놓습니다. 오른쪽에 불필요하게 이어진 빈 서식 영역은 원본 보기 범위에서만 제외하고, 긴 문구는 줄바꿈해 모두 읽을 수 있게 합니다. 원본 파일은 수정하지 않습니다. 큰 글꼴의 진료지원간호팀 표는 더 축소해 열을 맞추며, 작은 화면에서는 가로 스크롤로 끝 열까지 볼 수 있습니다.

전화번호 질문에서는 `비뇨의학과`, `비뇨기과`, `비뇨의학센터`, `비뇨기`가 같은 계열 이름으로 검색됩니다. `비뇨기과번호`처럼 붙여 써도 됩니다. 이 연결은 전화번호부에만 적용하며 모든 진료 명칭을 자동으로 비슷하게 찾는 기능은 아닙니다.


## 원본이 첫 행으로 열렸던 경우

진료지원 문서의 여러 줄 업무형태 인용을 처리하는 화면 문제를 2026-10-14 보완했다. 기존 문서를 다시 등록할 필요 없이 화면을 새로고침하고 답변 출처를 다시 펼친다. 직접 근거가 확인되면 해당 행 근처로 이동하고 답변에 사용된 글자만 강조한다.
