# 체크리스트 인쇄 사용 안내

로컬 기능 비교 환경에서 체크리스트를 연 뒤 상단의 **인쇄**를 누른다. 채팅 안 작업창과 별도 창에서 같은 기능을 사용한다. 프린터 선택과 실제 출력은 브라우저 인쇄 창에서 진행한다.

- 세부 항목이 있는 큰 항목은 제목이며 체크되지 않는다.
- 세부 항목과 단독 항목의 체크 상태는 기존처럼 저장된다.
- 화면에서 접은 구역도 인쇄에는 모두 포함된다.
- 체크 항목은 ☑와 취소선, 미체크 항목은 ☐로 표시된다.
- 환자정보·기타메모는 기존 이름 가리기를 적용한 내용으로 인쇄된다.
- 인쇄를 해도 체크 상태나 체크리스트 내용을 변경하지 않는다.

A4 세로 인쇄를 기준으로 구성했다. 브라우저가 기본으로 넣는 날짜·주소 머리글과 바닥글은 브라우저 인쇄 설정에서 끌 수 있다. 2026-10-14 현재 자동 검사와 로컬 반영은 완료했으나, Edge·Chrome 실제 미리보기와 여러 장 인쇄, 모바일 실화면은 브라우저 연결 제한으로 미확인이다.
