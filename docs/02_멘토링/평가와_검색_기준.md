# SCHAT 평가와 검색 기준

이 문서는 멘토링 산출물에 나뉘어 있던 검색 구조, 성능 평가, 답변 안전 기준과 버전 4 계획을 한곳에 모은 정본임.

## 평가 우선순위

1. 간호사가 정한 정답 문서와 페이지를 우선함.
2. Hit@10과 MRR로 검색 결과를 평가함.
3. 간호사가 실제 답변과 출처를 검수함.
4. RAGAS는 보조 자동평가로만 사용함.

RAGAS가 사람 검수를 대신하지 않음. 이번 기준 수립 과정에서 RAGAS 실제 Gemini 호출은 실행하지 않음.

## 현재 검색 구조

- Gemini Embedding으로 질문과 문서의 의미를 비교함.
- ChromaDB에 문서 조각과 embedding을 저장함.
- BM25로 약물명·검사명·약어 같은 정확한 단어를 찾음.
- Hybrid 검색은 Vector 75%와 BM25 25%를 결합함.
- 검색 후보 수와 점수 계산은 버전 3 기준을 유지함.

## Chroma 저장 기준

| 저장 항목 | 용도 |
|---|---|
| `id` | 문서 조각을 구분함. |
| 문서 내용 | Gemini 답변 근거와 근거 원문에 사용함. |
| `document_id` | 원본 문서와 PDF를 연결함. |
| `page` | Citation 페이지를 표시함. |
| `section` | 질문과 관련된 목차·절차 범위를 고름. |
| `content_type` | 본문과 image description을 구분함. |
| `image_key` | 관련 이미지를 연결함. |
| `document_version` | 향후 최신 문서 필터에 사용할 수 있으나 현재 값은 비어 있을 수 있음. |

- 거리 계산은 코사인 방식을 사용함.
- 본문은 약 900자 단위로 자르고 약 120자를 겹침.
- 표 구조 검색의 추가 개선은 버전 4 이후 항목임.

## 버전 3 검색 평가

현재 문서명·페이지 기준 21문항 결과임.

| 방식 | Hit@10 | MRR |
|---|---:|---:|
| Vector | 100% (21/21) | 0.743 |
| BM25 | 71.4% (15/21) | 0.560 |
| Hybrid | 100% (21/21) | 0.738 |

- 버전 3 합격 기준은 Hybrid Hit@10 95% 이상, MRR 0.70 이상임.
- 범위 밖 질문 20건에서 문서 밖 추측 답변 0건을 확인함.
- 검색 후 근거 선택 최소 수정 뒤 A8 Top-10이 이전과 같음을 확인함.
- 당시 본문 vector 654개를 기준선으로 확인함.
- 21문항 전체 Automatic 재실행은 버전 3 필수 조건에서 제외하고 버전 4 품질검증으로 이관함.

## 답변과 Citation 안전 기준

- 등록된 병원 문서와 검색된 근거 안에서만 답변함.
- 근거가 없으면 “등록된 문서에서 확인되지 않습니다.”라고 답함.
- 병원 질문인데 최종 source가 0개이면 구체적인 숫자·시간·절차 답변을 만들지 않음.
- 숫자, 시간, 용량, 단위와 기준값을 문서와 다르게 바꾸지 않음.
- 본문 근거를 우선하고 image description은 질문과 직접 관련될 때만 보조로 사용함.
- 같은 PDF와 같은 페이지의 Citation은 중복 표시하지 않음.

## 21문항 실패 분석과 개선

A8 검색기는 정답 페이지를 찾았지만 Automatic의 검색 이후 근거 선택 단계에서 정답이 빠지는 사례가 있었음.

- `진정할 때 주의할 점은?`: 활용형과 요청 표현 때문에 진정 근거가 탈락함.
- `진정은 어떻게 진행하는 거야?`: 관련 본문 대신 낙상 image description만 남음.
- `그중 진정 후에는 어떻게 관찰해?`: 후속질문의 직전 주제를 검색에 보완하지 못함.
- `수혈간호를 전체적으로 핵심 요약해줘`: 전체적으로·핵심·요약을 필수 내용어로 잘못 취급함.
- `피 넣기 전에 뭐부터 체크해야 돼?`: 구어체 수혈 질문을 병원 질문으로 감지하지 못함.

검색기·Hybrid 비율·Embedding·Top-K는 그대로 두고 요청 표현 분리, 제한적 활용형 정리, 후속 문맥 보완, 구어체 alias, 본문 우선과 source 0 안전장치만 수정함. 관련 회귀검사 55건을 통과했고 A8 Top-10은 유지함.

## 프롬프트 관리 기준

우선순위는 다음과 같음.

1. workspace prompt가 있으면 우선함.
2. 관리자 화면의 `SCHAT 기본 답변 규칙`을 운영값으로 사용함.
3. YAML은 기준본·기본값·백업본으로 사용함.
4. 코드 기본값은 마지막 fallback으로 사용함.

YAML 변경이 관리자 DB 값을 자동으로 덮어쓰지 않으며, 관리자 저장도 YAML을 자동 변경하지 않음.

## 버전 4 이후 개선사항

- 21문항 전체 Automatic 답변과 Citation을 독립 thread로 다시 검수함.
- Citation 직접 관련성을 추가로 정밀하게 개선함.
- 문서 family, version, current 상태를 DB에 관리함.
- 구버전을 삭제하지 않고 최신 문서만 Vector와 BM25 검색에 포함함.
- RAGAS 실제 평가를 소규모로 검토함.
- 표 구조 검색과 추가 UX를 개선함.

문서 버전 DB migration 전에는 DB 백업과 rollback 방법을 먼저 확인해야 함. 구버전과 운영 PDF를 자동 삭제하면 안 됨.
