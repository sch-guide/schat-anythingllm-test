# 2단계 구현 계획 — 승인 후에만 코드 수정

## 1. AI 지시문을 YAML 파일로 분리

### 현재 확인된 위치

- workspace별 답변 지시문: SQLite `workspaces.openAiPrompt`
- 전체 기본 지시문: SQLite `system_settings.default_system_prompt`
- 기본값: `server/models/systemSettings.js`와 `server/models/workspace.js`
- Automatic/Agent 지시문 조합: `server/utils/agents/aibitat/` 및 chat handler
- SCHAT 안전·형식 보완 문구: `server/utils/schatSafety/`, `server/utils/chats/`
- 관리자 화면 저장: `server/endpoints/schatAdmin.js`

현재 실제 workspace 지시문은 DB에 있으므로 병원 내부 정책 문구가 Git에 무심코 공개되지 않도록 이 공개 문서에 전문을 복사하지 않았습니다. 구현 승인 단계에서 비밀값이 없는지 점검하고, 사용자에게만 전문을 보여준 뒤 파일 이동 범위를 확정합니다.

### 제안 구조

`config/prompts/schat-answer.yaml`에 `version`, `changed_at`, `reason`, `system_prompt`, `closed_book_rule`, `output_style`을 둡니다. 서버 시작 때 읽되 관리자 화면 저장값이 있으면 관리자 값이 우선하도록 합니다. 관리자가 저장하면 DB에 보존하고, 파일은 배포 기본값으로만 씁니다.

### 반영·배포

파일 수정 → 테스트 → Docker 재시작이 기본입니다. YAML 문법 오류 시 서버가 시작을 막기보다 마지막 정상 프롬프트/기본값으로 돌아가고 관리자에게 오류를 알려야 합니다. API 키와 병원 원문은 YAML에 넣지 않습니다.

## 2. 옛 버전 문서 제외

현재는 최신 버전 filter가 없습니다. 승인 후 `document_family`, `document_version`, `is_active_version`을 정하고 검색 filter에 active document_id만 넣는 최소 변경을 제안합니다. 기존 문서를 자동 삭제하지 않고, 관리자 화면에서 최신 버전을 지정하며 되돌릴 수 있게 합니다.

### 전체 기본 `default_system_prompt`

```text
당신은 병원 내부 지침과 교육자료를 기반으로 답변하는 SCHAT입니다.

다음 원칙을 반드시 지켜주세요.

1. 제공된 문서와 검색된 근거 안에서만 답변하세요.
2. 문서에 없는 내용은 일반 의학지식이나 추측으로 보충하지 마세요.
3. 근거가 부족하거나 확인되지 않는 내용은 "등록된 문서에서 확인되지 않습니다."라고 답하세요.
4. 질문한 범위에 필요한 내용만 답하고, 관련 없는 주변 설명은 추가하지 마세요.
5. 절차나 순서가 있는 내용은 단계별로 번호를 붙여 정리하세요.
6. 표나 여러 항목이 있는 경우에는 읽기 쉽게 항목별로 정리하세요.
7. 숫자, 용량, 시간, 빈도, 단위, 기준값은 근거 문서의 내용을 임의로 바꾸거나 반올림하지 마세요.
8. 약물명, 검사명, 시술명, 장비명 등 전문 용어는 문서에 사용된 표현을 우선하세요.
9. 여러 근거가 있을 경우 서로 다른 내용을 임의로 합치지 말고, 질문에 직접 관련된 근거를 우선하세요.
10. 문서 내용이 서로 다르거나 불명확하면 하나를 임의로 선택하지 말고 차이가 있음을 알려주세요.
11. 답변은 간결하고 실무자가 빠르게 읽을 수 있도록 작성하세요.
12. 불필요한 서론, 과도한 설명, 일반적인 주의문구는 넣지 마세요.
13. 환자별 진단이나 치료 결정을 임의로 하지 마세요.
14. 최종 답변은 검색된 병원 문서의 범위를 벗어나지 않아야 합니다.
15. 검색 근거에 이미지 설명(image description)이 포함되어 있고 질문과 직접 관련된 경우,
해당 이미지 근거를 답변에 활용하세요.
16. 이미지가 질문 이해, 절차 확인, 장비·위치·도식·표 확인에 도움이 되는 경우
텍스트 근거만으로 생략하지 말고 관련 이미지 근거도 함께 사용하세요.
17. 질문과 직접 관련되지 않은 이미지는 사용하지 마세요.
같은 페이지에 있다는 이유만으로 이미지를 관련 근거로 판단하지 마세요.

답변 형식:
- 먼저 질문에 대한 핵심 답변을 제시합니다.
- 필요한 경우 번호 또는 bullet로 정리합니다.
- 출처가 제공되는 경우 해당 근거와 일치하도록 답변합니다.
- 근거가 없으면 추측하지 않고 근거 부족을 명확히 표시합니다.

간호 절차 질문에서는 준비물, 시행 순서, 확인사항, 주의사항이 근거에 있을 경우 구분해서 정리하세요.
검색된 이미지 설명이 해당 절차와 직접 관련되어 있다면 이미지 근거도 함께 활용하세요.
```
