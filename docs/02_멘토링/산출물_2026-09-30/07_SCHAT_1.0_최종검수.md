## SCHAT 버전 3 주요 기준

- Hybrid 검색을 사용함.
- Hit@10 100%를 달성함.
- Hybrid MRR 0.738을 확인함.
- 범위 밖 질문에서 추측 답변 0건을 확인함.
- 검색 회귀검증을 통과함.
- 등록 문서 근거 안에서 답변함.
- Citation과 원본 PDF 근거를 제공함.
- 직원과 관리자 권한을 분리함.
- 시범운영 가능한 웹서버 환경을 구성함.

## 간호사 검수표

- 현재 Automatic 경로에서 21문항을 각각 정확히 1회 실행해 답변과 Citation을 `로컬전용_원자료/SCHAT_간호사_최종검수.xlsx`에 채웠습니다.
- 사람이 입력할 `핵심내용 일치`, `숫자/시간/용량 정확`, `출처 정확`, `불필요 내용 없음`, `최종 판정`, `수정 의견`은 비워 두었습니다.
- 응답 Citation에 기대 페이지가 하나 이상 포함된 문항은 13/21이었고, Citation이 없는 답변은 5건이었습니다. 이는 간호사 판정을 대신하지 않는 사전 확인값입니다.
- 질문별 전체 답변과 Citation 원자료는 Git 제외 파일 `로컬전용_원자료/SCHAT_21문항_현재답변_실행결과.json`에도 보관했습니다.

## 실제 실행 횟수

| 구분 | 질문 수 | Agent 추가 검색 | Gemini 답변 요청 | Gemini Embedding 요청 |
|---|---:|---:|---:|---:|
| 범위 밖 질문 | 20 | 5 | 25 | 25 |
| 기존 정답 질문 | 21 | 7 | 28 | 28 |
| 합계 | 41 | 12 | 53 | 53 |

한 질문의 Agent가 추가 `rag-memory`를 호출하면 답변 모델과 검색 임베딩이 각각 한 번 더 호출됩니다. 따라서 관찰된 Google Gemini API 요청은 답변 53회와 임베딩 53회, 합계 106회입니다. 질문 재시도는 0회입니다.
