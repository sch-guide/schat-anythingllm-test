# 체크리스트 개인 상태 서버 저장 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 사용자 승인에 따라 현재 작업공간에서 진행하며 다른 미완성 변경을 보존함.

**Goal:** 체크·가린 환자정보·자유 메모를 계정별로 저장하고 마지막 수정 후 24시간 만료시킴.

**Architecture:** 브라우저에서 전송 전 이름을 가림. 전용 인증 API와 개인 상태 DB 테이블을 사용하고 서버 버전 비교로 동시 수정 충돌을 거절함. 만료 조회 차단과 주기 삭제를 병행함.

**Tech Stack:** React, Express, SQLite/Prisma, Node 테스트.

**Spec:** 2026-10-11 사용자 승인: 이전 기능 없음, 기존 브라우저 사본 정리, 화면 유지, 자유 메모 원문 저장 및 스냅샷 약 17일 잔존 허용, Secret Manager 사용 안 함.

## 공통 조건

- 실제 환자자료·Gemini·운영 서버 사용 금지. 합성 자료로만 검사함.
- 본인 계정만 조회·수정하며 관리자 우회 없음.
- 메모는 로그·통계·채팅·캐시·오류 보고에 포함하지 않음.
- 내용 변경만 24시간 기한을 갱신함. 조회와 로그인은 기한을 연장하지 않음.
- 로그아웃 후 서버 자료 유지, 브라우저 및 열린 화면 사본 정리.
- 다른 기능과 storage 데이터는 커밋 제외. 기능 전체 검증 후 한 번 별도 커밋, push 없음.
