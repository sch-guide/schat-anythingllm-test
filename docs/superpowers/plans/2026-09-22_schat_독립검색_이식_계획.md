# SCHAT 독립 검색 이식 구현 계획

> **For agentic workers:** 구현은 현재 세션에서 순서대로 실행하며 모든 기능 변경은 테스트 우선으로 진행한다.

**Goal:** Gemini 임베딩·ChromaDB 주 검색과 BM25 용어 보완을 이 테스트 저장소에 독립적으로 구현하고 Docker 웹 화면에서 실행 가능하게 한다.

**Architecture:** 기존 Chroma provider를 SCHAT 검색 진입점으로 유지하고, 동일 Chroma collection의 문서를 대상으로 BM25 순위를 계산한 뒤 가중 순위 결합을 수행한다. 설정 선택기는 Gemini와 Chroma만 허용하며 Docker Compose가 웹 서버와 ChromaDB를 함께 기동한다.

**Tech Stack:** Node.js, Jest, React, ChromaDB, Docker Compose, Gemini Embedding API

**Spec:** `docs/superpowers/specs/2026-09-22_schat_독립검색_이식_설계.md`
