# 질문 범위 기반 안전검사 설계

## 목표

검색된 모든 문장을 반복하게 하지 않고, 사용자 질문에 필요한 필수 임상 사실만 보존하면 자연스러운 답변을 허용한다. 숫자·단위·시간·조건·금기·행위 종류와 강도 등 임상 의미 변경은 기존 검사기를 재사용해 계속 차단한다.

## 구조

1. 질문 의도와 선택된 근거로 요청별 필수 사실 묶음(coverage slot)을 만든다.
2. 기존 SCHAT 검사기는 전체 근거 반복 요구만 끄고, 구조·인용 ID·숫자·조건·부정·분기 검사를 그대로 실행한다.
3. 새 정책 계층이 필수 사실 묶음의 누락을 검사한다.
4. 행위 종류·강도, 금기, 질문에 필요한 숫자·시간은 기존과 동일하게 차단한다.
5. 질문과 관계없는 선택 근거의 생략은 경고 또는 정상으로 처리한다.
6. 평면화된 표는 행 관계가 결정적으로 확인되는 경우에만 목록으로 구성하고, 불확실하면 추측하지 않는다.

## 안전 경계

- 원본 `src/controlled_generation.py`, `src/evidence.py`, `tools/evaluation_action_strength.py`는 수정하지 않는다.
- 존재하지 않는 SourceUnit 인용, 숫자·단위 추가/변경, 조건·부정·금기 변경, 행위 종류·강도 변경은 차단한다.
- 성인·소아 또는 서로 다른 제제 정보의 혼합을 허용하지 않는다.
- 실패 시 질문 관련 원문만 사용한 대체 답변을 표시하며 재시도하지 않는다.
- 일반적인 의미 동일성을 완전히 판정하는 별도 외부 모델은 추가하지 않는다.

## 표 처리

- 명시된 표 제목과 행 경계가 확인될 때만 구조화한다.
- 깨진 PDF 문자열에서 불확실한 열 관계를 복원하지 않는다.
- 본문의 페이지 표식·내부 태그·SVG·내부 ID는 표시하지 않는다.

## 검증

- 허용: 시행→수행, 동일한 15분 표현, 어순 변경, 주변 정보 생략, 질문 범위 요약.
- 차단: 시행→확인, 즉시 중단→고려, 반드시 시행→권고, 금지→주의, 숫자·시간·속도 변경, 필수 사실 누락, 존재하지 않는 SourceUnit.
- 저장된 UAT-T01/T02/T11/T12 결과를 가능한 범위에서 읽기 전용 회귀검증한다.
- 자동검사 후 Docker에 반영하고 지정된 네 질문만 각 한 번 실행한다.
