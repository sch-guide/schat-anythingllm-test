## 재개 작업 계획과 판단 기록

- 승인된 현재 폴더에서 작업을 이어감. 다른 창의 미커밋 체크리스트·답변 대기 표시 변경을 보존함.
- 화면 작업: 전체 묶음 사전 확인 → 중복 목록 팝업 → 취소 시 전송하지 않음 → 승인 시 교체 전용 API만 호출하도록 연결함. 진행 중임.
- 서버 작업: PDF 등 기존 변환기를 유지하면서 새 자료를 별도 임시 경로에서 준비하고, 교체 검증·실패 복구·이전 원본 보관을 연결함. 진행 중임.
- 보관 문서 작업: 이전 문서는 검색·고정 문서·일반 목록에서 제외하되 과거 PDF 접근과 저장공간 보호에 필요한 연결은 남기도록 점검함. 진행 중임.
- 통합 검증과 문서 업데이트 기능 커밋은 아직 하지 않음. 형광 표시는 그다음 순서로 유지함.
- 판단: 기존 변환기를 우회하는 TXT 전용 기능으로 범위를 줄이지 않음. 실제 사용 대상인 PDF 준비 경로를 분리하는 방식으로 진행함. 잘못 연결하면 원본·이미지 보존에 영향을 줄 수 있으므로 테스트 자료로만 검증함.
- 판단: 다른 작업 공간과 공유된 자료를 안전하게 교체할 수 없는 경우 자동으로 다른 공간까지 수정하지 않고 명확히 차단하도록 함. 이 경우 관리자가 공유 관계를 먼저 확인해야 함.
- 기존 검사 실행에서 39개를 통과하고 원본 PDF 검사 파일 1개는 로컬 `uuid` 참조 누락으로 실행되지 않음. 설치를 변경하지 않고 기존 frontend/node_modules를 테스트 프로세스에만 참조시켜 원본 PDF 검사 2개도 통과함.
- 로컬 Docker 읽기 전용 확인에서 web·ChromaDB·안전 검사 서비스가 모두 healthy임을 확인함. 이번 재개 작업에서 재빌드는 아직 하지 않음.

## 재개 작업 결과 — 안전 문제로 활성화 보류함

이 절을 최신 이어받기 기준으로 사용함. 위의 18개 검사·팝업 미연결 기록은 이전 단계의 기록으로 유지함.

- 전체 업로드 묶음 중복 확인, 겹치는 목록 팝업, 취소 시 전송하지 않는 흐름을 연결함. 승인 시 교체 전용 API만 호출하며 실패를 일반 업로드로 우회하지 않음.
- PDF를 별도 경로에서 준비하고 새 검색 자료 설치·구본 검색 제외·검사·실패 복구를 수행하는 서버 연결을 작성함. 구본 원본과 연결 행을 보존하고 체크리스트·퀴즈·과거 출처 연결을 결과로 알리도록 작성함.
- 보관 문서 재등록·수정·삭제 차단과 경로 우회 방지를 보강함. 공유 문서·감시 문서·연결 기록이 없는 구본 등 안전하게 처리하지 못하는 경우 교체를 거절함. 현재 PDF·Chroma 대상이며 모든 형식을 지원하는 것은 아님.
- 최종 관련 자동 검사 87개를 통과함. 임시 파일과 임시 SQLite DB를 사용하며 Collector·Chroma 통신은 가상 장치로 대신함. 실제 병원 자료·운영 DB·Chroma는 변경하지 않음.
- 실제 인증·권한 미들웨어와 API 연결을 실행하는 검사에서 권한 거절 및 준비 미완료 503 응답을 확인함. 실제 HTTP 서버·브라우저 검증을 대체하지는 않음.
- 화면 production build와 후처리를 통과함. 이후 화면 수명 관리·새로고침 오류 전달을 최소 수정하고 관련 검사·문법 검사를 수행함. 최종 화면의 실제 브라우저 검증은 사용 가능한 브라우저가 없어 수행하지 못함.
- 기존 공통 업로드와 Collector 전체를 전역 잠금으로 감싸는 수정은 자동 승인 검토에서 서비스 장애 위험으로 거절됨. 거절된 변경은 적용하거나 우회하지 않음.
- 남은 위험: 기존 업로드가 교체 중 같은 이름 자료를 추가할 수 있음. 작업공간 초기화·삭제가 교체 중 DB 행을 먼저 지우면 복구와 충돌할 수 있음. 단순 최종 재조회만으로 해결되지 않음.
- `server/utils/documentUpdates/readiness.js`에서 새 교체 기능을 비활성화함. 인증·권한 확인 후 파일을 받기 전에 503과 안내를 반환함. 환경변수로 우회하는 통로는 만들지 않음. 기존 일반 업로드 전체를 차단한 것은 아님.
- 기능 완료 조건이 충족되지 않아 별도 commit·push·Docker rebuild를 하지 않음. 형광 표시 단계도 시작하지 않음. 다른 창의 체크리스트·출처·대기 표시 변경은 그대로 보존함.

### 다음 작업

1. 사용자에게 동시 작업 위험과 자동 승인 거절 사실을 알리고, 같은 문서의 등록과 대상 작업공간 삭제 충돌을 막는 좁은 보호 범위를 확인함. 기존 모든 업로드를 전역 차단하는 방식을 재시도하지 않음.
2. 합성 문서로 동시 업로드·초기화·삭제·실패 복구를 검증함. 이후 격리된 실제 Chroma·Collector와 브라우저에서 확인한 뒤에만 준비 차단 해제를 검토함.
3. 문서 업데이트 기능이 안전 검증을 통과하면 해당 파일만 별도 커밋함. 사전 커밋 도구가 다른 창의 작업 문서까지 자동 포함하지 않는지도 확인함.
4. 이후 형광 표시를 구현·검증·별도 커밋함. 현재 다른 창에서도 Citation 파일을 수정 중이므로 먼저 diff를 다시 확인함.
