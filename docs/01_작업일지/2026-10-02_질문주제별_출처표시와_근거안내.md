# 질문 주제별 출처 표시와 근거 안내

## 범위와 변경

- 직원 출처 표시만 변경함. 서버 검색, BM25, Vector, Hybrid 75:25, 임베딩, Top-K와 Gemini 입력 근거는 변경하지 않음.
- 기존 전체 출처 복구 동작이 실패 테스트에서 재현됨을 확인한 뒤 수정함.
- CT·MRI·RI 주제를 구분하며 붙여 쓴 PDF 제목도 인식함. CT·MRI 복합 질문은 두 주제의 출처를 합쳐 보존함. 일반 질문의 기존 별칭·문구 일치 방식은 유지함.
- 다른 시술의 준비 항목에서 CT가 언급되는 것과 CT 문서 자체를 구분함. 금식 질문은 해당 근거에 금식/NPO 내용이 있는지도 확인함.
- 답변이 문서 확인 불가 문구로 시작하면 “문서 근거를 확인하지 못했습니다.”만 표시함. 참고 자료도 숨김.
- 내용이 있지만 직접 근거를 특정하지 못하면 “답변의 직접 근거를 특정하지 못했습니다. 원문 확인이 필요합니다.”를 표시함. 검색된 참고 자료 보기 버튼은 기본적으로 접힌 상태이며, 펼치면 “답변의 직접 근거로 확인되지 않은 자료입니다.”를 표시함.
- 두 주제 중 한쪽의 근거만 남으면 확인하지 못한 주제를 안내함. 저장된 source, page, PDF 연결과 답변 문장은 그대로 유지함.

## 전후 비교

새 Gemini 답변 생성이 아니라 기존 로컬 저장 답변·근거를 동일하게 넣어 화면 표시 함수를 재실행함. CT·MRI와 RI는 사용자가 지정한 질문 문구로 비교함. 출처 개수는 같은 문서·쪽의 중복을 합친 수임. 병원 원문·답변 전문은 이 문서에 복사하지 않음.

| 질문 | 수정 전 | 수정 후 직접 출처 | 보존 확인 |
|---|---:|---:|---|
| 조영제 CT 전 금식 몇 시간? MRI는? | 9 | 5 | 검사 및 시술 p.2·3·4·50·70 유지함. CT와 MRI 양쪽 및 답변의 MRCP 관련 근거를 보존함. RGC·Renal biopsy·수술 p.6·급식 화면을 제외함. |
| 혈당 280일 때 RI 몇 단위? | 12 | 0 | 기존 답변이 문서 확인 불가로 시작하여 안내만 표시함. 용량을 새로 판단하지 않음. |
| Renal biopsy | 2 | 2 | 검사 및 시술 p.56과 실무지침서 p.87 유지함. |
| 진정할 때 주의할 점은? | 3 | 3 | 실무지침서 p.166·162·163 유지함. |
| 수혈하는 동안 주의 깊게 볼 항목은? | 2 | 2 | 실무지침서 p.117·130 유지함. |

기존 질문은 수정 전에 표시되던 근거의 보존을 확인한 것이며, 간호사가 답변 전체의 정확성을 최종 판정한 결과는 아님. 수혈 질문의 기존 검색 근거에 없는 페이지를 새로 추가하지 않음.

## 검증과 제한

- 출처 필터 12개, 실제 React 출처 화면 렌더링 17개, 기존 검색 관련 회귀 56개가 통과함.
- CT·MRI 양쪽 보존, 한쪽 근거 부족 안내, RI 근거 부족 숨김, 직접 근거 미확인 시 접기, 원본 데이터 불변, 기존 PDF 출처 표시를 검사함.
- 작업 전후 server/collector/docker 변경 내역 및 주요 검색·Gemini 문맥 구성 파일 해시가 동일함. 입력한 저장 질문·답변·source 객체도 변경되지 않음을 확인함.
- 기존 A8 Top-10 저장 순위를 다시 집계하여 Vector Hit@10 100% / MRR 0.743, BM25 71.4% / 0.560, Hybrid 100% / 0.738과 일치함을 확인함. 저장된 평가의 본문 vector 수는 654개임.
- 이번에 실시간 검색·임베딩을 다시 호출한 것은 아니므로 현재 Chroma에 대한 새 A8 측정으로 표시하지 않음. Gemini 호출은 0회임.
- 브라우저 도구에서 Browser is not available: iab 오류가 발생하여 3001 실제 화면 캡처는 하지 못함. Docker 재빌드·운영 반영도 하지 않음.
- 규칙 기반 출처 선정이므로 문장별 실제 인용 추적을 보장하는 기능은 아님. CT·MRI·RI 외 모든 의료 주제의 정밀 분류를 새로 구현한 것도 아님.
- 코드 변경: frontend/src/utils/citationFilter.js 및 직원 Citation/index.jsx임. 관련 필터·렌더링 테스트를 갱신함.
- 기존 다른 작업 변경사항을 보존함. commit·push·tag를 하지 않음.
