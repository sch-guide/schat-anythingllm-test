# 2026-09-25 데이터 커넥터 기능 제거

## 변경 내용

- 관리자 문서 관리 화면의 데이터 커넥터 탭을 제거하고 문서 관리 화면만 표시하도록 변경했습니다.
- GitHub, GitLab, Gitea, YouTube 자막, 웹사이트 대량 수집, Confluence, Drupal Wiki, Obsidian, Paperless-ngx의 전용 화면과 이미지, frontend 모델을 삭제했습니다.
- 서버의 데이터 커넥터 `/ext/*` 공개 route와 전용 provider 검사 코드를 제거했습니다.
- collector의 커넥터 endpoint, loader, 커넥터별 재동기화 handler와 전용 검사를 삭제했습니다.
- YouTube URL은 더 이상 자막 loader로 처리하지 않고 일반 단일 URL 처리 경로만 사용합니다.
- 커넥터 전용 직접 dependency 선언을 제거하고 lockfile을 갱신했습니다.

## 유지한 기능

- PDF와 일반 파일 직접 업로드
- 단일 URL 직접 등록과 일반 URL 문서 재동기화
- Gemini Embedding 2, ChromaDB, BM25, SCHAT 검색과 structured 답변
- 답변 출처와 근거 원문 표시
- 과거 커넥터 출처를 안전하게 표시하거나 민감 query 정보를 제거하는 호환 코드
- SQL agent connector, Telegram 연결, Agent Builder 웹 도구처럼 데이터 커넥터 화면과 무관한 기능

## 검증

- YouTube 자막 우회 제거 테스트를 먼저 실패시킨 뒤 일반 URL 처리로 통과시켰습니다.
- connector source watch 차단 테스트를 먼저 실패시킨 뒤 일반 `link://`만 허용하도록 통과시켰습니다.
- collector URL 처리 검사 96개, 서버 문서 처리 관련 검사 22개, SCHAT 검색·답변·출처 mock 검사 54개가 통과했습니다.
- production Docker 이미지 빌드와 배포에 성공했고 SCHAT 웹, ChromaDB, Python 안전검사 서비스가 모두 healthy 상태입니다.
- 외부 Gemini 호출, ChromaDB 재색인, 문서·계정·대화 데이터 삭제는 하지 않았습니다.
