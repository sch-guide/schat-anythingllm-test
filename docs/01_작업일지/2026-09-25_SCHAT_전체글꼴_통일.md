# SCHAT 전체 화면 글꼴 통일

## 무엇을 바꿨나

- 채팅, 사이드바, 메뉴, 버튼, 입력창, 설정, 출처와 관련 이미지 영역이 같은 전역 산세리프 글꼴을 상속하도록 정리했습니다.
- 기본 글꼴 순서를 `Pretendard`, `Inter`, `system-ui`, 운영체제 기본 글꼴, `Segoe UI`, `sans-serif`로 통일했습니다.
- CSS와 Tailwind의 `font-sans`가 같은 전역 글꼴 변수를 사용하도록 연결했습니다.

## 유지한 것

- 코드 블록, 터미널 표시와 고정폭 문자는 기존 monospace 글꼴을 유지했습니다.
- 외부 CDN, 새 폰트 파일과 새 패키지는 추가하지 않았습니다.
- 레이아웃, 다크모드, 검색, Gemini, ChromaDB, BM25, 답변, 출처와 관련 이미지 기능은 변경하지 않았습니다.

## 확인 결과

- SCHAT UI 글꼴 계약을 포함한 frontend 회귀검사 34건이 모두 통과했습니다.
- production frontend build가 성공했습니다.
- Git 변경 형식 검사와 설명 화면 자동 갱신 검사를 통과했습니다.

## 주의사항

- 기기에 Pretendard나 Inter가 설치되어 있지 않으면 운영체제 기본 산세리프 글꼴로 안전하게 표시됩니다.
- 이 저장소는 기능 비교용 테스트 환경이며 실제 병원 Production 반영으로 간주하지 않습니다.
- Git commit, tag, push는 실행하지 않았습니다.
