# NRS 관련 이미지 오표시 수정

## 확인된 원인

NRS 답변은 간호실무지침 p.100의 본문을 근거로 사용했습니다. 이 본문 청크에는 같은 페이지에서 추출한 이미지 키 4개가 묶여 있었고, 이미지 설명은 모두 비어 있었습니다. 기존 화면 연결은 이미지 내용의 관련성을 확인하지 않고 같은 페이지의 이미지라는 이유만으로 간호부 로고와 표 조각까지 표시했습니다.

추가 확인 결과 현재 PDF에는 고유 이미지가 32개 있지만 기존 기본 상한은 앞쪽 20개였습니다. p.100은 이 상한 뒤에 있어 NRS 화면이 이미지 설명과 검색 근거로 만들어지지 않았습니다.

## 수정

- 페이지 본문에 일괄 연결된 `related_image_keys`는 직원 화면의 관련 이미지로 사용하지 않습니다.
- 검색되고 답변 근거로 직접 채택된 `image_description` 보조 벡터의 `image_key`만 관련 이미지로 표시합니다.
- 이미지 설명 근거가 없으면 기존 답변과 출처만 표시하고 관련 이미지 영역은 만들지 않습니다.
- 수정 전 저장된 과거 답변의 페이지 일괄 이미지도 직접 관련성 표식이 없으면 화면에서 숨깁니다.
- 기존 본문 벡터, Gemini Embedding, ChromaDB, BM25와 출처 선택은 변경하지 않았습니다.
- 이미지 설명 기본 상한은 50개로 조정해 현재 PDF의 고유 이미지 32개를 포함하면서도 무제한 외부 호출은 막았습니다. 동일 이미지 hash 재사용도 유지합니다.

## 문장형 질문과 FPRS 화면 오선택 추가 수정

이미지 설명을 채운 뒤에는 p.100의 NRS·FPRS·FLACC 화면 모두 왼쪽 메뉴에 세 도구명이 함께 보여, 각 설명에도 `NRS`, `FPRS`, `FLACC`가 같이 들어갔습니다. 짧게 `NRS`라고 질문하면 FPRS 화면의 부수적인 `NRS` 글자까지 정확 일치로 취급되어 FPRS 화면이 선택됐습니다.

또한 `NRS 통증척도는 어떻게 평가해?`는 기존 검색에서 `nrs`, `통증척도`, `어떻게`, `평가해` 네 토큰으로 처리됐습니다. 실제 근거의 일치율이 1/4로 낮아져 기존의 약한 근거 차단 기준에서 모든 후보가 제거됐습니다.

- `어떻게` 같은 요청 표현은 검색 핵심어에서 제외하고, `평가해`·`확인해` 같은 제한된 업무 동사는 `평가`·`확인` 형태로 정규화합니다.
- 이미지 설명에 `FPRS가 선택된`, `FLACC가 선택된`처럼 현재 선택 도구가 명시돼 있으면 질문의 영문 도구명과 일치하는 경우에만 관련 이미지 후보로 사용합니다.
- 일반 본문 근거와 선택 도구가 명시되지 않은 이미지 설명은 이 필터의 영향을 받지 않습니다.
- 특정 `NRS` 문구를 하드코딩하거나 기존의 약한 근거 차단 기준을 낮추지 않았습니다.

## 검증

- NRS 본문과 같은 페이지의 로고·표 이미지가 화면 후보에서 제외되는 실패 재현 검사를 추가했습니다.
- 직접 채택된 이미지 설명 근거는 계속 표시되고, 중복 제거·최대 3개·과거 대화 호환이 유지되는지 확인했습니다.
- 사용자 승인 후 누락 이미지 14장만 Gemini에 각각 1회 전송했으며 재시도는 하지 않았습니다. PDF 전체, 계정 정보와 대화 내용은 전송하지 않았습니다.
- 이미지 설명 14개를 기존 본문과 분리된 `image_description` 보조 벡터로 추가했습니다. 작업 후 이미지 설명은 32개이며 누락 설명과 누락 벡터는 모두 0개입니다.
- 기존 본문 벡터는 119개로 유지됐고 작업 전후 내용·metadata·embedding을 합친 해시가 동일했습니다. 전체 ChromaDB 벡터는 본문 119개와 이미지 설명 32개를 합한 151개입니다.
- 초기 누락 보완 확인에서 p.100 본문과 이미지 설명 후보가 모두 존재해 자료 누락이 아님을 확인했습니다. 이후 문장형 질문의 근거 탈락과 FPRS 화면 선택은 질문 정규화와 이미지 주제 판별 문제로 별도 진단했습니다.
- production 이미지를 다시 빌드해 적용했고 SCHAT 웹, ChromaDB와 안전검사 서비스의 healthcheck를 확인했습니다.
- 문장형 질문 정규화와 선택 도구 불일치 이미지 제외 회귀검사를 먼저 실패시키고 수정 후 관련 자동검사 51개가 모두 통과하는 것을 확인했습니다.
- 배포된 코드와 실제 ChromaDB로 외부 호출 없이 재생한 결과, `NRS`는 p.100 근거와 이미지 1개를 유지하면서 FPRS 선택 화면을 제외했습니다. `NRS 통증척도는 어떻게 평가해?`도 `nrs`, `통증척도`, `평가`로 정규화되어 p.100 이미지 근거가 남았고 FPRS 선택 화면은 제외됐습니다.
- 실제 직원 질문 1회는 이미지 설명 생성 승인과 별도인 답변 근거 외부 전송이므로 자동 실행하지 않았습니다. 화면에서 같은 질문을 다시 입력해 최종 문구를 확인할 수 있습니다.
