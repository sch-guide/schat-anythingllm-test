# 관리자 화면 쉬운 사용 개선

## 기준과 승인 범위

- 사용자가 release-1(a2c317f9) 운영 반영을 완료했다고 알려 줌. 운영 서버를 직접 확인한 것은 아님.
- 오늘의 release 반영·근거 조회 등 작업 기록과 현재 diff를 먼저 확인함. 기존 미커밋 문서·스타일·시험 자료는 보존하며 이번 항목 커밋에 넣지 않음.
- 승인된 순서: 1 답변 근거 보기 → 2 사용 통계 → 3 시스템 상태/연결 통합 → 4 옛 원본 삭제 확인 → 5 답변 고급 설정 → 6 브랜드 관리.
- 메시지가 6번 끝의 하이픈에서 끝나고, 3번이 가리키는 ‘7번 AI 설정’의 본문은 없음. 임의 기능을 추가하지 않고 추후 내용 확인 필요함. 1·2번 진행을 막는 조건은 아님.
- 항목별 구현·검사·선별 커밋하며 push·운영 반영·실제 Gemini 호출·DB migration은 하지 않음. 실제 원본 삭제 시험도 하지 않음.

## 1. 답변 근거 보기

- 메뉴·탭·본문 용어를 쉬운 말로 바꿈. 긴 내부 번호 대신 쪽과 현재 목록 순서 표시. 원문 고유 문단 번호가 아니므로 도움말에서 구분함.
- 없는 버전/등록 시각을 숨기고, 원본 상태 미확인 안내는 답변 위 한 번만 표시함. 이전 버전 표시는 유지함.
- 긴 설명은 (?) 도움말로 옮김. 조회 API·관리자 권한·검색 내용은 바꾸지 않음.
- 기존 기준 검사 22개 통과 → 변경 요구 검사 4개 실패 확인 → 수정 후 24개 통과함.
- 최초 build는 실행 도구의 상위 폴더 읽기 제한으로 실패했고 권한을 갖춰 재검증함. 최종 build 25.93초/exit 0 통과함. 기존 Browserslist·외부 모듈·큰 묶음 파일 경고는 유지됨. 기존 앱 재시작 없음.
- 별도 검토에서 (?)의 키보드 접근 문제를 발견해 버튼/초점 도움말로 수정함. 실패 재현 후 최종 화면 검사 25개 통과함. 재검토에서 커밋 차단 수준 문제 없음. 좁은 화면에서 도움말 배치 실제 확인은 남음.

## 이어갈 위치

1번 build·별도 코드 검토 → 이 항목만 커밋 → 2번 사용 통계임. 나머지 2~6번은 아직 구현 완료로 판단하지 않음.
