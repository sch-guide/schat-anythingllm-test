# 지침서 퀴즈

## 한 줄 요약

- 관리자가 지침서 근거로 AI 문제를 만들고 검토·공개합니다.
- 직원은 저장된 문제만 풉니다.
- AI(Gemini)는 관리자의 `AI로 문제 만들기`와 `AI로 다시 생성`에서만 호출합니다.

## 직원 화면 (`지침서 퀴즈`, 사이드바 이용 가이드 위)

- 탭은 퀴즈 풀기 / 오답노트 / 최근 기록 세 개입니다.
- 퀴즈 풀기
  - 대상 문서·주제·문항 수·난이도·문제 유형을 고르고 `퀴즈 시작`을 누릅니다. 공개된 문제 중에서 무작위로 뽑습니다.
  - 최근에 푼 문제는 뒤로 미뤄 덜 나오게 합니다.
  - 공개 문제가 모자라면 "현재 7문항이 준비되어 있습니다. 7문항으로 진행합니다."라고 안내하고 있는 만큼 진행합니다.
- 문제 풀이 화면
  - 진행률, Q번호, 선택지(A~D 또는 O/X), [이전] [정답 확인] [다음]이 있습니다.
  - 정답 확인 뒤에는 정답/오답, 정답 선택지, 저장된 해설, 출처(문서·쪽)가 나옵니다.
  - `근거 원문 보기`는 기존 Citation 화면을 그대로 씁니다. PC는 PDF 쪽을, 모바일은 원문 전용 화면을 엽니다.
- 오른쪽 카드에 현재 점수와 정답률(예: 1 / 2 (50%))이 나옵니다. 모바일에서는 문제 → 해설 → 점수 순서로 세로 배치됩니다.
- 결과 화면은 점수·정답 수·정답률과 [틀린 문제 다시 보기] [다시 풀기] [종료] 버튼으로 구성됩니다.
- 오답노트
  - 틀린 문제가 자동으로 저장됩니다.
  - 내가 고른 답, 정답, 해설, 출처를 보여 줍니다.
  - `틀린 문제 다시 보기`에서 맞히면 오답노트에서 빠집니다.
- 최근 기록은 날짜·주제·점수·정답률이며, 본인 기록만 보입니다.

## 관리자 화면 (`SCHAT 관리자 설정 > 퀴즈 관리`, 문제 신고 다음)

- 탭은 문제 목록 / 퀴즈 세트 / 문제 생성 / 통계 네 개입니다. 오른쪽 위에 "오늘 AI 문제 생성: N회"가 표시됩니다.
- 문제 생성
  - 대상 문서·주제·문항 수(1~20)·난이도(초급/중급/고급)·유형(객관식/OX)을 고르고 `AI로 문제 만들기`를 누릅니다.
  - "AI는 문제를 생성할 때만 사용됩니다. 직원이 퀴즈를 푸는 동안에는 AI API를 사용하지 않습니다." 안내가 함께 나옵니다.
- 근거 수집
  - PDF 전체를 보내지 않습니다.
  - 선택한 문서의 본문 검색 데이터에서 주제와 관련된 쪽을 기존 SCHAT BM25로 골라, 최대 10쪽·약 12,000자만 보냅니다.
  - AI가 만든 이미지 설명은 근거에서 제외합니다.
  - 근거가 없으면 AI를 부르지 않습니다.
- AI 규칙
  - 근거 안에서만 문제를 만듭니다. 일반 의학지식을 더하지 않습니다.
  - 정답은 하나이고, 숫자·시간·용량은 그대로 씁니다.
  - 출처 쪽과 근거 문장을 반드시 붙입니다.
  - 근거가 부족하면 만들지 않습니다.
  - 결과는 정해진 JSON 형식으로만 받습니다.
- 자동 확인
  - 보낸 쪽이 아닌 출처, 선택지 중복·개수 오류, 정답 위치 오류는 버립니다.
  - 근거 쪽에 없는 숫자나 원문에서 찾지 못한 근거 문장은 "확인 필요"로 표시합니다.
- 만든 문제는 모두 `작성중`입니다. 관리자가 공개해야 직원에게 나옵니다.
- 검토 창
  - 문제·선택지·정답·해설·주제·난이도·출처 쪽을 고칠 수 있습니다. 출처 쪽은 문서에 실제 있는 쪽인지 확인합니다.
  - `원문 확인`은 기존 PDF 보기로 해당 쪽을 엽니다.
  - 공개·사용중지·`AI로 다시 생성`을 할 수 있습니다.
  - 위험 영역의 완전삭제는 '삭제'를 입력해야 실행됩니다.
- 퀴즈 세트
  - AI로 한 번 만든 문제 묶음입니다.
  - 문제를 공개하면 작성중인 세트도 공개로 바뀝니다. 세트를 사용중지하면 그 세트의 문제가 출제되지 않습니다.
- 통계
  - 전체 현황, 주제별 정답률, 자주 틀리는 문항(답 3개 이상, 정답률 낮은 순), 문항별 정답률, 부서별 평균 점수·정답률·많이 틀린 주제를 보여 줍니다.
  - 응답자 5명 미만 부서는 평균을 표시하지 않습니다.
  - 개인 점수나 순위는 없습니다.

## 정답 저장 방식

- 객관식은 선택지마다 고정 번호(c1~c4)를 붙이고, 정답도 그 번호로 저장합니다. 직원 화면에서는 풀이마다 선택지 순서를 섞지만, 판정은 선택지 번호로 합니다.
- OX는 선택지 없이 정답 칸(`O`/`X`)에 따로 저장합니다.

## 문서 버전

- 문제마다 만들 때의 문서 ID·파일 이름·버전이 저장되고, 새 지침서가 올라와도 자동으로 바뀌지 않습니다.
- 현재 작업 공간에 없는 문서로 만든 문제는 관리자 화면에 `이전 문서 기반`으로 표시됩니다. 직원 출제에서는 빠지고 공개할 수도 없습니다.

## 데이터베이스

- 새 테이블만 추가했습니다. 기존 테이블과 데이터는 바꾸지 않았습니다.
  - `schat_quiz_sets`, `schat_quiz_questions`, `schat_quiz_attempts`
  - `schat_quiz_answers`, `schat_quiz_wrong_notes`, `schat_quiz_generation_logs`
- 정식 migration은 `20260927030000_schat_guideline_quiz`입니다.
- 작업 전 백업: `server/storage/anythingllm.before-quiz-20260927.db`
- 계정을 완전삭제하면 그 사람의 풀이 기록도 함께 지워집니다.
- AI에 보낸 글, AI 응답, API 키는 저장하지 않습니다. 생성 기록에는 횟수·상태만 남깁니다.
