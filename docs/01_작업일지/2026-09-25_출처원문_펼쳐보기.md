# 출처 근거 원문 펼쳐보기

## 목적

Query 모드의 간결한 답변은 유지하면서 직원이 답변에 사용된 병원 지침 원문을 채팅 화면에서 바로 확인할 수 있도록 출처 표시를 보완했습니다.

## 변경

- 기존 출처 버튼과 출처 사이드바는 그대로 유지했습니다.
- 답변 아래에 출처별 문서명·페이지·항목명을 표시하는 요약 행을 추가했습니다.
- 서버가 공개한 `excerpt`가 있는 출처만 `근거 원문 보기` 버튼을 표시합니다.
- 각 출처는 서로 독립적으로 열고 닫을 수 있습니다.
- 긴 원문은 제한된 높이로 먼저 보여주고 `더보기`와 `접기`로 전환할 수 있습니다.
- `excerpt`가 없는 과거 대화는 기존 출처 정보만 표시합니다.
- 화면에는 내부 SourceUnit ID, 저장 경로, metadata와 문서 SVG 데이터를 사용하지 않습니다.
- 모바일에서는 출처 정보와 버튼을 세로로 배치할 수 있고, 라이트·다크 테마 색상을 모두 적용했습니다.
- 표시 순서는 답변, 출처와 근거 원문, 관련 이미지 순서를 유지합니다.

## 유지한 기능

- Query 모드
- Gemini 답변과 structured response
- ChromaDB와 BM25 검색
- 기존 출처 버튼과 사이드바
- 관련 이미지
- 검색 및 답변 서버 경로
