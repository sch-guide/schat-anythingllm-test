# 개인정보 보안 서면 점검과 발표 준비

- 요청: 개인정보·비밀번호 8개 항목, 파일럿 위험 요소, 성과발표 예상질문 20개를 워드로 작성.
- 범위: 이 테스트 저장소의 계정 서비스·로그인 요청 처리·DB 구조 정의·삭제 마이그레이션과 기존 개인정보 동의 작업일지를 읽어 확인. 실제 직원 DB 내용 열람·로그인 시험·외부 API 호출·자료 전송·코드 수정·배포·Git commit 및 push 없음.
- 확인: bcrypt 계산 강도 10 해시 저장, 관리자 권한 검사, 사용자·부서·동의서·동의 기록 구조, 관리자 삭제 기능. 삭제 후 신고 사본 및 삭제 이벤트에 이름·사번·부서가 남는 구조 확인.
- 미확인: 실제 접속 HTTPS, 실제 DB 전체의 비밀번호 상태, 서버 디스크 암호화, 전체 관리자 접근 범위, 삭제 후 모든 저장소의 잔존 자료.
- 기존 기록: 대화·접속 기록 자동 파기는 2026-10-12 작업일지에 미구현 계획으로 명시됨. 이번에 구현 완료를 확인하지 않음.
- 후속 조치 제안: HTTPS 확인, 최초 비밀번호 등록 본인 확인 강화, 외부 전송 범위와 환자정보 입력 제한, 삭제 잔존정보 처리, 보유기간 및 자동 파기, 최소 권한, 오답 대응.
- 산출물: `05_인수인계/SCHAT_개인정보_보안점검과_성과발표_예상질문.docx`. 질문별 답변 준비사항과 내부 근거 경로 포함.
- 검증 한계: 기본 페이지 이미지 변환 도구는 pdf2image 미설치로 실패함. 문서 구조 검사와 문서 화면 생성·분리 검사를 별도로 수행하며, 페이지 이미지 검증 완료로 기록하지 않음.
