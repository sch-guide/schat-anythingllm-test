# 저장공간 정리: 조회와 삭제 전 미리보기

## 문서 관리 화면

- 폴더 옆 `(2008)`과 목록 위 `2008 관련 문서`를 숨겼습니다. 이 숫자는 예전 업로드까지 포함한 내부 파일 수였습니다.
- 오른쪽 작업 공간 목록 위에 `등록 문서 2개 · 총 543쪽`을 표시합니다.
  - 문서 수: 원본 PDF 하나를 한 개로 셉니다.
  - 페이지 수: 작업 공간에 연결되어 실제 검색에 쓰이는 페이지 기록 수입니다.
- `등록된 문서` 표시 이름과 업로드 안내문 삭제는 그대로 유지합니다.

## 저장공간 정리(관리자 설정 새 메뉴)

- 첫 화면에서 현재 사용 중인 자료와 정리 가능한 자료를 요약합니다.
  - 현재 사용 중: 문서 2개, 543쪽, 검색 데이터(본문 654, 이미지 설명 1,331), 체크리스트 64개
  - 정리 가능: 예전 업로드 4건, 페이지 기록 1,465개, 오래된 이미지 약 766MB, 예상 확보 용량 약 808MB
- `정리 대상 보기`를 누르면 업로드 한 번 단위로 목록이 나옵니다. 각 줄에 올린 시각, 페이지·페이지 기록 수, 이미지 수·용량, 기타 용량, 연결 확인(작업 공간·검색 데이터·체크리스트·원본 PDF), 상태가 보입니다.
- 현재 사용 중인 실무지침서(461쪽)와 검사 및 시술(82쪽)은 `사용 중 · 삭제 불가`로 표시되고 체크박스를 누를 수 없습니다.
- 예전 업로드만 선택할 수 있고 `선택 항목 확인`을 누르면 삭제 전 미리보기가 나옵니다. 서버가 이때 자료를 다시 확인합니다. 하나라도 검색 데이터와 연결되어 있으면 "현재 검색 데이터와 연결되어 있어 삭제할 수 없습니다."로 막습니다.
- 삭제 확인 문구는 미리 보여 주지만 `삭제 진행` 버튼은 누를 수 없습니다. 전체 자동 삭제 버튼은 없습니다.
- 이미지 설명 저장본(1,177개)은 같은 이미지를 다시 올릴 때 AI 설명을 다시 만들지 않도록 항상 유지합니다.
- 화면에는 내부 문서 ID와 파일 경로를 보내지 않습니다.
