# 위험 설정 메뉴 제거

## 바꾼 내용

- 관리자 설정 메뉴에서 `위험 설정`(작업 공간 삭제)을 뺌. 운영은 작업 공간 하나를 직원 전체가 쓰므로, 지우면 직원 채팅이 멈추고 문서를 모두 다시 등록해야 함. 평소 정리는 문서 삭제, 저장공간 정리, 부서 삭제로 충분함.
- 주소 `/settings/schat/danger`로 직접 들어와도 첫 메뉴(브랜드 관리)가 열림.
- 바꾼 파일: `frontend/src/pages/SchatAdmin/menu.js`, `index.jsx`, `components/SettingsSidebar/index.jsx`, 메뉴 테스트. `sections/Danger.jsx`는 삭제함.
- 서버의 작업 공간 삭제 기능 자체는 그대로 둠. 관리자 화면에서 누를 버튼만 없앰.

## 확인

- 메뉴 테스트 15개 통과. 로컬 Docker 3001 관리자 화면에서 메뉴 13개에 `위험 설정`이 없고, 직접 주소로 들어가도 작업 공간 삭제 화면이 나오지 않음을 확인함.
- 운영 서버는 바꾸지 않음. commit·push를 하지 않음.
