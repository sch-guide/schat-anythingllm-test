# 답변 평가와 직원 질문 기반 동의어 후보 — 진행 기록

## 승인과 순서

- 2026-10-12 새 표 `schat_answer_feedback` 하나 추가 승인. 기존 표·대화·신고 자료는 보존함.
- 순서: 남은 C(문서 후보 생성 실패 부분 재시도) → 싫어요 → 직원 질문 기반 후보 → 격리 검사 → 3001 백업·반영·화면 확인 → release-admin-8만 push.
- 실제 Gemini는 직원 질문 후보 확인 1회까지만 허용됨. 현재 추가 호출 0회.
- 기존 release-1부터 추적된 server/storage 파일 89개는 유지하고 새 변경만 올리도록 추가 승인받음. 이번 관리자 변경에서 해당 파일 차이는 없음. 새 비밀 파일·실제 DB·원본·백업이 섞이는지는 최종에 다시 검사함.

## 사전 확인

- 좋아요는 workspace_chats.feedbackScore에 저장하며 직원 자신의 대화만 변경하는 경로가 있음. 이유·메모·처리 상태는 없음.
- 문제 신고는 schat_issue_reports에 저장하며 목록·통계·FAQ 화면을 사용함. 새 평가를 관리자 목록에 합쳐 보여 주되 기존 신고·FAQ 기능은 유지해야 함.
- 사용 통계의 검색 실패는 저장된 답변의 출처 수가 0인 대화임. 모두 동의어 부족이라는 뜻은 아니므로 AI 제안은 관리자 승인 전 검색에 사용하지 않음.
- 새 후보와 실행 내역은 기존 동의어 표의 JSON 및 기존 설정 저장소를 활용할 계획이며 새 표 추가 승인은 답변 평가 하나에 한정됨.

## 현재 진행

- 기존 동의어 기본 선별 검사 46개 통과. 가짜 자료만 사용함.
- C 코드 커밋 6f143fe9: 성공한 묶음 기록, 실패 부분만 재시도, 문서 변경/삭제와 중복 실행 차단, 기록 저장 실패 시 호출 중단, 관리자 실패 안내를 구현함. 주담당 선별 검사 재실행 93개 통과. 독립 코드 검토 진행 중이며 3001에는 아직 반영하지 않음.
- 새 표 생성·실제 DB 변경·새 기능 배포·push는 아직 하지 않음.
- 다음: C 코드와 검사 검토 → 별도 커밋 → 답변 평가 구현. 상세 실행 계획은 docs/superpowers/plans/2026-10-12-feedback-synonym-followup.md.

- 6f143fe9 구현 후 독립 검토에서 내부 연결 재시도 직전 문서 확인과 재시도 기록 저장 실패 알림 누락을 발견함. f892b55e로 보완하고 재검토 통과함.
- 주담당 최종 선별 검사 95개 통과. 프론트엔드 빌드 성공. 실제 Gemini·실제 DB 변경 없음.
- 이제 답변 평가(싫어요) 구현을 시작함. C의 실제 3001 화면 확인은 전체 반영 단계에 남아 있음. GitHub push도 아직 하지 않음.

## C 추가 안전 보완과 이어갈 위치

- 설치된 호출 도구에 기본 자동 재시도 2회가 있음을 확인함. 이 자동 재시도가 문서 변경 확인을 건너뛰지 않도록, 동의어 후보 호출에서만 자동 재시도를 끄는 보완을 92d2de68로 커밋함. 일반 직원 채팅의 재시도 방식은 바꾸지 않음.
- 가짜 호출로 문서 변경·삭제 후 숨은 재전송이 없는지 확인함. 주담당이 관련 검사 101개를 재실행하여 모두 통과했고, 독립 재검토도 통과함.
- 답변 평가 구현을 재개함. 완료 후 직원 질문 후보 찾기, 3001 백업·반영과 화면 확인, 최종 파일 점검 순서로 진행함. 현재 새 표를 실제 DB에 적용하지 않았고 3001 재시작·실제 Gemini 호출·push도 하지 않음.
- 기존 추적 storage 파일 유지 승인은 확인함. 새 DB·백업·원본 PDF·비밀 파일을 추가해도 된다는 뜻은 아니며, 최종 push 전에 새 변경을 별도로 검사함.

## 추가 요청 ⓪ 우선 처리

- 사용자 최신 순서는 ⓪ 자동 생성 결과·행 디자인 → ③ 싫어요 → ⑤ 질문 후보 → GitHub임. 싫어요의 미완성 변경은 보존하고 아직 반영하지 않음.
- 3001 실행 이미지는 `schat-admin-build:synonym-bd-6a3021e8`로 확인함. C의 새 접힌 기록 화면보다 이전 버전이므로, 화면이 그대로인 직접 원인은 새 버전 미반영임. 브라우저 캐시 문제로 단정하지 않음.
- 최신 요약 문구를 '마지막 AI 후보 찾기'와 문서/새 제안/실패 수로 맞춤. 회차 선택에는 날짜 실행 이름을 표시함.
- 단어는 흰 바탕·옅은 테두리와 분류 색줄, 분류는 색 배지로 변경함. 검토 대기에도 수정 버튼을 추가하고 단어 클릭 편집은 제거함. 원문은 작은 알약 모양, 등록은 채운 버튼, 수정·제외는 테두리 버튼으로 변경함.
- 요구 변경 검사 3개 실패를 먼저 확인한 뒤 구현했고 동의어 관련 검사 95개가 통과함. 실제 3001 화면 확인은 백업·반영 후 진행할 예정이므로 아직 '실제 화면에서 확인함'으로 기록하지 않음.
- 보조 구현 실행 한도로 답변 평가가 중단되어, 미완성 파일은 그대로 유지함. 현재 주담당이 ⓪를 먼저 수행 중임.
