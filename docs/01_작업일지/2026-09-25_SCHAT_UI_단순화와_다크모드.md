# SCHAT 화면 단순화와 다크모드

## 무엇을 바꿨나

- 좌측 상단을 `SCHC` 마크와 `SCHAT` 이름으로 통일했습니다.
- 채팅 설정 메뉴에서 글자 크기만 남기고 다크모드 토글을 추가했습니다.
- 추억, 채팅 내보내기와 채팅 링크 복사 항목은 화면에서 제거했습니다.
- 채팅 우측 상단 모델명과 답변 아래 모델·속도 정보를 숨겼습니다.
- 사이드바 하단에는 관리자와 단일 사용자 모드에서만 설정 버튼을 표시합니다.
- 데스크톱과 모바일 사이드바가 같은 텍스트 브랜딩을 사용하도록 했습니다.

## 유지한 기능

- 모델 선택 컴포넌트와 응답 성능 측정 코드는 삭제하지 않고 화면에서만 숨겼습니다.
- 기존 `useTheme()`과 라이트/다크 CSS를 재사용했습니다.
- 검색, Gemini, ChromaDB, BM25, 출처, 관련 이미지와 답변 생성 코드는 변경하지 않았습니다.
- 관리자 설정 화면이 공유하는 푸터 아이콘 목록 상수는 호환성을 위해 보존했습니다. 이 상수의 아이콘은 SCHAT 사이드바에는 표시되지 않습니다.

## 확인 결과

- SCHAT UI 계약 5건과 절차 답변·출처 상세·관련 이미지 회귀 8건을 합한 13건 통과
- 변경 UI 파일 ESLint 통과
- 변경 UI 파일 Prettier 검사 통과
- frontend production build 성공
- Docker 이미지 build 성공
- `schat-web`, `schat-chromadb`, `schat-safety-evaluator` 모두 healthy
- 자동 브라우저가 제공되지 않아 실제 스크린샷 확인은 수행하지 못했고, 데스크톱·모바일 렌더링 경로는 코드 계약과 production build로 확인했습니다.

## 주의사항

- 이번 작업은 기능 비교용 테스트 저장소의 화면 변경이며 실제 병원 Production 반영으로 간주하지 않습니다.
- Git commit, tag, push는 실행하지 않았습니다.
