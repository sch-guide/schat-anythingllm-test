# Automatic 병원 질문 선행 검색

## 변경 내용

- Automatic·AgentHandler와 Gemini 자유형 답변 방식을 유지했습니다.
- 병원 문서 관련 질문이면 첫 답변 생성 전에 기존 `rag-memory`를 사용자 원문으로 정확히 1회 실행합니다.
- 검색 결과는 기존 function result 형식으로 답변 모델에 전달하고 실제 source는 기존 출처 보관소에 저장합니다.
- Agent가 필요하다고 판단하는 추가 도구 호출은 그대로 허용합니다.
- system prompt, Query 모드, ChromaDB, BM25, Embedding과 색인은 변경하지 않았습니다.

## 질문 판별

- 기존 검색의 `queryTokens`와 `detectQuestionIntent`를 재사용합니다.
- 병원 지침·간호·약물·검사·시술·수혈·감염·교육 등 문서 영역과 일반적인 임상 약어 형식을 판별합니다.
- 특정 NRS·FPRS 답변을 하드코딩하지 않습니다.
- `오늘 날씨 어때?`처럼 병원 문서와 무관한 일반 질문은 강제 검색하지 않습니다.

## 자동 검사

- 구현 전 네 의료 질문이 모두 강제 검색 0회로 실패하고 날씨 질문만 통과하는 RED를 확인했습니다.
- 구현 후 네 의료 질문은 각각 원문으로 1회 검색되고 날씨 질문은 0회인 GREEN을 확인했습니다.
- 기존 출처·원문·이미지 회귀를 포함한 서버 검사 26개가 통과했습니다.
- frontend production build와 Docker production 이미지 build가 성공했습니다.

## 실제 질문 검증 상태

- 실제 다섯 질문은 검색된 병원 문서 원문을 Gemini로 전송합니다.
- 현재 승인 문구만으로는 외부 데이터 전송 실행이 허용되지 않아 실제 호출은 실행하지 않았습니다.
- 병원 검색 원문의 Gemini 전송을 명시적으로 승인받은 뒤 각 질문을 1회, 재시도 없이 확인해야 합니다.
