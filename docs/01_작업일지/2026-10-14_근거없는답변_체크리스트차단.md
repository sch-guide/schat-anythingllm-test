# 근거 없는 답변의 체크리스트 표시 차단

- 증상: 정형외과 local block 하 I&D 질문에 ‘등록된 문서에서 확인되지 않습니다’라고 답하면서 정형외과 체크리스트 버튼을 표시함.
- 원인: 채팅 화면이 질문의 별칭만 검사하여 체크리스트를 연결하고, 답변의 근거 없음·대기·오류 상태는 검사하지 않았음. 출처 화면은 별도로 근거 없음 판정을 하고 있어 서로 다른 표시가 발생함.
- 수정: 질문 연결에 해당 답변 상태를 함께 전달하고, 출처 화면의 근거 없음 판정을 공통 사용함. 대기·응답 작성 중·오류일 때도 연결하지 않음. 정상 완료 답변은 기존 별칭 연결을 유지함. 과거 답변도 화면에서 같은 판정을 적용하며 저장 데이터는 바꾸지 않음.
- 새 검사 2개를 먼저 실행하여 기존 코드에서 실패함을 확인한 뒤 수정하여 통과함. 채팅 화면의 실제 선택 식을 실행하는 연결 검사도 추가함.
- 최종 선별 검사: 체크리스트·출처 관련 158개 통과, 실패 0개. 문서 화면 분리 검사 11개 통과. 최초 화면 검사 도구의 폴더 접근 제한과 새 검사 import 경로 오류를 해결한 뒤 전체 선별 검사를 재실행한 결과임. 실제 브라우저 확인은 미실시함.
- DB 구조·검색 자료·체크리스트 원본·개인 메모 변경 없음. 다른 작업의 미커밋 변경은 유지함. 실제 Gemini 호출·운영 반영·3001 재시작·커밋·push는 하지 않음.
- 이 기록은 로컬 코드 수정이며 운영 화면 수정 완료를 뜻하지 않음. 다음은 별도 승인 범위에 맞춘 배포와 실제 화면 확인임.
