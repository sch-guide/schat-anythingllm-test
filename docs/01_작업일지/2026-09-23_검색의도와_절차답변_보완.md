# 검색 의도와 절차 답변 보완

## 왜 바꿨나

- `수혈 종류` 질문에서 직접 관련된 혈액제제 종류 외의 주변 수혈 근거가 함께 선택됐습니다.
- 혈액제제 종류라는 제목이 한 청크의 끝에 있고 실제 목록은 다음 청크에 있어, 제목만 답변에 남을 수 있었습니다.
- `진정 절차`는 안전하더라도 실제 단계가 있는데 제목 수준으로 짧게 끝나거나 서로 다른 대상의 절차가 섞일 위험이 있었습니다.

## 무엇을 바꿨나

- `종류·목적·절차·준비·주의` 질문 의도를 일반 규칙으로 구분합니다.
- 가장 직접적인 근거보다 결합 점수가 크게 낮은 주변 근거는 결과 수를 채우기 위해 억지로 사용하지 않습니다.
- 질문과 맞는 제목이 청크 끝에 있으면 같은 문서에서 바로 다음에 저장된 청크만 이어 사용합니다.
- 제목과 다음 본문의 항목 관계를 이어 주되, 없는 항목명을 임의로 만들지는 않습니다.
- 절차 질문은 선택된 실제 단계들을 원문 순서대로 보존하고 성인·소아 등 다른 분기를 섞지 않습니다.
- 기존 Python 안전검사의 통과 기준은 변경하거나 완화하지 않았습니다.

## 실제 질문 4건 확인

허용된 실제 Gemini 질문은 각 1회만 실행했습니다.

- `수혈 종류 알려줘`: 주변 문서는 줄었지만 당시에는 제목만 남아 원문 기반 안전 답변으로 대체됐습니다.
- `진정 절차`: 관련 진정 근거를 사용했으나 안전검사에서 필수 근거 누락으로 판단해 원문 기반 안전 답변으로 대체됐습니다.
- `소아 진정 알려줘`: 소아 진정 근거를 사용했으나 필수 근거 누락으로 원문 기반 안전 답변으로 대체됐습니다.
- `비터널형 카테터는 뭐야?`: 등록 자료에 충분한 근거가 없어 답변하지 않았습니다.

이후 제목과 본문 연결 및 절차 분기 보완을 추가했습니다. 추가 Gemini 호출은 금지 조건을 지키기 위해 하지 않았습니다.

## 최종 자동검사

- 실제 116개 검색 데이터에서 `수혈 종류` 제목 다음의 혈액제제 목록 청크가 연결되는 것을 확인했습니다.
- 원래 문서 위치와 벡터 검색 순위를 혼동하지 않도록 별도 회귀검사를 추가했습니다.
- `진정 절차` 근거는 원문 순서를 유지하고 성인·소아 분기를 섞지 않도록 확인했습니다.
- 검색·직원 표시·안전 연결 관련 자바스크립트 검사 49건 통과
- 전체 Python 검사 28건 통과
- 변경한 Python 파일 코드 검사 통과
- Git 공백 오류 검사 통과

## 현재 판단

기존 116개 검색 데이터와 계정·대화는 그대로 유지됐습니다. 직원 웹테스트를 시작할 수 있지만, 최종 보완 뒤의 실제 문구는 직원 화면에서 사람이 다시 확인해야 합니다.
