# 문서 화면(docs_view) 최신화

## 한눈에 보기

- 문서 화면의 내용을 실제 코드와 최신 기록에 비교해 오래된 문장을 고침.
- 빠져 있던 기능 5가지를 기능 표에 추가함: 직원 일괄 등록, 처음 로그인 비밀번호 직접 설정, 연결 설정, 브랜드, 퀴즈 검토·통계.
- 통합 아키텍처 구조도를 문서 화면의 `구조도`에 추가함.
- 화면 위와 아래에 `최종 업데이트` 날짜를 표시함.
- 고치기 전 문서 상태를 커밋 `bb98a5b5`로 보존함. 이 커밋에는 문서 파일만 넣고, 다른 작업 중인 코드 파일은 넣지 않음.

## 새로 적은 기능

- 직원 일괄 등록: 양식(xlsx, csv)을 올리면 확인 결과를 먼저 보여 주고, 등록 버튼을 눌러야 계정을 만듦. 비밀번호는 양식에 넣지 않음.
- 처음 로그인: 직원이 등록된 직원인지 확인한 뒤 비밀번호를 직접 만듦.
- 연결 설정: Gemini 답변용·임베딩용 API 키 상태와 현재 모델 확인, 새 키 저장, 연결 테스트. 임베딩 모델은 이 화면에서 바꿀 수 없음.
- 브랜드: 서비스 이름과 작업 공간 이름 변경. 병원 로고와 로그인 화면은 미리보기만 제공함.
- 퀴즈 검토·통계: 문제 수정·삭제, 주제별·부서별 정답률, 자주 틀리는 문항.

## 추가 작업: Word 변환본과 구조도 수정

- 문서 화면(docs_view)을 Word 파일 하나로 만드는 도구를 추가함.
  - `문서도구/Word_만들기.py`: 화면의 제목·문단·목록·표·코드를 Word 서식으로 옮김. 5개 메뉴는 제목 1, 메뉴 안 구역은 제목 2 이하.
  - `문서도구/Word_그림_찍기.mjs`: 색깔 상자·단계 그림·구조도를 Chrome으로 2배 선명하게 찍음.
  - 표지(SCHAT 시스템 문서, 최종 업데이트 날짜), 목차, A4 세로, 맑은 고딕, 쪽 번호, 표 머리글 반복을 넣음.
  - `python-docx`는 이 PC에만 설치하고 requirements·package 파일에는 넣지 않음.
- 다시 만드는 방법: `python 문서도구/문서화면_만들기.py` 다음 `python 문서도구/Word_만들기.py`.
- 구조도 3장을 고침.
  - 질문 처리 흐름: 마지막 칸이 그림 밖으로 잘리고 6번째 단계가 빠져 있던 것을 원본 설계(.mmd)대로 6단계로 다시 그림.
  - 문서 등록 DFD: 빠져 있던 원본 PDF·이미지 보관과 체크리스트 추출 갈래를 넣음.
  - 시스템 아키텍처: 아래 빈 공간을 줄임(높이 580 → 300).
- 원본 문서의 줄 끝 `\`(Markdown 줄바꿈 표시)가 웹 화면에 `\`, Word에 `₩`로 보이던 문제를 문서 화면 변환 규칙에서 고침(304줄 → 0줄).
- 확인 결과: 전체 Word 96쪽을 Word로 PDF를 만들어 모든 쪽을 확인함. 잘린 그림 0, 폭을 넘는 표 0, 쪽 끝에 홀로 남은 표 머리글 0. 문서 화면 검사 4종 통과.
