# 관련 이미지 검색에 원문 질문 사용

## 문제

본문 근거 검색과 관련 이미지 후보 검색이 같은 검색 문장과 벡터를 사용했습니다. 본문 검색에 적합하게 확장된 문장은 답변 근거에는 도움이 되지만, 짧고 정확한 도구명으로 만들어진 이미지 설명과는 거리가 생길 수 있었습니다. 이 경우 `NRS` 이미지 설명이 등록되어 있어도 최종 `relatedImages`가 비어 화면에 나오지 않을 수 있었습니다.

## 수정

- 본문 검색은 기존의 확장된 검색 문장과 결과 순위를 그대로 사용합니다.
- 관련 이미지 검색은 직원이 입력한 원문 질문으로 별도의 벡터 및 BM25 후보를 계산합니다.
- 별도 결과 중 `image_description`이고 질문 초점 검사를 통과한 항목만 관련 이미지 후보로 전달합니다.
- 같은 페이지의 이미지 전체를 펼치지 않으며, 동일 이미지 키를 제거하고 최대 3개만 표시합니다.
- 이미지 후보는 Gemini 본문 근거와 직원 출처 목록에 추가하지 않습니다.
- ChromaDB 데이터, BM25 구조, 본문 top-N, Gemini 근거 상한과 프런트엔드는 변경하지 않았으며 재색인도 하지 않았습니다.

## 검증

- 수정 전에 확장 본문 검색어가 이미지 원문 질문을 덮어쓰면 NRS 이미지 후보가 0개가 되는 실패 검사를 확인했습니다.
- 수정 후 채팅 검색어 분리와 관련 이미지 검색 검사가 통과했습니다.
- `NRS`, `NRS 통증척도는 어떻게 평가해?`, `FPRS`, `통증 점수 설명`, `통증 점수 알려줘` 회귀 검사가 통과했습니다.
- NRS 질문에는 FPRS 선택 화면과 로고가 포함되지 않았고, FPRS 질문에는 FPRS 이미지 후보만 남았습니다.
- Chroma 및 SCHAT 관련 자동 검사 121건이 모두 통과했습니다.
- 실제 Gemini 호출과 재색인은 실행하지 않았습니다.
- Git commit, tag, push는 실행하지 않았습니다.
