# 체크리스트 인쇄와 큰 항목 제목 표시

확인일: 2026-10-14
작업 브랜치: feat/checklist-print-headings-20261014

## 무엇을 바꿨나
채팅 안 작업창과 별도 체크리스트 창에 프린터 아이콘이 있는 인쇄 버튼을 체크 모두 해제 왼쪽에 추가했다. 모바일에서도 같은 버튼을 사용한다. 인쇄는 체크리스트만 별도 임시 화면에 구성하며 접힌 구역도 모두 포함한다. A4 세로, 여백 14mm로 지정했다. 체크된 세부·단독 항목은 ☑와 취소선, 미체크는 ☐로 표시한다. 화면 메뉴, 입력 버튼, 안내 팝업과 스크롤 영역은 인쇄 내용에 포함하지 않는다. 환자정보와 기타메모에는 기존 이름 가리기 함수를 적용한다. 임시 인쇄 화면은 인쇄 종료 시 제거하며 외부 서비스를 사용하지 않는다.

세부 줄이 있는 식이·자세·관찰사항 등의 항목은 제목으로 표시하고 상위 체크박스와 일괄 체크 동작을 제거했다. 제목의 글씨체와 굵기는 유지한다. 세부 항목 없는 단독 체크는 유지한다. 체크리스트 원문, 순서, 항목 ID 및 체크 저장 키는 바꾸지 않았다. 기존 개별 체크는 그대로 표시되며 큰 항목을 다시 매핑하거나 사용자 저장 기록을 수정하지 않는다. 환자정보 입력과 이름 가리기, 체크 저장 처리도 그대로다.

## 검증 결과
- 체크리스트 관련 자동 검사 69개 통과. 실제 공통 컴포넌트 출력에서 큰 항목 체크 제거, 세부·단독 체크 개수와 저장 키 상태를 확인했다.
- 기존 체크 읽기, 사용자·체크리스트별 분리, 이름 가리기, HTML 입력 이스케이프, 체크·취소선, 400항목 마지막 내용 포함을 검사했다.
- 임시 인쇄 프레임 로드·인쇄 호출·종료 후 제거는 모의 환경 검사 통과.
- production build 성공. 기존 의존성·파일 크기 관련 빌드 경고는 남아 있다.
- 로컬 Docker 3001에 화면 파일만 반영. 첫 화면 HTTP 200, 빌드와 반영 파일의 SHA256 일치.
- 저장 API, 체크리스트 저장소, 검색과 Excel 처리 서버 파일은 이전 이미지와 SHA256 일치.
- 연결 가능한 브라우저 목록이 비어 있고 Edge와 Chrome 열기 모두 Browser is not available로 실패했다. 따라서 실제 PC·모바일 클릭, Edge·Chrome 인쇄 미리보기, 실제 여러 장 인쇄의 쪽 나눔/잘림은 미확인이다. 자동 검사만으로 실제 인쇄 검증을 완료했다고 판단하지 않는다.
- 실제 사용자 체크 상태·환자정보·운영 데이터는 테스트로 변경하지 않았다. 외부 AI 호출 없음, 추가 비용 0원. 운영 서버 배포 및 Git commit/push/tag 없음.
