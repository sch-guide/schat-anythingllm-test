# 처음 로그인: 직원이 비밀번호를 직접 설정

## 무엇이 바뀌었나

- 관리자가 임시비밀번호를 만들고 전달하던 방식을 없앴습니다. 직원 추가, 일괄등록, 비밀번호 초기화 어디에서도 비밀번호가 만들어지거나 표시되지 않습니다. Excel 양식에도 비밀번호 칸이 없습니다.
- 새로 등록된 직원은 `비밀번호 설정 전` 상태입니다. 이 상태에서는 어떤 비밀번호로도 로그인되지 않습니다.
- 직원이 로그인 화면에서 부서·사번·이름을 입력하고 비밀번호를 비워 둔 채 `로그인`을 누르면 `처음 로그인` 화면으로 넘어갑니다.
  - 새 비밀번호와 확인을 입력하면 바로 SCHAT으로 들어갑니다.
  - 조건: 8자 이상, 영문·숫자·특수문자 중 두 가지 이상, 사번 포함 금지
- 비밀번호를 정한 뒤에는 처음 로그인 화면으로 다시 들어갈 수 없고, 부서·사번·이름·비밀번호로 로그인합니다.
- 비밀번호를 잊으면 관리자가 `비밀번호 초기화`를 누릅니다. 기존 비밀번호와 이미 열려 있던 로그인은 즉시 무효가 되고, 직원은 다시 처음 로그인에서 새 비밀번호를 정합니다.
- 비밀번호는 기존처럼 bcrypt 해시로만 저장합니다.
- 사번이 없는 기존 관리자 계정은 현재 비밀번호를 그대로 씁니다.

## 알아 둘 위험

- 직원이 비밀번호를 정하기 전에는, 그 직원의 부서·사번·이름을 아는 다른 사람이 먼저 비밀번호를 정할 수 있습니다.
- 이 경우 본인은 로그인할 수 없어 알아챌 수 있고, 관리자가 초기화하면 되돌릴 수 있습니다.
- 처음 비밀번호 설정 성공과 실패는 시스템 기록에 남습니다(입력값 없이 IP만).
- 운영을 시작하면 직원에게 가능한 빨리 처음 로그인을 하도록 안내하는 것을 권장합니다.
