# Renal biopsy 플로팅 작업창과 Citation 정리

## 화면 변경

- 직원용 체크리스트만 배경을 막지 않는 플로팅 작업창으로 변경했습니다.
- PC 초기 크기는 390×520px(최소 310×260px)이며 제목 표시줄 이동, 오른쪽 가장자리·아래 가장자리·오른쪽 아래 모서리 크기 조절, 최소화, 복원, 닫기를 지원합니다.
- 사용자가 닫기 전까지 채팅 기록이 다시 그려져도 작업창 상태가 유지되도록 채팅 기록 상위에서 한 번만 렌더링합니다.
- 이동 위치에는 화면 경계 보정을 적용하지 않아 작업창을 화면 밖으로 옮길 수 있습니다.
- 모바일은 좌우 16px, 하단 16px의 고정 패널과 내부 스크롤을 사용합니다.
- 관리자용 체크리스트 보기·수정 모달과 체크리스트 자동 추출·저장 데이터는 변경하지 않았습니다.

## Citation 표시 정리

- 검색 결과, Gemini 근거, DB의 `response.sources`는 그대로 유지합니다.
- 직원 화면에서 Citation을 그리기 직전에 질문·답변·체크리스트 별칭과 원문을 비교합니다.
- Renal biopsy처럼 별칭이 원문에 직접 있는 source가 있으면 해당 source를 우선하고, 일반적인 `검사·준비·환자·간호·확인` 표현만 겹치는 후보는 숨깁니다.
- 직접 관련 source를 확실히 찾지 못하면 기존 전체 Citation을 표시하여 근거가 모두 사라지지 않게 했습니다.
- 같은 PDF와 같은 페이지 중복 제거 규칙은 계속 적용합니다.

## 실제 화면 확인

- 저장된 Renal biopsy 답변을 로컬 fixture로 복제해 Gemini 신규 호출 없이 Docker Chromium에서 확인했습니다.
- DB에 저장된 source는 4개로 유지됐고 화면에는 p.56 Citation 1개만 표시됐습니다. p.8·p.14·p.30은 화면에 표시되지 않았습니다.
- 플로팅 작업창은 390×520px로 열렸고, 510×600px로 크기 조절한 뒤 최소화·복원해도 크기·위치·체크 상태가 유지됐습니다.
- 화면 밖 이동, overlay 없음, 닫기, 모바일 하단 패널과 내부 스크롤을 확인했습니다.
- Citation PDF 원문 보기를 여는 동안 체크리스트가 유지됐고 원본 PDF 요청은 HTTP 200이었습니다.

## 보호한 기능

- Automatic, AgentHandler, rag-memory, BM25, ChromaDB, Gemini 답변, 체크리스트 자동 추출, 체크리스트 JSON, 원본 PDF API와 본문 벡터는 변경하지 않았습니다.

## 이어서 보완한 내용

이전 작업이 중간에 멈춰, 같은 날 코드 확인·보완·재검증을 이어서 진행했습니다.

- 크기 조절을 오른쪽 아래 모서리뿐 아니라 오른쪽 가장자리(너비만)와 아래 가장자리(높이만)에서도 할 수 있게 했습니다.
- `검사 전`·`검사 후` 접힘 상태를 작업창이 보관하도록 바꿔, X로 닫았다가 같은 화면에서 다시 열어도 위치·크기·체크 상태와 함께 유지됩니다. 관리자용 보기 모달은 기존처럼 따로 동작합니다.
- 이 작업일지를 작업일지 목차에 등록했습니다.

## 재검증 결과

- 저장된 Renal biopsy 답변을 직원 계정의 임시 검증 대화로 복제하고, 새 질문의 답변은 브라우저 안에서 모의 스트림으로 재현했습니다. Gemini 등 외부 서비스는 호출하지 않았고, 검증이 끝난 뒤 임시 대화는 삭제했습니다.
- Docker 안의 Chromium으로 PC 38개, 모바일 6개, 모두 44개 항목을 확인했고 전부 통과했습니다.
  - 처음 크기 390×520px, 배경 가림 없음, 채팅 입력창 클릭 가능
  - 제목 표시줄 이동, 왼쪽·오른쪽·아래쪽 화면 밖 이동과 전부 화면 밖 이동, 자동 위치 복귀 없음
  - 모서리·오른쪽·아래 크기 조절, 최소 크기, 작은 크기에서 내부 스크롤
  - 최소화 후 다시 펼쳐도 위치·크기·체크·접힘 상태 유지
  - 새 질문 3회(답변 생성 중과 완료 후 모두)에도 작업창·위치·크기·체크 상태 유지
  - Citation PDF viewer(원본 PDF HTTP 200)를 연 상태에서 체크, 채팅 스크롤, 입력이 모두 가능
  - X를 누를 때만 작업창이 닫힘
  - 모바일: 좌우·하단 16px 패널, 내부 스크롤, 최소화·복원·닫기, 배경 가림 없음
- Citation 결과
  - DB에 저장된 source는 p.56·p.8·p.14·p.30 4개 그대로입니다.
  - 기존 답변, 답변 생성 중, 답변 완료 후, 새로고침 후 모두 `출처 1 · 검사 및 시술(26.04.07).pdf · p.56` 한 개만 표시됐습니다.
  - 여러 페이지가 실제 근거인 검증 예시에서는 p.56·p.57 두 개가 유지됐고, 같은 p.57 중복은 하나로 합쳐졌습니다.
  - 직접 근거를 찾지 못한 예시에서는 저장된 Citation 전체를 표시했습니다.
- 프런트엔드 테스트 72개 통과, 체크리스트·원본 PDF 서버 테스트 20개 통과, rag-memory source 테스트는 Docker 안에서 22개 통과, Docker production build 성공.

## 남은 제한

- 모바일에서 작업창을 펼치면 화면 아래쪽 채팅 입력창을 가립니다. 입력할 때는 작업창을 최소화하면 됩니다.
- 여러 체크리스트가 생기면 작업창 위치·크기를 서로 같이 사용합니다. 현재 체크리스트는 Renal biopsy 하나입니다.
