# 퀴즈 세트 삭제

## 요청

- 퀴즈 세트 옆 [삭제] 버튼과 "정말 삭제할까요?" 확인창.
- 공개 중인 세트는 먼저 사용중지해야 삭제 가능.
- 직원 풀이 기록이 있으면 확인창에 몇 명의 기록이 같이 지워지는지 표시.
- DB 구조 변경 없음. 3001에서 빈 세트 하나 삭제 확인 후 release-admin-9에 commit·push. main 미변경.

## 변경

- 서버: 세트 삭제 확인 경로(문제 수·풀이 기록 수·오답노트 수·직원 수)와 삭제 경로 추가. 공개 세트는 확인·삭제 모두 거절. 확인창에서 본 개수와 다르면 지우지 않음.
- 세트 삭제는 문제 [삭제]와 같은 방식: 세트의 문제와 그 직원 풀이 기록·오답노트를 지우고, 그 문제가 들어 있던 풀이 회차는 남은 문제로 점수를 다시 맞춤(남은 문제가 없으면 회차 삭제). 퀴즈가 아닌 자료는 건드리지 않음. 공통 처리 함수로 정리함.
- 화면: 세트 줄에 [삭제]. 공개 세트는 버튼이 꺼지고 "삭제하려면 먼저 상태를 사용중지로 바꿔 주세요" 안내. 확인창에 "정말 삭제할까요?", 세트·문제 수, 기록이 있으면 "직원 N명의 풀이 기록 M건도 같이 지워져요" 표시.
