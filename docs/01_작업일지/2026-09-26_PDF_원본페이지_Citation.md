# 2026-09-26 · PDF 원본 페이지 Citation

## 변경 내용

- 관리자 화면에서 새 PDF를 등록할 때 검색용 문서 처리 전에 원본 PDF를 별도 보관 영역에 한 번 저장하도록 연결했습니다.
- 기존 문서 목록의 PDF 행에 `원본 PDF 연결` 기능을 추가해, 재업로드나 재색인 없이 원본 보기용 PDF만 연결할 수 있게 했습니다.
- 직원 화면에는 내부 문서 ID나 실제 경로를 보내지 않고, 저장소 비밀값으로 서명한 안정적인 공개 참조값만 전달합니다.
- 로그인과 workspace 권한을 확인하는 PDF 조회 API를 추가했고, PDF 형식 검사·경로 추측 방지·단일 HTTP Range 요청을 지원합니다.
- Citation의 `근거 원문 보기`는 원본이 있으면 브라우저 PDF viewer에서 실제 출처 페이지를 열고, 원본이 없거나 불러오지 못하면 기존 excerpt와 직접 연결 이미지를 표시합니다.
- 원본 PDF 페이지가 표시될 때는 페이지 안의 이미지와 별도 관련 이미지가 중복되지 않도록 Citation의 별도 이미지 영역을 숨깁니다.

## 기존 문서

- 현재 workspace의 원본 PDF는 `2026실무지침서 (26.7).pdf` 461쪽과 `검사 및 시술(26.04.07).pdf` 82쪽입니다.
- 두 문서는 과거 처리 과정에서 원본 파일이 보존되지 않았으므로 관리자 화면에서 원본을 한 번 연결해야 합니다.
- 연결 작업은 기존 문서 ID, page JSON, ChromaDB, BM25, 이미지 설명을 변경하지 않습니다.

## 보안

- PDF 파일명과 저장 경로에는 사용자가 보낸 경로를 사용하지 않고 내부 문서 식별값의 SHA-256 저장 키를 사용합니다.
- PDF 본문과 내부 경로는 문서 화면이나 로그에 기록하지 않습니다.
- 로그인하지 않았거나 해당 workspace에 접근할 수 없는 사용자는 PDF를 받을 수 없습니다.
