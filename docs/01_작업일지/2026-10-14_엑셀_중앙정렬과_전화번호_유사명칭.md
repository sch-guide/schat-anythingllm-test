# 엑셀 가운데 정렬과 전화번호 유사명칭

## 표시 문제의 원인과 보완

통합전화번호부는 축소한 표를 왼쪽에 놓아 빈 공간이 오른쪽에만 남았습니다. 축소 표의 좌우 여백을 자동으로 같게 두며, 표가 화면보다 넓을 때는 왼쪽 끝부터 스크롤할 수 있게 합니다.

진료지원간호팀 원본은 실제 내용보다 훨씬 큰 서식 전용 범위가 저장되어 있었습니다. 23열·999행 전체를 표의 크기로 계산하던 것을, 실제 값과 값이 있는 병합 범위의 끝을 기준으로 보기 범위만 5열·183행으로 줄였습니다. 앞/중간 빈칸·병합 영역은 유지하고, 원본 파일·검색용 추출·검색 자료는 바꾸지 않았습니다. 통합전화번호부도 후미 서식 전용 행을 제외하면 실제 범위는 4열·336행입니다.

큰 글꼴의 표는 최소 45%까지, 일반 글꼴은 기존 65% 하한으로 너비에 맞춥니다. 그래도 넓으면 내부 가로·세로 스크롤을 제공합니다. 긴 문구는 자동 줄바꿈하여 오른쪽 번호 칸으로 넘치거나 잘리지 않게 하고, 원래 행 높이는 최소 크기로 유지하되 내용에 따라 화면에서 늘어날 수 있습니다. 원본의 열 너비·병합·정렬·글꼴·색·테두리·글자 형광펜·다운로드 금지는 유지합니다.

## 전화번호 유사명칭

기존 동의어의 `termAlternatives` 함수를 전화번호부 전용으로 재사용합니다. 이번에 확인한 비뇨 계열 표현만 명시적으로 묶었습니다. 발음이 비슷하다는 이유로 임의의 부서명까지 넓히거나 모든 문서의 단어를 치환하지 않습니다.

- 비뇨의학과 번호
- 비뇨기과 번호
- 비뇨의학센터 번호
- 비뇨기 번호
- 비뇨기과번호

실제 등록 전체 자료로 모두 관련 전화번호부·진료지원간호팀 자료를 선택하고, 원문 내선번호 2275·2875·2376을 찾는 것을 확인했습니다. 다른 부서·별도로 한정한 소아 명칭은 일반 비뇨 명칭으로 넓혀 매칭하지 않는 검사와 일반 임상 질문에 확장하지 않는 검사를 추가했습니다. 기존 동의어 관리 화면·DB는 바꾸지 않았습니다.

전화번호부의 단어 일치와 근거 판정만 같은 명칭 묶음을 사용합니다. BM25/Hybrid 점수 공식·검색 비율·후보 수·Vector·Chroma·Gemini 구조는 그대로입니다. 관리자 프롬프트·재색인·원본 삭제·운영 배포는 없습니다.
