# 체크리스트 관리 삭제 기능

## 요청
체크리스트 관리에서 체크리스트를 삭제할 수 없음. 삭제할 수 있게 구현.

## 원인
관리자 화면·서버 모두 삭제 기능이 없었다(상태 변경: 검토 필요·공개·숨김, 내용 수정만 있음).

## 구현
- 체크리스트 관리 각 항목에 [삭제] 버튼. 확인창: 직원·관리자 화면에서 모두 사라짐, 같은 문서를 다시 읽어도 되살아나지 않음, 되돌릴 수 없음, 잠시 안 보이게만 하려면 '숨김' 사용.
- 서버 `DELETE /workspace/:slug/checklists/:checklistId`: 관리자·매니저만, 같은 작업공간 문서의 체크리스트만. 삭제 기록(event_logs `schat_checklist_deleted`, 체크리스트 번호·쪽만) 남김.
- 저장 방식: 파일을 지우지 않고 그 자리에 "삭제됨" 표시만 남김(제목·항목 내용은 남기지 않음). 같은 문서를 다시 읽는 자동 생성이 이 자리를 덮어쓰지 않아 되살아나지 않음. 목록·조회·직원 화면·저장공간 점검 체크리스트 수에서 제외. 등록 안 된 문서를 지울 때는 표시 파일도 함께 지워짐.
- 새 판(같은 이름 업데이트로 문서 번호가 바뀜)에서 같은 쪽 체크리스트가 다시 읽히면 "검토 필요"로만 들어옴(자동 공개 안 됨).
- 수정 파일: `server/utils/documentChecklists/repository.js`, `server/endpoints/workspaces.js`, `server/utils/schatAdmin/storageCleanup.js`, `frontend/src/models/checklist.js`, `frontend/src/pages/SchatAdmin/sections/Checklists.jsx`, 관련 자동 검사.

## 검증
- 서버 자동 검사 183개, 화면 자동 검사 259개 통과.
- 3001 반영 전 백업 `3001-checklist-delete-20261014`(불일치 0), 이미지 `schat-admin-build:checklist-delete-20261014`.
- 가상 시험 체크리스트 2개로 확인: PC에서 확인창 [취소] → 남음, 휴대폰 폭에서 [확인] → 삭제. 다시 열면 전체 81 → 80, 검색 0건. 삭제 후 화면에서 사라지기까지 약 0.9초. 다른 체크리스트 80개에 삭제 버튼 표시.
- 기존 병원 체크리스트는 삭제하지 않음. 시험 표시 파일·테스트 계정 정리 후 체크리스트 80개·파일 80개.
- 운영 서버 변경·commit·push·tag 없음.
