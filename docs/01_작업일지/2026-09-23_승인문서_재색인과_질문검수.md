# 승인 문서 재색인과 실제 질문 4건 검수

## 무엇을 했나요?

- 기존 ChromaDB와 계정·대화 데이터베이스를 먼저 백업했습니다.
- 승인된 논리 문서 1개에 속한 페이지 자료 100건만 Gemini 임베딩으로 다시 색인했습니다.
- 새 색인이 모두 성공한 뒤에만 기존 운영 색인과 교체했습니다.
- Docker를 다시 시작해 데이터가 유지되는지 확인했습니다.
- 일반 직원 계정으로 승인된 질문 4건만 실제 실행했습니다.

개인정보 가능 패턴 1건은 사용자가 지침서 예시값이라고 확인했습니다. 값 자체는 문서와 로그에 남기지 않았습니다.

## 재색인 결과

| 확인 항목 | 결과 |
|---|---|
| 대상 | 승인된 논리 문서 1개, 페이지 자료 100건 |
| 새 청크 | 116개 |
| 청크 규칙 | 약 900자, 120자 겹침 |
| Gemini 임베딩 요청 | 100회, 자동 재시도 0회 |
| 페이지 정보 | 116개 청크 모두 보존 |
| 항목명 | 원문에 명시된 63개 청크에 보존 |
| 문서명 | 116개 청크 모두 보존, 깨진 대체문자 0건 |
| 직원 계정 | 2개 유지 |
| 기존 대화 | 재색인 전 14건 유지 |
| 재시작 | ChromaDB 116개 벡터 유지 |

Gemini 응답에 실제 과금 토큰 수가 포함되지 않아 실제 청구액은 확인할 수 없었습니다. 로컬 추정치는 약 54,489토큰이며, 유료 표준 단가로 계산하면 약 15원 수준입니다. 무료 등급이면 0원일 수 있으므로 최종 청구액은 Gemini 사용량 화면에서 확인해야 합니다.

## 현재 판단

백업, 원자적 교체, 재시작 후 데이터 보존과 근거 부족 중단은 정상입니다. 다만 `수혈 종류` 검색 범위와 `진정 절차` 답변의 유용성은 아직 개선이 필요하므로, 전체 직원 대상 시범운영보다는 제한된 검수 단계가 적절합니다.
