# 엑셀 원본 표 보기

사용자가 변환된 근거 텍스트 대신 엑셀 원문 형태를 요청했습니다. 기존 엑셀 처리기는 파일을 읽은 뒤 업로드 임시 파일을 지우고 있었으며, PDF처럼 원본을 별도로 보관하지 않았습니다. 이미 등록된 엑셀의 원본을 저장 텍스트만으로 복원했다고 표시하지 않습니다.

## 추가한 내용

- 새로 등록한 `.xlsx`·`.xls` 원본을 `server/storage/original-spreadsheets/`에 보관합니다. 실제 원본과 보관 정보는 Git·이미지 전체 빌드 대상에서 제외합니다.
- 원본을 덮어쓰지 않고, 파일 이름을 저장 경로로 쓰지 않습니다. 작업공간에 등록된 문서의 보호된 참조값으로만 로그인 후 접근합니다.
- PC·모바일 출처 화면에 시트 선택·원래 행/열·병합 셀·100행 단위 표 보기와 원본 다운로드를 추가합니다. 외부 문서 서비스·AI로 원본을 보내지 않습니다.
- 형광 표시는 출처의 시트와 같은 시트에서, 인용문에 적힌 행과 원본 행의 셀 값·열 순서·빈칸이 일치할 때만 적용합니다. 다른 시트의 같은 행이나 단축/내선 번호가 바뀐 행은 표시하지 않습니다.
- 글꼴·색·그림은 원본과 다를 수 있고, 앞 80열까지 미리보기합니다. 20MB를 넘는 원본은 표 미리보기를 제한하고 다운로드를 제공합니다. 수식·매크로는 실행하지 않습니다.
- 과거 엑셀은 원본이 없어 새 이름으로 다시 등록해야 한다고 안내합니다. 기존 자료·과거 출처를 새 파일에 임의로 연결하지 않습니다.

## 검증

- 원본 보관·소속 확인·잘못된 참조 차단·기존 파일 덮어쓰기 방지, 인용 식별, 시트별·행별 강조, 실제 표 렌더링 관련 검사 12개 통과.
- 네트워크가 차단된 임시 컨테이너에서 가짜 실제 `.xlsx`·`.xls`를 생성해 변환→원본 보관→표 미리보기까지 검사 2개 통과. 앞자리 0·여러 시트·빈 시트·직접 첨부 경로를 확인했습니다.
- 기존 PDF·출처·텍스트 화면 렌더링 검사 20개 통과. 관련 고유 검사 합계 34개입니다.
- 코드 검토에서 다른 시트의 같은 행, 값은 같지만 번호 종류 순서가 뒤바뀐 인용이 잘못 표시될 수 있는 문제를 발견해 재현한 뒤 보완했습니다.
- 화면 빌드 성공. 실제 병원 엑셀 재등록·실제 AI 답변 시험은 하지 않았고 API 비용은 0원입니다. 브라우저 연결이 없어 직접 클릭 확인은 하지 못했습니다.

## 반영 범위

- 브랜치 `feat/excel-original-view-20261013`. 운영 서버·DB 구조·검색 설정·관리자 프롬프트는 변경하지 않습니다. Git 커밋·push도 하지 않습니다.
- 현재 실행 코드를 기준으로 필요한 원본 보관·접근·출처 연결·화면만 반영합니다. 다른 미완료 PDF 실험 서버 코드는 제외합니다.
