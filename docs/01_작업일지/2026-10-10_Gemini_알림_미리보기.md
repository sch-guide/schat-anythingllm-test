# Gemini 알림 미리보기

- 사용자 승인에 따라 가짜 데이터 전용 독립 HTML을 생성함.
- `docs_view/gemini-alert-preview.html`을 파일 탐색기에서 더블클릭하여 브라우저로 열 수 있음. 실제 Docker 3001 반영은 필요하지 않음.
- 한도 소진·일시적 혼잡·예산 80%·95%·계산 불가·정상 복구·기타 오류를 선택하여 확인함.
- 관리자 경고와 예산 요약은 기존 React 표시 코드를 재사용함. 직원 안내는 기존 오류 감시기의 가짜 오류 처리 결과를 사용함.
- 주변 배치는 설명용이며 실제 관리자 전체 화면과 동일한 화면은 아님. 예시 금액·시각을 명확히 표시함.
- 실제 API 호출, DB 변경, 예산 저장, Docker 변경, commit/push/tag 없음.
- 생성 원본: `frontend/scripts/gemini-alert-preview.mjs`. Node로 실행하면 HTML을 다시 생성함. 생성 HTML은 직접 수정하지 않음.
- 네트워크·저장소 객체가 없는 테스트 환경에서 7가지 선택 전환과 표시를 검증하여 1개 테스트를 통과함. HTML의 보안 정책도 외부 연결을 차단함.
- 실제 브라우저 육안 검증은 별도로 필요함.
