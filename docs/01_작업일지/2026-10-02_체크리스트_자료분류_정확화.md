# 체크리스트 자료 분류 정확화

## 기존 문제

- 관리자 자료 필터가 원본 PDF 이름을 먼저 사용해 혼합 자료 안의 수술형 체크리스트를 검사 및 시술로 표시할 수 있었음.
- 예전에 저장한 체크리스트에는 `templateKind`가 없어 파일명만으로 분류되는 경우가 있었음.
- 수술 자료의 일부 페이지는 일반 검사표 형식을 사용해 추출 형식만으로도 수술 여부를 판단하기 어려웠음.

## 변경 내용

- `수술 전·수술 후` 구역과 수술 전용 준비 항목을 현재 수술 추출기 기준으로 확인함.
- 저장된 `templateKind`가 있으면 함께 사용함.
- 수술 구조가 확인되면 원본 PDF 이름이 검사 및 시술이어도 수술로 표시함.
- 수술 자료 안에서 일반 검사표 형식을 사용한 페이지는 자료 종류를 보조 근거로 사용함.
- 검사·시술 또는 수술로 안전하게 확인되지 않으면 기타로 표시함.
- 체크리스트 JSON, 제목, 내용, 공개 상태와 원본 PDF 연결은 변경하지 않음.

## 현재 로컬 분류

- 검사 및 시술 76개로 확인함. 같은 날 후속 수정에서 `3Position BP` 1개를 기타에서 검사 및 시술로 이동함.
- 수술 75개로 확인함.
- 기타 0개로 확인함.
- 공개 57개와 검토 필요 94개 상태가 그대로 유지됨.
- 골조직검사, 화학적 혈관 성형술, CS 심장혈관 흉부외과, 하지 정맥류는 수술로 확인함.
- 기관지내시경 BFS는 검사 및 시술로 확인함.

## 검증

- 잘못된 분류를 먼저 실패 테스트로 확인한 뒤 수정함.
- 서버 체크리스트 관련 테스트 46개를 통과함.
- 관리자 상태 필터와 자료 필터 동시 사용 테스트를 통과함.
- 저장 파일을 읽기만 했으며 운영 데이터와 로컬 체크리스트 원본을 수정하지 않음.
- RAG, Citation, BM25, Vector, Hybrid, ChromaDB를 변경하지 않음.

## Git

- commit, push, tag를 실행하지 않음.

## 3Position BP 후속 수정

- 제목 또는 별칭이 `3Position BP`, `3 Position BP`, `three position BP`, `three-position BP`와 일치하면 검사 및 시술로 표시함.
- 기존 수술 판정을 먼저 유지하고, 위 이름과 정확히 일치하는 항목만 처리함.
- 기존 151개 중 해당 1개의 표시 분류만 달라졌음을 확인함.
- 전체 저장 파일의 SHA-256 값을 비교해 내용·공개 상태·원본 연결이 바뀌지 않았음을 확인함.
- 표기 차이와 오인 방지 검사 및 관련 테스트 17개를 통과함.

## 후속 수정 Git 실행 여부

- commit, push, tag를 실행하지 않음.
