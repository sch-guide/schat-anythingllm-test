# release-admin-9 공지·퀴즈 개선

## 승인 범위와 현재 위치

- 5eadc625에서 release-admin-9를 생성함. 기존 다른 미커밋 변경은 보존하고 선별 커밋함.
- 공지: 길이와 관계없이 약 50px/초로 반복 이동, 마우스/누르는 동안 멈춤과 움직임 줄이기 유지, 브랜드 미리보기 동일.
- 일반 퀴즈 삭제: 삭제 상태로 보관하고 직원의 과거 풀이·점수·오답노트는 유지. 기존 물리 삭제 경로는 연결된 답변·오답노트를 함께 지우므로 사용자가 보존 방식 승인함.
- 별도 초기화: 관리자 확인·직접 입력 후에만 풀이·점수·오답노트와 삭제/이전 문서 문제를 완전 삭제. 현재문서 초안/중지 문제도 보존함. 다른 자료와 기존 백업은 변경하지 않음.
- 실제 기록 초기화 금지, 가짜 격리 기록만 검사. Gemini 호출·DB 구조 변경 없음.
- 순서: 공지 → 일반 삭제/필터 → 3001 백업·반영·검사·push → 수동 초기화 → 새 백업·반영·검사·push.
- 현재: 공지 구현 진행 중. 아직 새 기능 배포·push하지 않음.

## 일반 삭제의 격리 DB 확인

- 실제 자료 폴더를 연결하지 않고 외부망을 차단한 일회용 Docker에 기존 migration으로 빈 SQLite를 만들었음. 가짜 문제 2개와 답변 2개, 풀이 1개, 오답노트 2개를 넣고 일반 삭제를 실행함.
- 관리자 목록에서 문제는 사라지고, 문제의 연결 자료·풀이·50점 기록·오답노트는 모두 그대로였음. 가짜 계정·문서·대화도 전후 동일함.
- 해당 DB는 일회용 컨테이너 내부에만 만들었으며 컨테이너 종료와 함께 정리됨. 3001의 실제 직원 기록에는 초기화·삭제를 실행하지 않음.
- 이 결과는 서버 자료 처리 확인임. 관리자 화면·권한 연결 검사 및 최종 커밋 이후 재검사는 다음 순서임.
