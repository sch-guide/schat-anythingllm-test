# 안전 검사 저장소 내부 독립 배포

## 변경 내용

- 외부 `sch-guide-ai/src`, `sch-guide-ai/tools`에서 실제 안전 검사에 필요한 파일만 `schat-core/src`, `schat-core/tools`로 복사했습니다.
- 복사 대상은 안전 평가 import 폐쇄 집합과 prompt YAML 두 개로 제한했습니다.
- `.env`, `__pycache__`, `.pyc`, DB 및 데이터 파일은 복사하지 않았습니다.
- Docker Compose의 안전 검사 마운트를 저장소 내부 경로로 변경했습니다.
- 외부 원본은 이름 변경·이동·삭제 없이 그대로 보존했습니다.

## 보안 확인

- `.gitignore`에서 `schat-core/**/.env*`를 제외하도록 명시했습니다.
- `settings.py`는 환경변수와 `.env`를 읽는 코드만 포함하며 비밀 값 자체는 포함하지 않습니다.
- API key, password, secret, token의 하드코딩 값 패턴과 Google/OpenAI 키 형태를 검사했으며 발견되지 않았습니다.

- 외부 원본과 복사 파일 13개의 SHA-256 일치
- safety evaluator 회귀 테스트 51개 통과
- Docker 이미지 재빌드 성공
- `schat-web`, `schat-chromadb`, `schat-safety-evaluator` 모두 healthy
- 실행 중 safety evaluator의 실제 마운트가 저장소 내부 `schat-core`만 가리키는 것을 확인
