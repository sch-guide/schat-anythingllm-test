# 이용 가이드와 비밀번호 만들기

## 1. FAQ가 직원 화면에 안 보였던 이유

- FAQ는 정상 저장되어 있었고, 관리자가 등록한 1건도 `직원에게 보이기(승인)` 상태였습니다.
- 그러나 직원은 문제 신고 화면에서 제목·내용이 키워드와 맞을 때만 FAQ를 볼 수 있었습니다.
  - 직원용 FAQ 목록 API와 화면·메뉴가 아예 없었습니다.
  - 권한 문제는 아니었습니다.

## 2. 이용 가이드(직원 화면)

- 왼쪽 사이드바 `+ 새 대화` 아래에 `이용 가이드` 메뉴를 추가했습니다. 모든 직원이 볼 수 있습니다.
  - 아이콘은 흰 말풍선 안의 `?`이고, 테두리는 SCHAT 파란색입니다. 다크모드에서도 흰 말풍선에 파란 테두리를 유지합니다.
- 화면 구성
  - 제목 `이용 가이드`, 설명 `필요한 해결 방법을 빠르게 찾아보세요.`
  - 검색창 `해결 방법 검색`: 제목·문제 상황·키워드·해결 방법을 검색합니다. AI 호출은 없습니다.
  - 분류 버튼 `전체`와 실제 항목이 있는 분류들. 분류는 문제 신고 종류와 같습니다.
  - 목록은 Q/A 접이식입니다. 제목을 누르면 해당 답만 열립니다.
- 답 아래에 `도움이 되었나요?`, `도움이 됐어요`, `해결되지 않았어요 · 문제 신고` 버튼이 있습니다.
  - `해결되지 않았어요`를 누르면 기존 문제 신고 창이 열립니다.
  - 신고에는 이용 가이드 항목의 id와 제목만 연결됩니다. 대화 내용은 첨부하지 않습니다.
- 관리자가 `직원에게 보이기`를 켜고 저장하면 바로 보입니다. 재색인·Gemini·서버 재시작이 필요 없고, 검색 문서(RAG)와 섞이지 않습니다.
- 숨김 항목과 관리자용 정보(원본 신고, 통계)는 직원에게 보내지 않습니다. 항목이 없으면 "등록된 이용 가이드가 없습니다."가 표시됩니다.
- 문제 신고 중 관련 도움말 자동 제안은 그대로이며, 같은 FAQ 데이터를 씁니다.

## 3. 관리자 FAQ 관리

- 분류는 문제 신고 종류 목록에서 고릅니다.
- 항목마다 조회 수, `도움이 됐어요` 수, `해결되지 않았어요` 수를 보여 줍니다. 누가 눌렀는지는 기록하지 않습니다.
- 문제 신고 상세에 `관련 이용 가이드`가 표시됩니다.

## 4. 비밀번호 만들기

- 로그인 화면 비밀번호 아래에 `처음 사용하시나요? 비밀번호 만들기` 링크를 추가했습니다.
  1. 부서·사번·이름을 입력하면 등록되었고 비밀번호가 아직 없는 직원인지 확인합니다.
  2. 맞으면 새 비밀번호와 확인을 입력해 만듭니다.
- 이미 비밀번호가 있으면 "이미 비밀번호가 설정된 계정입니다. 기존 비밀번호로 로그인해주세요."가 나옵니다.
  - 정보가 맞지 않거나 사용중지된 계정은 로그인과 같은 일반 문구만 보입니다.
- 반복 시도 방어: 같은 IP나 같은 사번으로 10분 안에 10번 실패하면, 10분 동안 로그인·비밀번호 만들기가 막힙니다.
- 관리자 비밀번호 초기화, 임시비밀번호 폐지, 기존 관리자 비밀번호 유지는 앞선 변경 그대로입니다.
