# 출처 하이라이트를 실무지침서에만 적용 — 2026-10-11

## 사용자 요청과 변경

실무지침서를 제외한 검사 및 시술·수술 등은 형광 표시가 필요 없다는 요청을 반영했다. PC·모바일 PDF 표시 단계에서 문서명에 ‘실무지침’이 포함된 경우에만 기존 직접 근거 텍스트를 강조 대상으로 전달한다. ‘실무 지침’처럼 띄어쓴 이름도 허용한다. 문서명이 없거나 다른 문서이면 원문만 표시한다.

출처의 원본 evidenceQuotes·metadata와 출처 개수/선택·검색·답변 생성은 변경하지 않았다. 원문 PDF 페이지 이동과 가로 폭 맞춤은 유지한다. 실무지침서도 확인된 직접 근거가 있을 때만 표시한다.
