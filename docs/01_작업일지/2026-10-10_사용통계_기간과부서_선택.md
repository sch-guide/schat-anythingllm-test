# 사용 통계 기간·부서 선택

## 목적과 사용 방법

- 기존 파트 테스트 기록을 삭제하지 않고 두 부서 시범운영 실적을 구분하도록 구현함.
- 관리자 사용 통계에서 기존 기간 버튼 또는 날짜 직접 선택을 고르고 대상 부서를 선택한 뒤 조회함.
- 시작일과 종료일은 한국 시간 기준으로 모두 포함하며 최대 366일을 조회함.
- 여러 부서를 함께 선택할 수 있으며, 선택하지 않으면 전체 부서를 조회함.
- 적용 기간과 대상 부서를 결과 위에 표시함.

## 집계와 보호

- 질문 수·검색 실패·근거 없음 응답·문서 인용·부서별 사용량·토큰 합계에 같은 조건을 적용함.
- 토큰은 선택한 부서들의 저장된 입력·출력 토큰 합계임. 부서 하나를 선택하면 해당 부서 합계를 확인함. 기록이 없는 토큰은 추정하지 않음.
- 부서는 질문 당시가 아닌 현재 계정의 소속 기준임. 계정 삭제·부서 이동 이력이 있으면 과거 소속을 정확히 재구성하지 못함.
- 기존 소수 인원 보호를 유지함. 선택 부서 중 기간 내 사용자가 1~4명인 부서가 있으면 전체 결과를 숨김. 사용 기록이 없는 경우에는 0건으로 표시함.
- 질문 목록은 최근 90일 이내 최대 100건만 표시함. 이전 기간은 질문 전문 없이 건수와 토큰 등을 집계함.
- 잘못된 날짜·미래 날짜·존재하지 않는 부서는 거부함. 조회 조건마다 임시 저장 결과를 구분함.

## 검증 범위

- 통계·관리자 화면·조회 요청 관련 자동 테스트 28개를 통과함. 배포용 화면 빌드를 통과함. 빌드 도구에서 파일 크기·모듈 분리 관련 경고가 출력됨.
- 문서 화면을 재생성하고 문서 분리 검사 11개와 git diff --check를 통과함. 생성 도구의 기존 문자열 이스케이프 경고가 출력되나 생성과 검사는 정상 종료함.
- 화면 검사 도구의 React 연결 누락을 보완함. 제한 환경에서 의존성 읽기가 막힌 검사는 권한 허용 후 재실행하여 통과함.
- 가상 자료로 한국 날짜 경계, 두 부서 합산, 다른 부서 제외, 토큰 합계, 잘못된 조건, 소수 인원 숨김, 오래된 질문 보호, 조건별 임시 저장 분리를 검사함.
- 로컬 구현이며 연결 가능한 브라우저가 없어 실제 Docker 화면 클릭 검증은 하지 못함. 운영 반영은 별도 진행함.
- 이후 로컬 Docker 웹 이미지를 빌드하고 웹 컨테이너만 교체함. 3001 응답과 제공되는 화면 파일의 날짜·부서 선택 문구, 서버 코드 일치를 확인함. 세 컨테이너 모두 healthy를 확인함.
- 재시작 전후 DB 존재와 문서·원본·이미지·체크리스트 폴더 항목 수가 동일함을 확인함. 기존 storage 연결을 유지하며 ChromaDB와 안전 검사 컨테이너는 재시작하지 않음. 실제 로그인 후 클릭 검증은 미수행함.
- 검색·Gemini 호출·원본 PDF·체크리스트·운영 데이터는 변경하지 않음. commit·push·tag는 수행하지 않음.
