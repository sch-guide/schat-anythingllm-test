# 표 표시와 절차 근거 마무리

## 해결한 문제

### 수혈 종류

PDF 표가 한 줄로 붙어 저장돼 직원 화면에서 읽기 어려웠습니다. 실제 표에서 확인되는 반복된 셀 경계만 사용해 다음 네 종류가 빠짐없이 구분되도록 했습니다.

- 적혈구 제제
- 혈소판 제제
- 신선동결혈장
- 동결침전제제

실제 직원 질문에서는 Gemini 답변이 안전검사를 통과했고, 네 종류만 자연스러운 문장으로 표시됐습니다. 표에 없는 내용은 추가되지 않았습니다. 출처는 문서명, p.114, 혈액 제제의 종류 항목으로 표시됐습니다.

### 진정 절차

기존에는 가장 높은 검색 결과 한 건만 안전검사에 전달되어 답변이 한 문장으로 끝났습니다. 절차형 질문일 때만 같은 문서에서 바로 이어지는 같은 대상의 절차 항목을 추가하도록 바꿨습니다.

이번 문서에서는 p.160의 진정 전 확인 항목과 p.161의 진정 중 기록 항목만 연결했습니다. 목적·규정·대상처럼 관계없는 항목과 떨어져 있는 소아 절차는 섞지 않았습니다.

실제 직원 질문에서는 두 단계가 포함된 Gemini 답변이 안전검사를 통과했고 두 페이지의 출처가 함께 표시됐습니다.

## 유지한 안전 원칙

- 숫자·단위·시간·속도·조건·금기·행위 검사를 완화하지 않았습니다.
- 기존 ChromaDB와 BM25 검색 구조를 유지했습니다.
- 재색인하거나 기존 데이터를 삭제하지 않았습니다.
- 답변에 내부 식별자를 표시하지 않았습니다.
- 각 질문은 Gemini에 한 번씩만 요청했고 자동 재시도는 0회였습니다.

## 확인 결과

- Python 안전검사: 38건 통과
- 검색·화면 관련 자바스크립트 검사: 40건 통과
- Docker 빌드 성공
- SCHAT 웹, ChromaDB, Python 안전검사 서비스 정상
- `수혈 종류 알려줘`: 안전검사 통과, Gemini 답변 표시, 대체 답변 미사용
- `진정 절차`: 안전검사 통과, Gemini 답변 표시, 대체 답변 미사용

제한된 직원 웹테스트는 계속할 수 있습니다. 이번 확인은 두 대표 질문에 대한 결과이므로 전체 병원 지침과 모든 질문에 대한 정식 운영 승인을 의미하지는 않습니다.
