# FAQ 삭제

- 위치: `SCHAT 관리자 설정 > 문제 신고 > FAQ 관리`에서 FAQ의 `수정`을 누르면 아래에 `위험 영역 > FAQ 삭제`가 나옵니다. 새 FAQ를 추가할 때와 목록 줄에는 나오지 않습니다.
- 확인창: "FAQ를 삭제하시겠습니까?"와 제목·분류·상태, 복구할 수 없다는 안내, `취소`·`삭제`가 나옵니다.
- 삭제 방식: 데이터베이스에서 완전히 삭제합니다.
  - 이용 가이드와 문제 신고의 관련 도움말에서 바로 사라집니다.
  - 이 FAQ와 연결된 문제 신고는 FAQ 제목을 따로 저장해 두어 그대로 남습니다.
  - 관리자 기록에는 FAQ 번호·분류와 삭제한 관리자만 남깁니다.
- 잠시 숨기려면 지금처럼 `직원에게 보이기(승인)`를 끄고 저장하면 됩니다.
- 권한: 관리자만 삭제할 수 있습니다. 로그인하지 않은 호출은 401로 거부됩니다.
- 확인
  - 실제 브라우저에서 확인용 FAQ를 새로 만들어 수정 → 위험 영역 → 확인창 → 취소 → 삭제 → 새로고침 후 미표시까지 확인했습니다.
  - 기존 FAQ 4개와 문제 신고는 건드리지 않았습니다.
  - 화면 테스트 123개, 서버 테스트 267개 통과. Docker 정상.
