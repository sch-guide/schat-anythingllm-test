# 관리자 "사용 통계" 화면

## 조사 결과

- **대화 기록:** `workspace_chats` 표에 저장됩니다.
  - 칸: 질문(`prompt`), 답변(`response`), 사용자(`user_id`), 대화방(`thread_id`), 시간(`createdAt`)
  - 답변 칸 안에 답변 글(`text`), 인용 출처 목록(`sources`: 문서 이름·쪽·목차), 토큰 사용량(`metrics`: 입력·출력 토큰, 모델)이 함께 들어 있습니다.
- **부서:** 사용자 표의 `department_id` → 부서 표 `schat_departments`로 이어집니다.
- **"근거 없음":** 따로 표시하는 칸은 없습니다. 답변 글이 "등록된 문서에서 확인되지 않습니다" 같은 문구로 나옵니다.
- **검색 결과:** 검색 결과가 없거나 부족했는지 따로 기록하지는 않습니다. 답변에 인용된 출처가 몇 건인지로 알 수 있습니다.
- **토큰:** 토큰 수는 이미 기록되고 있습니다(최근 답변 대부분).
- **결론:** 통계에 필요한 정보가 이미 저장돼 있어 **새 기록이나 DB 변경을 추가하지 않았습니다.**

## 화면 (`SCHAT 관리자 설정 > 사용 통계`)

기간은 오늘 / 최근 7일 / 최근 30일 / 최근 90일이고, 한국 시간 기준입니다.

1. **질문 수:** 전체 수, 날짜별 막대그래프, 시간대별 막대그래프
2. **많이 검색된 주제:** 답변에 인용된 지침 문서의 목차(없으면 쪽) 기준 상위 10개. AI로 분류하지 않습니다.
3. **많이 인용된 지침 문서:** 문서별 질문 수와, 그 기간에 한 번도 인용되지 않은 등록 문서 목록
4. **검색 실패 질문:** 답변에 인용된 근거가 **0건**인 질문
5. **근거 없음 응답:** 근거는 **1건 이상** 찾았지만 답변이 "확인되지 않는다"는 취지인 질문
   - 4와 5는 겹치지 않습니다.
   - 근거 0건에 "확인되지 않습니다"라고 답한 질문은 4에만 들어갑니다.
   - 인사처럼 문서가 필요 없는 질문도 근거 0건이면 4에 들어갈 수 있습니다.
6. **부서별 사용량:** 부서별 질문 수를 가나다순으로 보여줍니다. 그 기간 사용자가 5명 미만인 부서는 "인원이 적어 표시하지 않음"입니다.
7. **대략적인 AI 사용량:** 질문 수, 토큰 기록이 있는 답변 수, 입력·출력 토큰 합계. 금액은 계산하지 않습니다.

## 개인정보 보호

- 화면과 API 어디에도 이름·사번·계정이 없습니다. 개인별 목록·사용량·순위도 없습니다.
- 질문 원문은 **API가 응답을 만들 때** 다음을 `***`로 가립니다.
  - 주민등록번호 형식
  - 전화번호 형식
  - 6자리 이상 이어진 숫자(등록번호 등)
- 질문 원문 목록은 최근 90일까지만 보여주고, 각 목록은 최근 100건까지입니다.
- 기존 대화 기록을 지우는 기능은 만들지 않았습니다.
  - 오래된 기록을 지우려면 DB 백업 후 기간을 정해 `workspace_chats`에서 지우는 작업이 필요합니다.
  - 이 작업은 대화 기록 화면에도 영향이 있으므로 따로 결정이 필요합니다.

## 성능

- 통계는 관리자가 화면을 열 때만 DB에서 읽어 계산하고, 기간별로 5분간 캐시합니다.
- 채팅 흐름에는 아무것도 추가하지 않았습니다.
- 통계를 조회하는 동안 Gemini 호출은 0회였습니다(서버 기록으로 확인).
- **인덱스:** `workspace_chats` 표에는 시간 인덱스가 없습니다.
  - 지금(약 200건)은 문제없습니다.
  - 기록이 수만 건 이상 쌓이면 `createdAt` 인덱스 추가를 권합니다.
  - 기존 표에 손대는 일이라 이번에는 추가하지 않았습니다.

## 확인

- **실제 브라우저로 확인한 것**
  - 관리자 계정으로 7개 항목을 모두 확인했습니다(PC·모바일·다크모드).
  - 일반 직원 계정은 API 401(권한 없음)이고, 화면은 첫 화면으로 돌아갔습니다.
- **가짜 데이터로 확인한 것**
  - 가짜 등록번호·전화번호·주민번호가 `***`로 가려졌습니다.
  - 사용자 5명 이상인 부서만 수가 나왔습니다.
  - 확인 후 가짜 데이터(대화방 1개, 대화 7건)는 지웠습니다.
- **채팅 속도:** 채팅 경로에는 1부의 동의어 적용만 더해졌고, 단어 일치 검색 1회 약 11~15ms로 차이가 없었습니다.
- **자동 테스트:** 서버 301개, 화면 135개가 통과했습니다. Docker 빌드도 성공했습니다.
