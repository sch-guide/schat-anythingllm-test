# 직원 답변 표현 방식 개선

## 무엇을 바꿨나요?

검색 결과와 안전검사 기준은 그대로 두고, 안전검사를 통과한 답변을 직원이 읽기 쉬운 모양으로 정리했습니다.

- 종류 질문: 항목별 목록
- 절차 질문: 순서를 유지한 번호 단계
- 준비사항 질문: 체크리스트
- 비교 질문: 비교 항목별 목록
- 설명 질문: 짧은 핵심 답변과 추가 설명

## 안전성은 어떻게 유지했나요?

- Gemini가 만든 임상 문장은 기존 Python 안전검사를 먼저 통과해야 합니다.
- 화면 정리는 안전검사 통과 후에만 적용됩니다.
- 숫자·단위·시간·조건·금기·행위 표현은 바꾸지 않습니다.
- 안전검사에 실패한 원문 기반 대체 답변에는 새 서식을 적용하지 않습니다.
- 검색, ChromaDB, BM25, 필수 내용 검사와 대체 답변 정책은 변경하지 않았습니다.

## 어떻게 확인했나요?

실제 Gemini 호출 없이 가짜 응답으로 목록·번호·체크리스트·비교·설명 표시를 확인했습니다. 기존 Python 안전검사 전체도 다시 실행해 통과 여부를 확인했습니다.
