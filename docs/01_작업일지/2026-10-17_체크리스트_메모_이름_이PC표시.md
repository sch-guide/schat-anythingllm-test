# 체크리스트 메모 이름: 이 PC 화면은 원래 이름 (3001 반영)

- 날짜: 2026-10-17
- 요청: 환자정보에 "홍길동"을 쓰면 바로 "홍○동"으로 바뀜. 입력 중인 창, 새로고침, 로그아웃 후 별도 창에서는 적은 그대로 보이게.
- 상태: 3001 반영. GitHub·운영 미반영.

## 예전 동작

- 10-11부터 메모를 서버(계정)에 저장하면서, 자동 저장(입력 멈춘 뒤 0.8초) 때 화면 글자도 가린 이름으로 바꿈. 10-14 작업일지에서 정상 동작으로 확인했던 부분.

## 바뀐 동작

| 상황 | 보이는 이름 |
|---|---|
| 입력 중인 창 | 홍길동 |
| 같은 PC에서 새로고침·다시 열기 | 홍길동 |
| 로그아웃 후 이 PC에 남는 별도 창 | 홍길동 |
| 서버 저장 | 홍○동 (그대로) |
| 다른 PC에서 열기 | 홍○동 |
| 인쇄 | 홍○동 (그대로) |

- `checklistPersonalSession.js`: 서버로 보낼 때만 가림. 이 PC 원래 글자는 브라우저 저장소 `schat_checklist_names_v1:사용자:작업공간:체크리스트`에 24시간(서버 기한과 같음) 보관하고, 서버 값이 그 글자를 가린 값과 같을 때만 원래 글자로 보여 줌(다른 PC에서 고친 내용이면 서버 값). 기한 지난 보관본은 창을 열 때 지움.
- `checklistPopupSession.js`: 별도 창 PC 저장본에 원래 글자 보관, 로그아웃 후에도 가리지 않음.
- 개인정보 동의서 문구("이름은 가운데 글자를 가려 저장")는 서버 저장 기준으로는 그대로 맞음. 이 PC 브라우저에는 실명이 최대 24시간 남음(사용자 결정, 동의서는 바꾸지 않기로 함).
