# 체크리스트 다중 추출과 직원 출처 표시 개선

## 한눈에 보기

- 한 PDF 쪽에 좌우 또는 상하로 체크리스트 표가 여러 개 있으면 영역별로 나누어 각각 생성하도록 개선함.
- 같은 문서와 같은 쪽의 체크리스트도 서로 다른 ID와 파일로 저장해 덮어쓰지 않도록 개선함.
- 관리자 체크리스트 화면에 `검사 및 시술`, `수술`, `기타` 자료 필터와 자료 종류 표시를 추가함.
- 직원 답변·Citation·체크리스트·관련 이미지에는 쪽 번호를 표시하지 않고 문서명만 표시함.
- 내부 `page` 정보와 원본 PDF 이동 주소는 그대로 유지함.

## 검사 및 시술 자료 확인

- 현재 로컬 자료는 `검사 및 시술(26.04.07).pdf` 82쪽임.
- 관리자 체크리스트는 80개이며 공개 57개, 검토 필요 23개임.
- 표준 자동 추출 결과는 68개이며, 비표준 구조를 관리자가 확인하도록 만든 초안은 12개임.
- 체크리스트가 없는 1쪽은 표지이며, 4쪽은 일반 MRI 안내문이라 누락 체크리스트로 판단하지 않음.
- 현재 원문에서 새롭게 누락된 체크리스트는 확인되지 않음.

## 수술 자료 다중 추출

- 페이지에서 첫 번째 구역 표시가 두 번 이상 나오면 표의 위치를 확인함.
- 좌우 표는 X 좌표로 나누고, 상하 표는 Y 좌표로 나눔.
- 각 영역 안에서 제목·수술 전·수술 후 항목을 독립적으로 읽음.
- 좌표 구조를 본뜬 테스트에서 한 쪽의 서로 다른 수술표 2개를 각각 생성함.
- 현재 로컬 PDF에는 한 쪽에 수술표 2개가 있는 실제 사례가 없어 합성 좌표 테스트로 검증함.

## 안전장치

- 기존 체크리스트 파일은 예전 저장 이름을 그대로 읽고 갱신함.
- 새로 생성되는 체크리스트만 ID를 포함한 저장 이름을 사용함.
- 공개·검토 필요·숨김 상태와 새 문서 버전 자동 공개 규칙을 유지함.
- 자동 추출 실패 기록에 문서명, 쪽, 제목과 실패 이유를 남김.
- BM25, Vector, Hybrid 75:25, ChromaDB, Gemini 답변 생성과 동의어는 변경하지 않음.

- 서버 체크리스트 테스트 53개를 통과함.
