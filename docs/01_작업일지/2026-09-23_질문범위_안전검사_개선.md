# 질문 범위에 맞춘 안전검사 개선

## 왜 바꿨나요?

기존 검사는 검색된 근거의 모든 내용을 답변에 반복하도록 요구했습니다. 이 때문에 질문과 관계없는 주변 설명을 생략한 자연스러운 답변도 차단되는 경우가 있었습니다.

## 무엇을 바꿨나요?

- 직원 질문에 직접 필요한 필수 사실을 먼저 정합니다.
- 필수 사실을 정확히 보존하면 주변 설명을 생략해도 차단하지 않습니다.
- 어순, 조사·어미, 띄어쓰기, 같은 뜻의 표현과 중복 제거는 임상 의미가 같으면 허용합니다.
- 선택한 근거를 생략한 경우에는 위험하지 않으면 경고로 남깁니다.
- 표에서 확인된 항목은 행 관계를 보존해 읽기 쉬운 목록으로 표시합니다.

## 그대로 유지한 안전 차단

숫자·단위·시간·속도·조건·예외·부정·금지·행위 종류·행위 강도가 바뀌면 계속 차단합니다. 성인과 소아를 섞거나, 서로 다른 제제의 수치를 바꾸거나, 존재하지 않는 근거 번호를 사용하거나, 질문에 필요한 필수 사실을 빠뜨려도 차단합니다.

## 실제 질문 4건 결과

| 질문 | 결과 | 직원 화면 |
|---|---|---|
| 수혈 종류 알려줘 | 안전검사 차단 | 당시에는 원문 표가 한 줄로 붙은 대체 답변이 표시됨 |
| 수혈 절차 알려줘 | 통과 | Gemini가 정리한 답변과 문서명·페이지·항목 표시 |
| 진정 절차 | 통과 | Gemini 답변 표시. 다만 답변이 한 문장으로 짧아 추가 개선 필요 |
| 비터널형 카테터는 뭐야? | 근거 부족 | 등록 지침에서 근거를 확인할 수 없다는 안내 |

`수혈 종류` 실행 뒤 확인된 표 붙음 문제는 실제 표의 반복된 셀 경계가 정확히 확인될 때만 네 항목으로 나누도록 보완했습니다. 질문당 1회 호출 제한을 지키기 위해 Gemini를 다시 부르지는 않았고, 같은 형태의 가짜 데이터 자동검사로 읽기 쉬운 목록과 출처 분리를 확인했습니다.

## 자동검사 결과

- 안전검사 서비스: 37건 통과
- 기존 SCHAT 안전검사 회귀검사: 184건 통과
- 검색·직원화면·이미지 관련 자바스크립트 검사: 38건 통과
- 코드 형식 검사: 통과
- Docker의 SCHAT 웹, ChromaDB, Python 안전검사 서비스: 모두 정상

## 현재 판단

제한된 직원 웹테스트는 계속할 수 있습니다. 다만 전체 직원 시범운영을 확정하기 전에는 `수혈 종류`의 최신 표 표시를 실제 화면에서 한 번 더 확인하고, `진정 절차`가 필요한 여러 단계를 찾도록 검색 근거의 충분성을 개선해야 합니다.
