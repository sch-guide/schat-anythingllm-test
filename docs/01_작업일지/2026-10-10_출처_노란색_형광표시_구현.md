# 출처 노란색 형광 표시 — 로컬 구현

## 범위와 구현

- 다른 창에서 문서 업데이트를 계속 진행 중인 것을 확인함. 이 창은 준비 후 사용자의 “구현해줘” 요청에 따라 형광 표시 코드만 구현함. 문서 업데이트·체크리스트 코드와 실행 중 서비스는 변경하지 않음.
- 승인된 [요구사항](2026-10-10_출처_노란색_형광표시_요구사항.md)을 기준으로 출처의 전체 근거 텍스트를 PC·모바일에 전달함. 같은 문서·같은 페이지로 합쳐진 출처도 원래 근거 목록을 유지함.
- 비교는 공백·줄바꿈만 제외하며 문장·표의 내용과 문장부호는 그대로 확인함. 외부 AI나 검색 설정 변경 없이 기존 pdf.js 4.8.69를 사용함. 새 패키지를 추가하지 않음.
- PC: 브라우저 메모리에서 노란 PDF 주석을 추가한 임시 PDF를 기본 뷰어에 표시함. 원본 파일은 바꾸지 않음. 새 창에서 원본을 여는 링크는 표시 없는 원본을 제공함. 첫 위치는 페이지와 PDF 뷰어의 위치 지정 값으로 전달함.
- 모바일: PDF 화면에 같은 위치의 노란 표시를 그리며, 페이지 회전과 확대 배율을 반영함. 첫 근거 위치로 자동 스크롤하도록 연결함.
- 닫기·출처 전환 시 이전 처리 결과가 새 화면에 들어오지 않도록 취소 여부를 확인하고 PDF 작업과 임시 주소를 정리함.

## 정확성을 위한 처리

- 출처에 지정된 페이지에서 각 근거 전체가 유일하게 일치하고 좌표를 확인한 경우만 표시함.
- 여러 근거 중 하나라도 실패하면 모든 표시를 생략하고 “정확한 위치를 찾지 못해 원문을 표시합니다.”를 보여 줌.
- PDF 글자 묶음의 중간에 걸친 구간은 글자 폭을 비례 추정하지 않고 생략함. 페이지를 넘는 근거, 반복 문구, 표 읽기 순서 차이, 텍스트 없는 스캔, 지원하지 않는 글자 방향도 추측하지 않음. 이러한 PDF에서는 표시 성공률이 낮을 수 있음.
- PDF 자체를 불러올 수 없는 경우의 기존 텍스트 원문 전환은 유지함.

## 확인한 결과

- 새 위치·실패 처리 검사 8개, 실제 합성 PDF 저장·재열기 검사 4개, 실제 출처 묶음 전달 검사 1개와 기존 출처 화면 검사 17개로 총 30개를 통과함.
- 합성 PDF의 문장·여러 근거·표 칸·회전 0/90/180/270도와 원본 바이트 불변을 확인함. 저장 결과의 노란 Highlight 주석과 본문을 다시 읽어 확인함.
- 합성 PDF를 PDFium으로 이미지로 그려 노란 표시가 문장과 표 칸에 나타나고 글자가 읽히는 것을 확인함. 생성된 PDF·이미지는 운영 자료가 아닌 임시 테스트 결과이며 Git에 넣지 않음.
- Vite 화면 빌드를 별도 임시 출력 폴더로 실행해 6,169개 모듈 변환과 종료 코드 0을 확인함. 기존 브라우저 호환 정보·음성 라이브러리·큰 묶음 등의 경고가 남아 있음. 형광 표시 핵심 코드·PDF 화면의 eslint 검사를 통과함.
- 제한된 경로 읽기 권한 때문에 출처 화면 검사 도구가 처음 실패함. 동일 검사를 권한 검토 후 다시 실행해 통과함. 검사 코드의 React 주입 누락도 보완한 뒤 전달 검사를 통과함.
- requesting-code-review 지침에 따른 읽기 전용 별도 코드 검토에서 중대 오류를 발견하지 못함. 위 표시 제한과 실제 브라우저 검증 필요성을 확인함.
- 기존 가상환경 Python을 찾아 문서 화면을 재생성하고 문서 화면 분리 검사 11개를 통과함. 생성기의 기존 문자열 이스케이프 경고는 남아 있음.
- 커밋의 자동 문서 갱신은 작업 폴더 전체를 읽어 다른 창의 미커밋 문서도 포함할 수 있으므로, 형광 표시 변경만 담은 별도 사본에서 동일 생성기로 커밋용 문서 화면을 생성함. 다른 창의 작업 폴더 변경은 그대로 보존함.

## 미확인과 다음 확인

- 연결된 브라우저가 없어 실제 PC 기본 PDF 뷰어·모바일 화면의 클릭, 확대, 자동 이동은 확인하지 못함. PDF 저장·이미지 검사가 이를 대신했다는 뜻은 아님.
- 병원 원본·외부 API·Docker 컨테이너·실행 중 서비스를 변경하지 않음. 테스트 저장소의 로컬 코드 결과이며 Production 반영을 뜻하지 않음.
- 다음: 테스트 화면에 반영한 뒤 합성 PDF로 PC·모바일의 첫 위치 이동과 실패 안내를 실제 확인함. 문서 업데이트 담당 창의 변경과 형광 표시 변경을 섞어 커밋하지 않음.
