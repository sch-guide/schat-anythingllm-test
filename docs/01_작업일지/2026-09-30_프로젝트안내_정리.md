# 2026-09-30 프로젝트 안내 정리

## 작업 목적

- 현재 SCHAT 1.0과 시범운영 상태에 맞게 프로젝트 안내를 정리함.
- 비개발자가 필요한 내용을 빠르게 찾도록 중복 설명과 오래된 테스트 단계 문구를 줄임.

## 변경 내용

- `00_읽어보기.md`를 비개발자용 첫 안내로 다시 작성함.
- `CLAUDE.md`를 개발 위치·규칙·안전수칙 중심으로 줄임.
- 현재 상태 문서를 기능·동작·서버·안전·1.0 상태 중심으로 다시 작성함.
- 멘토링 현재 현황에서 B3·D6·E3·E4를 제거함.
- SCHAT 1.0 핵심 목표에서 제외한 A5를 현재 멘토링 현황과 WBS에서 제거함.
- D1을 목적·범위·완료 기준을 먼저 정하는 현재 개발 방식에 맞춰 완료 처리함.
- F3을 직접 개발한 검색 기술과 AnythingLLM 서비스 기반을 결합한 실제 흐름으로 수정함.
- A7 동의어 기능과 회귀 테스트는 확인했으나 초안 23개가 모두 검토 필요 상태라 완료로 바꾸지 않음.
- A9·C1·E2·F3을 SCHAT 1.0 확정 기준에 맞춰 완료 상태로 정리함.
- 완료 22개, 진행 중 1개, 전체 23개로 다시 계산함.
- WBS 문서와 엑셀에서 삭제된 멘토링 항목의 연결 작업을 제거함.
- 과거 작업일지와 날짜별 기록은 변경하지 않고 보존함.

## 기능 영향

- RAG, Vector, BM25, Hybrid, Embedding, Gemini, Citation을 변경하지 않음.
- PDF viewer, 체크리스트, 로그인, 문제 신고, 퀴즈를 변경하지 않음.
- 운영 DB, ChromaDB, 등록 문서와 서버 설정을 변경하지 않음.
