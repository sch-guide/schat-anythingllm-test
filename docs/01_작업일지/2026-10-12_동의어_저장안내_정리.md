# 동의어 상단 저장 안내 정리

- 요청: 동의어 관리 위쪽에 계속 남는 ‘저장했어요.’ 상자 제거.
- 성공 안내 상자만 숨기고 실패·중복 안내 및 짧은 저장 알림은 유지함. 저장 처리나 DB 구조는 바꾸지 않음.
- 실제 화면 구성 검사를 추가하여 변경 전 실패, 변경 후 11개 통과를 확인함. 가짜 상태만 사용했고 실제 Gemini와 자료 저장은 실행하지 않음.
- 다른 미커밋 변경은 보존함. 이번 수정은 Docker 3001에 아직 반영하지 않음.
- 다음: 3001 백업 후 새 화면 빌드·반영. 앞서 확인한 등록 버튼 글자색 문제는 이번 요청과 별개이며 아직 수정하지 않음.
