# 진료지원 Excel 답변 근거 위치 복원

확인일: 2026-10-14

## 문제와 원인
`비뇨` 답변에 진료지원 문서와 단축번호 1796이 포함됐지만, 원본을 펼치면 첫 행이 보이고 형광펜이 없었다. 검색 실패가 아니라 화면의 근거 연결 문제였다. 업무형태 셀은 여러 줄인데 답변 근거는 첫 문장만 인용했다. 공백을 제거한 뒤 문장을 비교하면서 이 정상 인용을 거부했다.

## 수정
원래 줄바꿈을 유지한 상태에서 직접 인용을 검증한다. 최신 저장 답변과 실제 원본을 대조해 142행 연결, 1796 글자 강조를 확인했다. 긴 병합 셀의 부서명보다 위쪽의 번호 근거를 우선해 이동하도록 보완했다. 셀 전체 배경을 칠하지 않으며 원래 서식을 유지한다. 재등록은 필요 없다.

수정 화면 파일: `frontend/src/utils/spreadsheetView.js`, `frontend/src/components/WorkspaceChat/ChatContainer/ChatHistory/Citation/SpreadsheetViewer.jsx`. 관련 회귀 검사도 추가했다. 검색, 답변 생성, 출처 선택과 서버 코드는 이번 수정에서 변경하지 않았다.

- production build 성공.
