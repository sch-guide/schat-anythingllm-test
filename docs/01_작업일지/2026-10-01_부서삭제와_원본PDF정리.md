# 2026-10-01 · 빈 부서 삭제와 연결 없는 원본 PDF 삭제

## 1. 사용자 관리 — 직원 0명 부서 삭제

### 왜 했나

- 부서 관리는 만들기, 이름 변경, 사용중지, 다시 사용만 있었고 서버와 화면 어디에도 삭제 기능이 없었음.
- 원래 "직원이 있는 부서는 지우지 않고 사용중지한다"는 설계였음. 그래서 E2E삭제테스트처럼 직원이 없는 테스트 부서도 목록에 계속 남았음.

### 바뀐 동작

- 직원이 0명인 부서에만 `삭제` 버튼이 보임. 직원이 있는 부서는 버튼을 숨기고, 카드 설명에 "직원이 있는 부서는 사용중지"라고 적어 둠.
- 삭제를 누르면 "OOO 부서를 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다." 확인창이 나옴.
- 서버 안전장치(API `DELETE /schat-admin/departments/:id`, 관리자만)
  1. 부서가 있는지 확인함.
  2. 소속 직원 수를 확인하고, 1명 이상이면 "직원 N명이 소속된 부서는 삭제할 수 없습니다"로 거부함.
  3. 실제 삭제 명령 자체에도 "직원이 없을 때만" 조건을 넣음. 확인과 삭제 사이에 직원이 추가되어도 지워지지 않음.
  4. 부서 한 줄만 지움. 직원 계정, 로그인, 다른 부서, 문제 신고(신고 당시 부서 이름을 따로 저장함)는 그대로임.
- 시스템 기록에 "부서 삭제 · 부서 이름"이 남음.
- DB 구조 변경(migration)은 없음.

## 2. 저장공간 정리 — 연결 정보가 없는 원본 PDF 삭제

### 왜 했나

- 원본 PDF 파일 이름은 문서 번호를 한쪽으로만 바꾼 값(sha256)이라, 파일 이름만으로는 어느 문서의 원본인지 되돌려 알 수 없음.
- 그래서 페이지 기록에 연결되지 않은 원본은 모두 "검토 필요(삭제 불가)"로만 표시했음.

### 바뀐 판정

- 시스템 곳곳에 남아 있는 **모든 문서 번호**를 모아 같은 방식으로 바꿔 보고, 원본 파일 이름과 대조함.
  - 모으는 곳: 작업 공간 문서, 페이지 기록, 검색 데이터(Chroma), 체크리스트, 이미지 폴더, 퀴즈, 과거 답변의 출처(대화 기록)
- 어느 문서 번호와도 맞지 않는 원본만 `삭제 가능`으로 판정함.
- 하나라도 맞으면 `검토 필요`로 둠. 이유: "대화 기록·퀴즈 등 다른 자료에서 이 문서를 가리키고 있어 확인이 필요합니다."
- 조사 중 하나라도 실패하면(검색 데이터를 읽지 못함 등) 어떤 원본도 삭제 가능으로 판정하지 않음.
- 현재 작업 공간 문서와 예전 업로드의 원본은 그 업로드 묶음에 속하므로 이 목록에 나오지 않음.

### 바뀐 삭제 흐름

- `정리 대상 보기`의 표 아래에 **연결 정보가 없는 원본 PDF** 칸이 따로 생김.
  - 삭제 가능한 파일만 체크박스로 고를 수 있음.
  - `선택한 파일 삭제`를 누르면 "선택한 원본 PDF N개를 삭제하시겠습니까? … 삭제 후 복구할 수 없습니다." 확인창이 나옴.
- 서버 재검증(API `POST /schat-admin/storage-cleanup/originals/delete`, 관리자만, 확인 필요, 다른 정리 작업과 동시 실행 안 됨)
  - 삭제 직전에 저장소를 처음부터 다시 조사하고 파일마다 다시 판정함.
  - 여전히 `삭제 가능`인 파일만 지움. 지우는 것은 `original-documents` 안의 해당 `.pdf`와 정보 `.json` 두 파일뿐임.
  - 나머지는 파일마다 거부 이유를 돌려줌. 예: 원본 PDF 항목이 아님, 목록에서 찾을 수 없음, 다른 자료와 연결됨.
  - 삭제 후 운영 수치(문서, 쪽, 본문·이미지 검색 데이터, 체크리스트, 현재 원본 수)가 그대로인지 다시 확인함.
- 삭제 결과 화면에 "연결되지 않은 원본 PDF N개 삭제 · 확보 공간: 약 XMB"가 나오고, 목록에서 바로 사라짐.
- 시스템 기록에 "연결되지 않은 원본 PDF 삭제 · N개 삭제 · 확보 공간 XMB"가 남음. 파일 내용, 파일 이름, 문서 번호는 남기지 않음.
- 기존 "예전 업로드" 삭제 흐름(미리보기 → 확인 → 전부 통과해야 삭제)은 그대로이고, 원본 PDF는 이 흐름에서 선택되지 않게 막음.

## 바꾸지 않은 것
