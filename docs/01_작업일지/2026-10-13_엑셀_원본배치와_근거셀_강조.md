# 엑셀 원본 배치와 근거 셀 강조

## 기존 화면이 원본과 달랐던 이유

원본 XLSX 파일은 그대로 보관되어 있었지만, 보기 기능이 표시값·병합만 읽고 서식을 읽지 않았습니다. 화면에서도 임의의 행 번호, A/B/C/D 좌표 헤더, 일정한 여백과 너비를 붙였습니다. 검색용 텍스트 추출기의 한계 때문에 원본 서식을 잃은 것은 아닙니다.

실제 파일에 셀 값, 시트 이름, 병합, 열 너비, 행 높이, 정렬, 배경, 테두리, 굵은 글씨가 남아 있음을 확인했습니다. 서버에 이미 포함된 ExcelJS로 보관 원본을 읽어 보기 전용 서식 정보를 제공합니다. 검색용 추출기·저장된 검색 데이터는 바꾸지 않았습니다.

## 원본 표시

- 인공 행/열 헤더 제거. 원본 자체에 있는 값과 표 제목은 유지합니다.
- 원본 열 너비는 화면 픽셀로 환산하고 행 높이는 포인트에서 픽셀로 환산합니다. 병합·숨긴 행/열·정렬·줄바꿈·배경·글꼴·테두리를 반영합니다.
- 원본 서식 CSS는 정해진 속성·색 형식만 만들며 셀 내용은 React 문자열로 출력합니다. 수식·매크로·외부 문서 프로그램을 실행하지 않습니다.
- XLSX를 대상으로 서식을 복원합니다. 구형 XLS는 기존 값·병합 보기 수준입니다. 그림·차트·조건부 서식·글꼴 설치 환경까지 동일한 Excel 프로그램 화면을 재현하는 것은 아닙니다.

## 하이라이트가 사라진 이유와 수정

최근 간호부 답변의 직접 인용은 `간호교육파트 교대제 | 내선번호: 6741`처럼 행 번호 없이 저장되어 있었습니다. 이전 표는 `행 152:` 형식만 찾아서 첫 행으로 열리고 강조도 하지 못했습니다.

- 직접 인용만 기존 출처 본문의 행과 대조합니다. 값 순서와 명시된 열 이름이 같고, 위치가 유일할 때만 행 번호를 복원합니다.
- 표시 시 원본 셀의 값과 다시 대조합니다. 단축/내선 열 이름이 뒤바뀌거나 같은 값이 여러 위치에 있으면 표시하지 않습니다.
- 실제 최신 간호부 답변으로 152~155행의 부서명·번호 열 8개 셀만 표시 대상으로 확인했습니다. 주변 행은 칠하지 않습니다.
- 원래 배경과 글자색을 유지한 채 반투명 연두색과 얇은 안쪽 테두리를 겹칩니다.
- 문서 등록에서 단순히 원본을 열면 직접 인용이 없어 하이라이트하지 않습니다. 직원·관리자·모바일은 같은 컴포넌트를 재사용합니다.

## 보호 범위와 검증

다운로드 차단, 단일 시트 UI 숨김, 긴 설명 제거를 유지합니다. 검색·BM25·Vector·Hybrid·Chroma·Gemini·출처 선택·체크리스트·동의어·PDF는 수정하지 않습니다. 원본 파일을 삭제·덮어쓰거나 재색인하지 않습니다. 외부 AI 호출 비용 0원입니다.

서식이 있는 가상 XLSX를 격리·네트워크 차단 컨테이너에서 만들어 병합·너비·높이·정렬·색·테두리·글꼴·앞자리 0을 검사했습니다. 인공 헤더 제거, 원래 색과 강조 동시 유지, 직접 셀만 강조, 관리자 무강조, 시트 UI, 모호한 인용 제외, 열 이름 뒤바뀜 제외, PDF 회귀와 다운로드 권한을 검사했습니다.

브라우저 연결 조회 결과 앱·브라우저가 모두 없어 PC 직접 클릭·실제 모바일 확인은 수행하지 못했습니다. 실제 원본 및 기존 답변과의 대조, 화면 렌더링 검사와 Docker API로 확인하며 새 AI 답변은 생성하지 않습니다.
