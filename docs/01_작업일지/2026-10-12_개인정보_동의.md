1. 관리자 화면에 보관 기간 설정(대화 기록 N개월, 접속 기록 N개월, 0이면 끔). 기존 설정 표에 저장하므로 DB 구조 변경은 필요 없을 것으로 봄.

4. 안전장치: 켜기 전 "삭제 예정 N건" 미리보기, 삭제 후 건수만 기록, 처음엔 꺼진 상태로 배포.

6. 순서: 기능 배포(꺼짐) → 미리보기 확인 → 담당 부서 확정 → 동의서 문구 수정(v2, 전원 재동의) → 자동 삭제 켜기.
