# 직원 계정 완전삭제

## 정책

- 일반 퇴사·휴직은 `사용중지`를 씁니다.
  - 로그인만 막히고 계정·신고·알림·통계는 그대로 남으며, 다시 사용할 수 있습니다.
- 잘못 만든 계정, 테스트·중복 계정, 실제 직원이 아닌 계정만 `완전삭제`합니다. 계정 자체가 없어지고 되돌릴 수 없습니다.

## 화면(관리자 설정 > 사용자 관리)

- 각 행에 `사용중지` 또는 `다시 사용` 버튼이 있습니다.
- 사용중지된 행에만 작은 `완전삭제` 링크가 나옵니다. 사용중인 계정의 삭제는 `수정` 창 아래 `위험 영역 > 직원 계정 삭제`에서만 할 수 있습니다.
- 행마다 체크박스가 있어 여러 명을 고를 수 있습니다. 선택하면 `선택 N명: 사용중지 / 다시 사용 / 선택 사용자 삭제`가 나옵니다. 검색·부서·상태 필터와 함께 쓸 수 있고, 전체 삭제 버튼은 없습니다.
- 삭제 창
  - 삭제 대상 목록과 사람별 연결 데이터(문제 신고·알림·대화 기록 수)를 먼저 보여 줍니다.
  - 사용중인 계정에는 "현재 사용중인 계정입니다. 삭제 대신 사용중지를 권장합니다."가 표시됩니다.
  - 확인을 위해 한 명이면 직원 이름을, 여러 명이면 `삭제`를 입력해야 버튼이 켜집니다.

## 삭제되는 것과 남는 것

- 삭제되는 것: 계정, 그 직원의 개인 알림, 개인 대화 기록(기존 시스템과 같은 방식)
- 남는 것
  - 문제 신고는 신고 당시 이름·사번·부서와 함께 그대로 남습니다. 관리자 화면에는 `(삭제된 사용자)`로 표시되고, 신고 통계도 그대로입니다.
  - 이용 가이드의 조회·도움 수는 사람과 연결되지 않은 합계라 그대로입니다.
- 같은 사번으로 다시 등록할 수 있습니다. 새 계정은 새 번호(id)를 받고, 과거 신고가 새 계정으로 연결되지 않습니다.

## 보호 장치

- 삭제는 관리자만 할 수 있고 서버가 권한을 확인합니다. 직원이 API를 직접 불러도 막힙니다.
- 지금 로그인한 관리자 본인은 선택할 수 없고 삭제도 막힙니다.
- 사용중인 관리자가 하나도 남지 않게 되는 삭제는 막힙니다("마지막 관리자 계정은 삭제할 수 없습니다.").
- 서버는 삭제 직전에 같은 확인을 다시 하고, 입력한 확인 문구도 다시 검사합니다.
- 삭제 기록은 시스템 상태의 시스템 기록에 `사용자 관리 기록: 계정 삭제`와 이름·부서·사번으로 남습니다. 비밀번호·해시·대화 내용은 기록하지 않습니다.

## DB 변경

- migration `20260927020000_schat_account_delete`
  - 신고의 신고자 연결을 계정 삭제 시 비우도록(SET NULL), 알림은 함께 삭제되도록(CASCADE) 바꿨습니다.
  - SQLite 특성상 표를 새로 만들어 모든 행을 같은 id로 옮깁니다.
  - DB 사본에서 적용 전후 신고·알림·FAQ·사용자 수가 같은 것을 확인했습니다.
- 적용 전 백업: `server/storage/anythingllm.before-account-delete-20260927.db`(Git 제외)

## 이후 변경: 사용자 목록 정리

- 목록 각 칸이 한 줄로 보이도록 줄바꿈을 막았습니다.
  - 이름·부서가 길면 `…`로 줄이고, 마우스를 올리면 전체가 보입니다.
  - 화면이 좁으면 표를 가로로 스크롤합니다(모바일 포함). 글자가 세로로 쪼개지지 않습니다.
- 상태는 `사용중`/`사용중지` 배지로, 비밀번호가 없는 계정은 옆에 `비밀번호 미설정` 배지로 표시합니다. 관리자 본인의 `나` 표시는 이름 옆 한 줄에 둡니다.
- 목록 작업 버튼은 `수정` 하나만 남겼습니다. `사용중지`·`다시 사용`·`비밀번호 초기화`·`계정 삭제`는 모두 `수정` 화면에서 합니다.
- `작업` 칸은 표 오른쪽에 고정되어, 표가 옆으로 스크롤되어도 `수정` 버튼이 항상 보입니다. PC(1024px 이상)에서는 표 전체가 한 화면에 들어옵니다.
- `수정` 화면은 세 부분으로 나눴습니다.
  - `기본 정보`: 이름·사번·부서·권한
  - `계정 상태`: 사용중/사용중지, 비밀번호 설정 여부, 최근 로그인
  - `계정 관리`: 사용중지/다시 사용, 비밀번호 초기화. 본인 계정은 사용중지할 수 없고, 본인 비밀번호는 사용자 메뉴의 비밀번호 변경을 안내합니다.
  - `위험 영역`: 빨간 테두리 안에 `계정 삭제`
- 본인 계정이나 마지막 관리자 계정은 서버와 같은 규칙으로 확인해 `계정 삭제` 버튼을 끄고 이유를 보여 줍니다.
- 한 명을 삭제할 때 확인 창에 이름·사번·부서를 따로 보여 줍니다. 이름을 입력해야 삭제되는 이중 확인은 그대로입니다.
