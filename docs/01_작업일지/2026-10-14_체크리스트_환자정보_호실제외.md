# 체크리스트 환자정보 칸에서 호실 제외

## 요청
체크리스트 환자정보 칸에 호실을 적지 않도록 안내를 바꾼다(채팅 화면의 체크리스트 창, 별도 창 모두).

## 수정
- 안내 글자(예시): "예: 612호 / 홍길동" → "예: 홍길동".
- "환자정보" 제목 옆에 작은 주황 글씨로 "환자등록번호 및 호실은 적지 마세요"를 넣었다. 색은 답변 신고 창의 "환자 이름·등록번호는 적지 마세요"와 같은 `text-orange-500`이다. 폭이 좁으면 제목 아래 줄로 내려간다.
- 이름 가리기(홍○동)는 그대로다.
- 수정 파일: `ChecklistMemo.jsx`(안내 문구 자리), `ChecklistFloatingPanel.jsx`, `pages/ChecklistPopup/index.jsx`, `utils/checklistMemo.node.test.mjs`.
- DB 구조·서버·동의서 문구는 바꾸지 않았다. 동의서 문구 변경 방법(v1 수정 / v2 재동의)은 사용자 결정을 기다린다.

## 검증
- 체크리스트 화면 자동 검사 93개 통과. 린트의 기존 줄바꿈 오류 3개는 손대지 않은 줄이며 HEAD에서도 같다.
- 3001 반영 전 백업 `schat-local-backups/3001-checklist-hint-20261014`(4,328개, 불일치 0). 이미지 `schat-admin-build:checklist-hint-20261014`.
- 브라우저 확인(테스트 계정, PCD 체크리스트):
  - 별도 창 PC 1400px: 예시 "예: 홍길동", 안내 문구가 제목과 같은 줄, 주황색 rgb(249,115,22), 가로 넘침 없음.
  - 별도 창 휴대폰 390px: 안내 문구가 제목 아래 줄로 내려감, 가로 넘침 없음.
  - 채팅 화면 체크리스트 창(폭 390px): 같은 문구·예시, "지우기" 버튼이 있을 때 안내가 제목 아래 줄.
  - "홍길동" 입력 후 "홍○동"으로 가려짐.
- 테스트 계정·부서·대화·체크리스트 개인 상태·이벤트 기록은 지웠다. AI 호출: 채팅 질문 1회.
