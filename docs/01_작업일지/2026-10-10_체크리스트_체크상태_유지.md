# 체크리스트 체크 상태 유지

## 결정

- 직원 체크리스트의 체크 표시를 창을 닫았다 다시 열어도 유지함.
- 다음 환자를 위해 처음부터 다시 체크할 수 있도록 "체크 모두 해제" 버튼을 추가함. 누르면 확인 창이 한 번 뜸.

## 동작

- 체크 상태는 브라우저 저장공간(localStorage, 이 PC의 브라우저에만 남는 저장 칸)에 **사용자별 + 체크리스트별**로 저장함. 같은 PC를 다른 직원이 로그인해 쓰면 서로의 체크가 섞이지 않음.
- 채팅 화면 안의 작은 창과 "별도 창으로 열기" 창이 같은 저장값을 씀. 한쪽에서 체크하면 다른 쪽에도 바로 반영됨.
- 새로고침, 다른 대화방 이동, 브라우저 재시작 후에도 유지됨. 다른 PC나 다른 브라우저에는 따라가지 않음.
- 저장되는 내용은 체크 칸 번호(체크리스트·구역·항목 식별값)뿐이며 환자정보는 저장하지 않음.
- 접힘/펼침 상태는 기존처럼 창을 닫으면 처음 상태로 돌아감.

- `frontend/src/hooks/useChecklistChecks.js`: 두 화면이 함께 쓰는 체크 상태
- `frontend/src/components/WorkspaceChat/ChatContainer/ChatHistory/Checklist/ChecklistResetButton.jsx`: "체크 모두 해제" 버튼
