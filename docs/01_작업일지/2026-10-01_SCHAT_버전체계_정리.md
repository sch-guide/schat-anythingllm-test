# SCHAT 버전 체계 정리

## 목적

기존 `SCHAT 1.0`과 `1.1 이후` 표현이 개발 단계의 버전 번호와 혼동되어 공식 명칭을 버전 1~4 체계로 통일함.

## 정리한 기준

- 버전 1은 처음 직접 만든 병원 문서 챗봇으로 정의함.
- 버전 2는 ChromaDB·Embedding·BM25·Hybrid 검색을 적용한 직접 개발 RAG로 정의함.
- 버전 3은 버전 2의 검색 기술과 AnythingLLM 서비스 기반을 결합한 현재 SCHAT으로 정의함.
- 버전 4는 문서 버전 관리, Citation 정밀 개선과 추가 품질검증을 진행하는 다음 단계로 정의함.
- 과거에 `SCHAT 1.0`으로 확정한 현재 시스템은 새 체계에서 `SCHAT 버전 3`으로 표시함.
- 과거의 `1.1 이후 개선사항`은 `버전 4 개선사항`으로 표시함.

## 변경 범위

- `docs/00_현재상태/SCHAT_버전_체계.md`를 공식 기준 문서로 추가함.
- 처음 읽기, 현재 프로젝트 상태와 `CLAUDE.md`에 현재 운영 버전과 공식 문서 위치를 반영함.
- 멘토링 현황, WBS, 확정 기준과 최종 검수 문서의 설명 문장을 새 체계로 정리함.
- 개발 복기와 과거 작업일지는 설명 문장만 새 체계로 정리함.
- 실제 Git commit 메시지, 과거 파일명, 코드 식별자와 문서 예시의 `v1.0`·`v1.1` 값은 역사적 증거이므로 유지함.

## 기능 영향

- 기능 코드, 검색 설정, DB, ChromaDB와 운영 데이터를 변경하지 않음.
- Git commit, push와 tag를 실행하지 않음.
