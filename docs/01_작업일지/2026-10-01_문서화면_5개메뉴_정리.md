# 문서 화면(docs_view) 5개 메뉴 정리

## 한눈에 보기

- 메뉴가 많아 길을 잃기 쉬운 문서 화면을 5개 메뉴로 묶음: `1. 프로젝트 소개`, `2. 동작 방식`, `3. 기능과 상태`, `4. 개발 과정`, `5. 운영·인수인계`.
- 기존 내용은 버리지 않고 각 메뉴 안의 카드·구역·접기(펼쳐 보기)로 옮김.
- 한 번에 한 메뉴만 보이고, 지금 보고 있는 메뉴를 왼쪽 메뉴에 색으로 표시함.
- 휴대폰에서는 메뉴를 접고 펼 수 있는 버튼으로 바꿈.

## 바꾼 내용

- `05_인수인계`의 안내 문서를 내용에 맞는 메뉴에 둠.
  - 「검색 점수 읽는 법」은 `2. 동작 방식`에 둠.
  - 「개발 복기와 AI 협업 인수인계」는 `4. 개발 과정`에 둠.
  - 「서버 배포 및 업데이트 안내」 같은 운영 문서는 `5. 운영·인수인계`에 둠.
- 현재 상태 문서의 검색 방식, 문서 등록, 기능 표, 검증 결과, 환경, 안전 규칙을 메뉴별로 나누어 보여 줌. 내용의 정본은 계속 `docs/00_현재상태/현재_프로젝트_상태.md` 하나임.
- 멘토링 기록마다 고유한 이동 위치를 붙여 끊겨 있던 `#mentoring-2` 링크를 고침.
- 메뉴마다 이전·다음 메뉴로 가는 버튼을 둠.

## 고친 파일

- `문서도구/문서화면_만들기.py`: 5개 메뉴 화면, 안내 문서 배치, 메뉴 전환과 휴대폰 메뉴 버튼.
- `문서도구/SCHAT_개요데이터_만들기.py`: 현재 상태 문서를 구역별로 읽는 기능, 멘토링 이동 위치.
- `검사/문서화면_분리_검사.py`, `검사/SCHAT_설명화면_검사.py`: 새 화면 구조에 맞게 검사 기준을 바꾸고 "5개 메뉴와 화면 안 링크가 모두 이어지는지" 검사를 추가함.

## 확인 결과

- 화면 안 링크 41개를 검사했고 끊긴 링크는 0개임.
- 문서 화면 검사 4종 중 3종을 통과함.
- 나머지 1종은 이번 작업 전부터 있던 실패임. 개발 복기 문서에 테스트 계정 비밀번호 설정의 실제 이름이 적혀 있어 생김. 값은 적혀 있지 않음. 2026-10-02에 일반적인 말로 바꿔 해결함.
- 실제 브라우저 확인(컴퓨터·휴대폰 화면)은 2026-10-02 [문서 화면 최신화](2026-10-02_문서화면_최신화.md) 작업에서 함께 진행함.

## 바꾸지 않은 것

- 검색, 임베딩, 답변 규칙, 운영 데이터는 바꾸지 않음.
- 원본 문서의 내용은 바꾸지 않고 보여 주는 위치만 바꿈.
