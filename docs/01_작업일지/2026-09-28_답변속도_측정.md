# 답변 속도 측정 (개선 전 기준값)

## 측정 방법

- 대표 질문 10개(짧은 2, 절차 3, 약물 3, 이미지 2)를 각각 3번씩, 모두 30번 측정했습니다.
- 매번 새 대화방에서 시작해 이전 대화가 섞이지 않게 했습니다.
- 채팅 화면과 같은 Automatic(에이전트) 경로를 컨테이너 안에서 직접 실행했습니다.
- 측정용 스크립트가 자기 프로세스 메모리 안에서만 시간을 쟀습니다. 운영 서버 프로세스와 저장소 코드는 바꾸지 않았습니다.
- 기록한 것은 시간·횟수·토큰 수 같은 숫자뿐이고, 질문·답변·근거 원문은 저장하지 않았습니다.

## 결과 요약 (30회 평균)

| 구분 | 첫 글자까지 | 답변 완료 | AI 호출 | 검색 |
|---|---|---|---|---|
| 전체 평균 | 10.6초 | 13.0초 | 3.0회 | 2.6회 |
| AI가 검색을 다시 요청하지 않은 경우(14회) | 3.9초 | 4.9초 | 1회 | 1회 |
| AI가 검색을 다시 요청한 경우(16회, 평균 3.8번 재검색) | 16.4초 | 20.1초 | 4.8회 | 3.8회 |

- 가장 오래 걸리는 것은 **AI가 검색 도구를 여러 번 다시 부르는 왕복**입니다(질문당 평균 3.7초, 느린 질문은 최대 약 13초).
- 그다음은 최종 답변 AI(첫 글자까지 평균 2.6초, 완료까지 5.0초)와 검색 1회(평균 1.4초)입니다.
  - 검색 1회의 구성: 질문 임베딩 0.65초, BM25 계산 0.42초, Chroma 전체 조각 불러오기 0.24초, Chroma 의미 검색 0.04초
- 안전 검사(Python)는 현재 설정에서 호출되지 않습니다(0회).
- 입력 토큰은 질문당 평균 19,099개였습니다.
  - AI를 한 번만 부른 질문은 약 1,300개였습니다.
  - 검색을 다시 요청한 질문은 약 34,600개였고, 많게는 8만 개를 넘었습니다.
- thinking 토큰은 API가 따로 알려 주지 않습니다. 전체−입력−출력으로 추정하면 최종 답변 1회당 평균 약 420개입니다.
- 측정 비용: Gemini 입력 약 57만 토큰, 출력·thinking 약 2만 8천 토큰으로 약 0.54달러(약 750원, 1달러≈1,400원으로 계산)입니다.
