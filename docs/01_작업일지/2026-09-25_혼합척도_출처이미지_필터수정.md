# 혼합 척도 출처 이미지 필터 수정

## 쉽게 요약

- NRS·FPRS·FLACC가 함께 나오는 통증평가 원문 화면은 질문한 척도가 설명에 있으면 허용하도록 초점 필터를 바꾸었습니다.
- NRS 질문에 FPRS만 있는 이미지, FPRS 질문에 NRS만 있는 이미지는 계속 제외합니다.
- 로고·장식 제외, 직접 `image_key` 연결, 중복 제거와 같은 기존 조건은 변경하지 않았습니다.

## 확인 결과

- 실패 테스트에서 혼합 척도 2건이 탈락하는 것을 먼저 확인했습니다.
- 수정 후 관련 회귀검사 17개가 통과했습니다.
- 실제 브라우저에서 새 `NRS` 질문은 출처 4개를 저장했지만 각 출처의 직접 이미지는 0개였습니다. 선택된 출처가 이미지 설명 source가 아니어서, 이번에 승인된 `ragSources.js` 필터 범위만으로는 실제 화면 표시까지 완성되지 않았습니다.
- `memory.js`에서 `relatedImageSources`를 보존하는 추가 수정을 시도했지만, 실제 반환 항목에는 `image_key`만 있고 질문 초점 검사에 필요한 이미지 설명 `text`가 없었습니다. 설명 없이 통과시키면 NRS 질문에 FPRS 전용 이미지를 막을 수 없어, 효과 없는 임시 수정은 되돌렸습니다. 실제 브라우저 `NRS` 1회 검증에서도 출처 4개·이미지 0개였으며, 올바른 해결을 위해서는 검색 반환 경계가 선택한 이미지 설명 원문을 함께 전달해야 합니다.
- 검색·Gemini·Automatic·frontend는 변경하지 않았습니다.
