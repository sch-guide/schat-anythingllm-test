# Renal biopsy 체크리스트 MVP

## 무엇을 만들었나

- `검사 및 시술(26.04.07).pdf` p.56의 신장조직검사 표를 보수적인 규칙으로 구조화합니다.
- 추출 성공 시 별도 승인 없이 활성 상태의 파일형 체크리스트로 저장합니다.
- 직원의 `renal biopsy`, `renal bx`, `신장 조직검사`, `신생검` 관련 질문에만 답변 아래 체크리스트 버튼을 표시합니다.
- 관리자는 문서 화면에서 체크리스트를 보고 수정하거나 원본 p.56을 열 수 있습니다.

## 원문 보호 원칙

- PDF에서 확인되는 문자열만 저장하며 Gemini는 호출하지 않습니다.
- `검사목적`은 설명형 항목이라 체크박스를 표시하지 않습니다.
- 동의서, 금식여부, IV line, 검사 전 준비, Prepare 등 실제 확인·수행 항목만 체크할 수 있습니다.
- 원문의 ①·② 세부 문장은 별도 체크박스로 나누지 않고 상위 항목 설명으로 유지합니다.
- 체크리스트 수정은 JSON 파일에만 반영하며 PDF, ChromaDB, BM25와 본문 벡터는 변경하지 않습니다.

## 화면 동작

- 검사 전과 검사 후 구역은 각각 접고 펼칠 수 있습니다.
- 체크 상태는 같은 화면을 사용하는 동안 유지되며 환자별 또는 DB 영구 상태로 저장하지 않습니다.
- 데스크톱·모바일과 라이트·다크 모드에서 사용할 수 있습니다.
- 원본 보기는 기존 인증 PDF viewer와 `pdfRef` 연결을 재사용합니다.

## 검증 결과

- 서버 체크리스트·저장·API 테스트 16개와 직원/관리자 화면 테스트 10개가 통과했습니다.
- production frontend build가 성공했습니다.
- 실제 Docker Chromium 화면에서 관리자 보기·수정·원본 p.56, 직원 버튼·팝업·접기·체크·다시 열기 상태 유지를 확인했습니다.
- 관련 없는 수혈 질문에는 체크리스트 버튼이 표시되지 않았습니다.
- 본문 벡터는 작업 전후 654개이며 snapshot hash가 동일합니다.
- 실제 Gemini 호출, DB migration, 재색인은 수행하지 않았습니다.
