# 화면 디자인 폴더 정리

## 무엇을 바꿨나

- `03_전체_공식문서` 밖에 독립된 `04_화면디자인` 폴더를 만들었습니다.
- `로고와 이름`, `색상과 다크모드`, `화면 확인 방법`을 비개발자가 읽기 쉬운 별도 문서로 정리했습니다.
- 어떤 화면을 바꾸려면 어떤 프로그램 파일을 확인해야 하는지 쉬운 말로 안내했습니다.
- 처음 잘못 배치했던 `frontend/src/04_화면디자인`과 `docs/04_화면디자인`은 제거했습니다.
- SCHAT 로고, 다크모드 버튼과 화면 검사 실행 파일은 앱이 안정적으로 작동하는 원래 `frontend` 위치로 복구했습니다.

## 유지한 것

- 검색, Gemini, ChromaDB, BM25, 답변, 출처, 관련 이미지와 로그인 기능은 변경하지 않았습니다.
- 화면의 실제 모양과 동작은 바꾸지 않고 파일 위치와 설명 문서 구조만 바로잡았습니다.

## 확인 결과

- SCHAT 화면 계약 검사 4건이 통과했습니다.
- 전체 frontend Node 회귀검사 33건이 통과했습니다.
- 실행 파일을 원래 위치로 복구한 production Docker 이미지 빌드가 성공했습니다.
- 새 이미지를 적용한 뒤 SCHAT 웹, ChromaDB와 안전검사 서비스가 모두 정상 상태이고 웹 응답을 확인했습니다.
