# Renal biopsy 계층형 체크리스트와 별도 창

## 바뀐 점

- 직원용 체크리스트를 상위 항목과 세부 줄로 나누어 각각 체크박스를 표시합니다.
  - 상위 항목을 누르면 세부 줄 전체가 선택되고, 다시 누르면 전체가 해제됩니다.
  - 세부 줄은 하나씩 체크할 수 있고, 일부만 체크하면 상위 체크박스는 중간 상태(-)로 보입니다. 전부 체크하면 상위도 체크됩니다.
  - 체크한 세부 줄은 취소선과 흐린 글자로 표시되고, 해제하면 원래대로 돌아옵니다.
- `검사목적`과 `검사장소/이동수단`은 읽기용 정보라 체크박스 없이 표시합니다. 저장된 체크리스트 JSON은 바꾸지 않고 직원 화면 표시 규칙으로만 처리했습니다.
- `별도 창으로 열기`를 추가했습니다. 답변 아래 버튼 옆과 작업창 제목줄 아이콘에서 열 수 있습니다(PC만).
  - 브라우저의 작은 별도 창(내부 약 420×640px)으로 열리며, SCHAT 창과 따로 이동·크기 조절·최소화·닫기가 됩니다.
  - SCHAT 본창을 최소화해도 별도 창은 계속 화면에 남고 체크할 수 있습니다.
  - 별도 창은 체크리스트를 스스로 불러오므로 SCHAT에서 다른 화면으로 이동해도 유지됩니다. 체크 상태는 그 창을 닫을 때까지만 유지되며, SCHAT 안 작업창과 체크 상태를 공유하지 않습니다.
  - 같은 체크리스트를 다시 열면 새 창을 더 만들지 않고 이미 열린 창을 사용합니다.
- 기존 작업창 기능(배경 가림 없음, 자유 이동, 화면 밖 이동, 크기 조절, 최소화, X로만 닫기, 상태 유지, 모바일 하단 패널)은 그대로입니다.

## 바꾸지 않은 것

Citation과 출처 선별, response.sources, PDF 근거 원문 보기와 원본 PDF API, Automatic, AgentHandler, rag-memory, Gemini 답변 방식, BM25, ChromaDB, 체크리스트 자동 추출, 체크리스트 JSON, 관리자 체크리스트 보기·수정 모달, 본문 벡터.

## 확인 결과

- 저장된 Renal biopsy 답변을 직원 계정의 임시 검증 대화로 복제해 확인했고, 끝난 뒤 삭제했습니다. 새 답변은 브라우저 안의 모의 스트림으로 재현해 Gemini를 호출하지 않았습니다.
- Docker 안 Chromium 검증 48개 항목 모두 통과
  - 작업창: 열기, 이동, 화면 밖 이동, 오른쪽·아래·모서리 크기 조절, 최소화·복원, 위치·크기 유지, 새 질문·새 답변 후 유지, PDF 원문과 동시 조작, X로만 닫힘
  - 체크박스: 정보 항목 2개 체크박스 없음, 상위 9개·세부 26개 표시, 전체 선택·해제, 개별 선택, 중간 상태, 취소선 표시·제거
  - 별도 창: 열기, 독립 이동·크기 조절, SCHAT 창 최소화 중 표시·체크 가능, 별도 창 단독 최소화, 닫기
  - 회귀: Citation은 기존·새 답변·새로고침 후 모두 p.56 한 개, PDF 원문 보기 HTTP 200, 관리자 모달은 기존처럼 체크박스 10개
  - 모바일: 하단 패널, 내부 스크롤, 최소화·복원·닫기, 배경 가림 없음, 별도 창 버튼 숨김
- 실제 Windows Chrome 창 검증 4개 항목 통과: 별도 창이 SCHAT과 다른 OS 창으로 열림, 이동·크기 조절, SCHAT 창 최소화 중에도 별도 창 표시와 체크 가능, 정상 닫힘
- 프런트엔드 테스트 81개 통과, Docker production build 성공

## 남은 제한

- 별도 창과 SCHAT 안 작업창은 체크 상태를 서로 공유하지 않습니다.
- 브라우저의 팝업 차단 설정이 켜져 있으면 별도 창이 막힐 수 있습니다. 버튼을 직접 누르는 경우 Chrome 기본 설정에서는 정상적으로 열립니다.
- 모바일에서는 별도 창 버튼을 숨깁니다. 모바일 브라우저는 별도 창 대신 새 탭으로 열기 때문입니다.
- 모바일에서 작업창을 펼치면 아래쪽 채팅 입력창을 가립니다. 입력할 때는 최소화하면 됩니다.
- `검사목적`·`검사장소/이동수단` 정보 항목 판단은 항목 이름 규칙(목적·장소·이동수단)을 사용합니다. 앞으로 다른 체크리스트가 추가되면 이 규칙이 맞는지 다시 확인해야 합니다.
