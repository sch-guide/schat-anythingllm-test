# 엑셀 원본 보기 통일과 다운로드 제한

## 무엇을 바꿨나

문서 등록 화면의 사용 중 엑셀에도 `원본 보기`를 연결했습니다. PDF·엑셀에 맞는 뷰어를 같은 원본 모달에서 선택하며, 엑셀 표 컴포넌트는 직원 답변 출처와 모바일에서 재사용합니다.

직원 엑셀 근거 화면의 긴 안내문, `근거 원문` 제목, `시트` 설명, 원본 다운로드, 연두색 설명, 변환 텍스트 중복을 제거했습니다. 시트가 하나면 바로 표를 보여주고 여러 개일 때만 이름 선택 상자를 남겼습니다. 근거 첫 행 자동 이동·검증된 행 연두 표시·행 범위 이동은 유지합니다.

## 다운로드 제한

- 관리자 포함 모든 사용자에게 엑셀 다운로드 버튼을 제공하지 않습니다.
- 기존 원본 API의 `download` 매개변수 요청은 값과 관계없이 403으로 거부합니다. 바이너리 파일을 반환하는 분기는 제거하고 표 JSON만 반환합니다.
- 인증과 작업공간 접근 검사는 유지합니다. 원본은 별도 보관 폴더에 그대로 두며 정적 공개 폴더가 아닙니다. 생성 파일 다운로드 API도 다른 별도 경로만 취급합니다.
- 화면에 보여준 셀 값을 복사하거나 캡처하는 것까지 막는 기능은 아닙니다.
- PDF 원문 경로는 기존 동작을 유지합니다.

## 보호한 범위

이번 작업은 표시와 원본 접근에 한정합니다. Excel 추출·검색 인덱스·BM25·Vector·Hybrid·Chroma·Gemini·출처 선택·전화번호 검색·체크리스트·동의어는 수정하지 않았습니다. DB 구조·원본 파일 삭제·재색인·운영 서버 배포·commit/push/tag도 없습니다.

## 검증 과정

- 직접 다운로드가 허용되던 상태와 기존 엑셀 설명이 남는 상태를 검사로 먼저 재현한 뒤 수정했습니다.
- 코드 검토에서 다운로드 옵션 제거 후 변수 참조가 남는 문제를 발견했습니다. 실제 요청 함수 호출로 실패를 재현한 뒤 정리했고 JSON 요청 검사 통과를 확인했습니다.
- 원본 메타데이터·소속·다른 문서 차단·다운로드 권한, 단일/다중 시트·표·병합·앞자리 0·HTML 안전 출력·근거 강조·PDF와 출처 회귀 검사를 실행했습니다.
- production build 성공. 빌드 경고는 기존 대용량 번들 및 브라우저 호환 패키지 안내입니다.
- 브라우저 직접 확인은 Computer Use가 현재 URL을 충분히 확인하지 못해 중단되었습니다. 우회하지 않았으며 PC 직접 클릭·실제 모바일은 검증하지 않았습니다.
- 실제 AI 답변을 새로 생성하지 않고 기존 답변 출처와 실제 등록 원본으로 읽기 전용 확인합니다. 외부 AI 호출 비용 0원.

## 실행 반영

새 브랜치 `feat/excel-view-only-20261013`. 최신 자료 백업 후 로컬 Docker 3001에 필요한 서버 파일과 화면만 반영하며, 다른 미완료 작업 서버 코드는 포함하지 않습니다. 최종 API·자료 보존 확인 결과는 아래에 기록합니다.

## 최종 확인 결과

- 실제 등록된 `통합전화번호부.xlsx`, `진료지원간호팀 단축번호_업무형태.xlsx` 모두 목록에 원본 보기 참조와 보관 상태가 제공되고, 두 원본의 표 조회가 정상입니다.
- 기존 설정·동의를 마친 실제 직원 권한과 관리자 권한으로 표 조회 200, 시작 행 152 확인. `download=1`, `download=true`, `download=0` 모두 403, 잘못된 참조 404, 비로그인 401 확인.
- 기존 전화번호 답변 출처를 현재 원본 API와 대조해 첫 행 152 및 연두 표시 대상 152~155행을 확인했습니다. 새 AI 답변은 생성하지 않았습니다.
- PDF 원본은 부분 조회 206·PDF 형식·inline 응답 유지 확인.
- 검색·추출·출처 선택 관련 실행 파일 7개가 변경 전 이미지와 SHA256 동일합니다.
- 백업 `3001-excel-view-only-20261013-224841`: 4,316개 파일, 649,267,512바이트를 해시로 검증했습니다. 엑셀 원본·보관 정보 4개 파일도 백업과 동일합니다.
- DB 무결성 정상. 백업과 작업공간 1개·사용자 27명·대화 358개·등록 문서 597개·변경 기록 50개 동일합니다.
- 현재 이미지 `schat-admin-build:excel-view-only-20261013`, 서버 healthy. 코드 검토의 발견 오류를 해결한 뒤 새 중대 결함 없음 확인.
- 최종 자동 검사 31개, production build 통과. 문서 생성·분리 검사도 수행합니다. 실제 PC 클릭·모바일 직접 확인은 도구 제한으로 미검증입니다.

## 사용자가 할 일

화면을 새로고침하면 됩니다. 원본이 이미 보관된 두 엑셀은 재등록할 필요가 없습니다. 과거 실패 답변 자체는 다시 작성되지 않지만 원본 참조가 있는 출처는 새 보기 방식으로 열립니다.
