# 체크리스트 관리자 분류 지정 검증

## 이어받은 상태

- 현재 git diff에 관리자 분류 저장 API, JSON adminKind 저장, presenter 우선순위, 관리자 수정 화면과 기본 테스트가 이미 존재함.
- Claude의 정확한 마지막 실행 시점·메시지는 확인 불가함. 현재 파일 기준으로 기능 구현은 갖춰져 있었고, 이번 작업에서 검증과 문서를 마무리함.
- 기존 구현 파일을 되돌리거나 중복 구현하지 않음. 기능 코드는 추가 수정하지 않고 테스트만 보강함.

## 사용 방법과 저장

- 관리자 체크리스트의 수정 버튼을 누른 뒤 자료 분류에서 자동 분류 사용 / 검사 및 시술 / 수술 / 기타를 선택하고 저장함.
- 자동 분류 선택지에 현재 자동 판단을 표시함. 보기 화면에서는 관리자 지정 여부와 자동 분류 결과를 함께 표시함.
- JSON adminKind가 있으면 이를 우선 사용함. 없으면 checklistAutoKind의 기존 자동 분류를 사용함.
- 자동 분류 사용으로 저장하면 adminKind 필드를 제거함. DB migration은 필요 없음.
- 분류만 바꾸면 내용 수정 API를 호출하지 않음. 제목·별칭·내용·공개 상태와 editedByAdmin 표시를 유지함.
- 반환된 source.kind로 관리자 필터와 카드 배지를 갱신함. 파일을 다시 읽어도 관리자 지정값을 유지함.

## 새 버전

- 기존 원문 일치·자동 공개 검증을 그대로 사용함. 동일한 체크리스트의 이전 공개본과 새 원문이 같고 기존 검증을 통과하면 관리자 분류를 승계함.
- 내용 변경, 신규 항목, 다른 체크리스트 또는 기존 승계 기준 미충족이면 관리자 분류를 자동 승계하지 않음.
- 기존 버전 비교기와 실제 문서 처리 경로를 거치는 동일/변경 두 테스트를 추가해 확인함.

## p.63과 데이터 보존

- 검사 및 시술(26.04.07).pdf p.63 뇌동맥류 : 인터벤션의 실제 JSON을 임시 폴더에 복사하여 검사함.
- 자동 분류 수술 → 관리자 지정 검사 및 시술 → 자동 분류 수술 복귀를 확인함. 재조회 후 저장값 유지도 확인함.
- 원본 PDF 참조·p.63·제목·별칭·내용·검토 필요 상태가 동일함을 확인함.
- 실제 원본 체크리스트 151개의 검증 전후 해시가 동일함. 임시 병원자료 복사본은 검사 후 제거함.
- 필터·배지·직원 질문 연결은 가상 체크리스트로 상태 3종과 분류 4종 조합을 검증함. 실제 직원 계정·API key·Gemini 호출을 사용하지 않음.
