# Query 본문 검색 확장

## 목적

관련 이미지를 정상 표시하는 Query 모드를 유지하면서, Automatic 모드보다 좁았던 본문 근거 검색 범위를 로컬 규칙으로 보완했습니다.

## 변경 내용

- 사용자 원문은 관련 이미지 검색에만 그대로 사용합니다.
- 본문에는 원문과 최대 3개의 로컬 검색 변형을 사용합니다.
- 평가·사정, 절차·단계, 관리·주의사항처럼 의료 문서에서 일반적으로 쓰는 질문 의도를 이용하며 특정 질환이나 약어 목록에만 맞춘 규칙은 사용하지 않습니다.
- 각 변형은 기존 ChromaDB와 BM25 검색을 사용합니다.
- 같은 SourceUnit은 한 번만 남기고 여러 검색에서 반복 확인된 근거를 우선합니다.
- 최종 근거는 일반 질문 4개, 절차 질문 6개를 넘지 않습니다.
- 변형 검색에서는 관련 이미지 후보를 만들지 않아 이미지에는 확장 질문이 사용되지 않습니다.

## 유지한 기능

- Query 모드
- Gemini Embedding과 ChromaDB
- BM25와 기존 관련성·질문 초점 필터
- closed-book 답변 원칙
- structured JSON과 출처 ID 검증
- 관련 이미지 최대 3개 표시
- ChromaDB 기존 데이터와 색인

## 검증

- 먼저 구현 파일이 없는 상태에서 새 회귀 테스트 실패를 확인했습니다.
- NRS, 긴 NRS 평가 질문, FPRS, 수혈 절차, 중심정맥관 관리, 관련 없는 질문의 변형 규칙을 mock으로 확인했습니다.
- 원문 검색만 관련 이미지를 요청하고 변형 검색은 본문만 검색하는 계약을 확인했습니다.
- SourceUnit 중복 제거와 일반 4개 상한을 확인했습니다.
- 관련 Chroma·BM25·이미지·SCHAT 회귀 테스트 69개가 통과했습니다.
- production Docker 이미지 build가 성공했습니다.
- `schat-web`, `schat-chromadb`, `schat-safety-evaluator` 3개가 모두 healthy입니다.
- 실제 Gemini 답변 호출은 실행하지 않았습니다.
