# 2026-09-30 · 체크리스트 보기와 수정 화면을 같은 구조로

## 왜 했나

- 관리자 `체크리스트 관리`에서 "체크리스트 보기"와 "수정" 화면의 모양이 서로 달라서, 원문과 대조하면서 고치기 어려웠음.
- 조사해 보니 체크리스트 화면이 세 가지로 따로 만들어져 있었음.

| 화면 | 이전 모양 |
|---|---|
| 관리자 "체크리스트 보기" | 항목마다 체크박스 1개, 세부 줄은 글자만 있음. ①②③ 줄에 체크박스가 없고 설명 줄 구분도 없음 |
| 관리자 "수정" | 종류 선택, 입력칸, 화살표 버튼을 한 줄씩 늘어놓은 입력 폼. 계층과 들여쓰기가 없음 |
| 직원 화면 | 상위·하위 체크박스, 설명 줄 들여쓰기, 설명 항목(체크박스 없음)이 있는 계층형 |

## 바뀐 동작

- 관리자 "체크리스트 보기", "수정", 직원 화면이 모두 **같은 화면 부품(ChecklistTree)**을 씀.
- "체크리스트 보기"와 "수정"은 한 창임.
  - 보기에서 `수정`을 누르면 같은 자리의 글자가 입력칸으로 바뀜.
  - 저장하면 다시 보기로 돌아가고, 고친 줄이 같은 자리에 표시됨.
  - 취소하면 고친 내용을 버리고 보기로 돌아감.
- 수정 화면에서 바뀌는 것은 다음뿐임.
  - 제목, 찾는 이름, 섹션 이름, 항목 이름, 각 줄이 제자리에서 입력칸으로 바뀜. 긴 줄은 입력칸이 늘어나 보기 화면처럼 여러 줄로 보임.
  - 체크박스는 직원 화면과 같은 자리에 보이지만 눌러지지 않음.
  - 각 줄과 항목 오른쪽에 작은 도구가 붙음: 체크 줄/설명 줄 바꾸기, 위·아래 이동, 삭제, 줄 추가, 항목 추가.
- 창 위쪽에 `원본 보기 p.X` 버튼이 있어서, 수정 중에도 원본 PDF를 열어 대조할 수 있음. PDF 창을 닫아도 고치던 내용은 그대로 남음.
- 목록 카드의 `체크리스트 보기`, `수정`, `원본 보기 p.X` 버튼은 그대로 유지함.
- 따로 있던 "직원 화면 미리보기" 버튼은 없앰. 이제 보기 화면이 곧 직원 화면 모양이기 때문임.
- 예전 관리자 보기 창(`ChecklistModal.jsx`)은 더 이상 쓰는 곳이 없어 지움.

## 바꾸지 않은 것

- 저장 방식(`Checklist.update`), 저장 데이터 형식, 공개·검토 필요·숨김 상태
- 직원 화면의 체크 동작(상위·하위 체크, 취소선, 접기)
- 자동 추출, 새 버전 자동 공개 판정, 동의어, RAG 검색, BM25, Vector, Hybrid, ChromaDB, Citation

## 확인

### 자동 테스트

- 새 화면 테스트 3개(`checklistEditLayout.node.test.mjs`)
  - 요청 예시(동의서 ①②③, 금식여부 설명 줄, IV line 18G와 하위 설명)와 같은 모양의 가상 체크리스트를 실제로 그려 비교함.
  - 보기와 수정의 항목 순서, 계층, 체크박스, 설명 줄 순서가 같음을 확인함.
  - 같은 들여쓰기 칸 안에 있음을 확인함.
  - 수정 화면이 한 줄 입력 목록이 아니라 제자리 입력칸과 도구를 가짐을 확인함.
- 기존 테스트 2개 파일의 기대값을 새 구조에 맞게 바꿈. "관리자 보기는 예전 모양 유지"를 요구하던 테스트였음.
- 화면 테스트 140개 모두 통과
