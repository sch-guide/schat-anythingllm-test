# 직원 화면 공지 띠 개선

## 바꾼 내용

- 공지 띠가 오른쪽 위 버튼(설정·알림·내 정보)을 가리던 문제를 고침. PC에서는 채팅 칸 맨 위에 띠가 한 줄을 따로 차지하고, 버튼과 대화 화면이 띠 높이만큼 내려감. 휴대폰에서는 고정된 맨 위 머리줄 바로 아래에 띠가 붙음. 공지가 없으면 예전과 같음.
- 모양: 둥근 모서리의 연한 청록 띠(바탕 #ecfdf8, 테두리 #bfe8dc, 제목 #0f766e 굵게). 순서는 📢 → 제목 → 세로 구분선 → 공지 글 → ✕. "자세히 보기"는 없음.
- 제목: 관리자 > 브랜드 관리 > 직원 화면 공지에 `제목` 칸을 추가함. 기본값 `공지사항`, 최대 8자, 비우면 `공지사항`으로 보임, 제목 옆 [원래대로]는 `공지사항`으로 되돌림. 기존 브랜드 설정 저장값(`schat_brand`)에 함께 저장하며 DB 구조는 바꾸지 않음. 제목이 없던 예전 공지는 `공지사항`으로 보임.
- 흐르는 글: 칸보다 긴 글만 오른쪽에서 왼쪽으로 1초에 약 50px로 흐르며 반복함. 짧은 글은 그대로 보임. 마우스를 올리거나 누르고 있으면 멈춤. 컴퓨터의 '움직임 줄이기'를 켠 사람에게는 말줄임(…)으로 보이고 누르면 전체가 펼쳐짐. 띠 양 끝은 글이 흐리게 사라짐.
- ✕ 닫기: 그 브라우저에서 그날은 다시 안 보임. 제목이나 내용이 바뀌거나 날짜가 바뀌면 다시 보임(브라우저 저장소에 날짜와 공지 지문만 저장).
- 관리자 미리보기: 공지 칸 아래에 실제 띠 모양 미리보기를 보여 주고, 제목·내용을 고치면 바로 바뀜.
- 공지 켜기, 시작·종료 일시는 그대로 동작함.

## 확인

- 서버 브랜드 테스트 7개 통과(제목 8자 제한, 빈 제목, 예전 공지, 초기화). 화면 브랜드 테스트 12개 통과(제목 기본값, 그날만 닫기, 내용·제목 변경 시 다시 보임, 띠 순서와 색, 자세히 보기 없음, 버튼 위치, 관리자 제목칸과 미리보기).
- 마지막 커밋에 이 변경만 넣은 복사본에서 화면 테스트 313개 중 310개 통과. 실패 3개는 이 변경 전에도 실패하던 메뉴 아이콘·문서 목록 테스트임.

## 함께 고친 문제

- 브랜드 설정 저장소가 브라우저 타이머를 잘못된 대상으로 불러 Chrome에서 "Illegal invocation" 오류가 나고, 직원 채팅 화면 전체가 오류 화면으로 바뀌던 문제를 고침(공지 기능을 처음 넣은 `231bd277`부터 있던 문제). 옛 코드에서 실패하고 고친 코드에서 통과하는 테스트를 추가함.
- 공지 도우미 파일에 보이지 않는 0번 글자가 들어가 Git이 바이너리 파일로 보던 문제를 `\u0000` 표기로 바꿈. 값은 같음.
- 휴대폰에서 손가락을 떼도 흐르는 글이 멈춰 있던 문제를 고침. 마우스 올림과 누르고 있음을 따로 판단함.

## 로컬 3001 화면 확인

- PC(1280px): 공지가 없으면 버튼 위치가 예전과 같음(위에서 36px). 공지가 있으면 띠가 25~65px에 있고 버튼은 88px로 내려가 겹치지 않음. 짧은 글은 그대로, 긴 글은 2초에 약 100px 흐름. 마우스를 올리거나 누르면 멈추고 떼면 다시 흐름.
- 움직임 줄이기: 말줄임으로 보이고 누르면 펼쳐짐. 펼친 높이만큼 버튼도 더 내려가 겹치지 않음.
- 휴대폰(390px, iPhone): 띠가 맨 위 머리줄 아래(73~113px)에 붙고, 머리줄 버튼(12~47px)과 겹치지 않음. 손가락으로 누르면 멈추고 떼면 다시 흐름.
- ✕: 닫으면 사라지고 버튼이 원래 위치로 돌아감. 같은 날 새로고침해도 안 보이고, 날짜가 바뀌거나 제목·내용이 바뀌면 다시 보임.
- 관리자: 제목칸은 8자까지만 입력됨. 미리보기가 바로 바뀌고, 제목 [원래대로]와 빈 제목은 `공지사항`으로 보임.
- 확인 뒤 로컬 공지 설정은 확인 전 값으로 되돌림. DB 구조 변경과 새 마이그레이션은 없음.
