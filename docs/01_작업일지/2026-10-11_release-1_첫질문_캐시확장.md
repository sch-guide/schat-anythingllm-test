# release-1 일반 채팅 첫 질문 답변 재사용

## 변경

- SCHAT 지침 기반 답변에서 일반 채팅 모드도 새 대화의 첫 질문이면 답변 재사용 대상으로 허용함. 이전에는 query 모드만 허용했음.
- 과거 대화가 있거나 개인 첨부 자료·명령·Agent 요청이면 기존대로 재사용하지 않음. 자동 모델 선택 모드와 native 임베딩 제외 규칙도 유지함.
- 부서·문서·모델·설정이 같은 경우만 재사용함. 일반 chat과 query 답변도 서로 섞지 않음.
- 재사용 답변의 출처와 표시 자료는 유지하며 대기열과 실제 생성 호출을 건너뜀. 저장된 채팅에 재사용 표시와 토큰 0을 기록하는 기존 동작은 그대로 사용함.
- 저장 방식은 기존 서버 메모리 방식임. 서버 재시작 시 비워짐. 이번 변경은 영구 저장 기능이 아님.

## 검증

- 새 동작 검사 2개가 기존 코드에서 실패함을 확인한 뒤 허용 모드 조건만 수정함.
- 캐시·첫 질문·실제 스트리밍 함수에 가짜 응답 연결·문서 변경 연동 검사 총 24개 통과함.
- 새 대화 첫 질문 재사용, 후속 질문 재생성, 출처 보존, 대기열 우회, 다른 부서/문서/모델과 개인 자료 제외를 검사함.
- 시험은 가짜 DB와 가짜 모델을 사용함. 실제 브라우저나 Gemini 응답 시험 결과는 아님.
- 3001/3002/3003 재시작·실제 API 호출·push는 하지 않음.

## 나중에 직접 확인

1. 이 커밋을 적용한 확인 환경에서 일반 채팅의 새 대화를 열고 합성 문서 질문을 보냄.
2. 또 다른 새 대화에서 동일 질문을 보내고 관리자 답변 재사용의 사용 횟수가 늘어나는지 확인함.
3. 같은 대화의 후속 질문은 재사용 횟수가 늘지 않는지 확인함. 현재 실행 중인 3003에는 아직 새 코드를 반영하지 않음.
