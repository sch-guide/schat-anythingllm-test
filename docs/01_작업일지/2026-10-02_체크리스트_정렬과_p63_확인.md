# 체크리스트 정렬과 p.63 확인

## 수정 내용

- 기존 문서명·쪽 정렬을 유지하고 같은 쪽에서는 고정 checklist ID로 순서를 정함.
- 문서가 바뀌는 곳에 문서명을 표시함. 자료 필터는 PDF 이름이 아닌 체크리스트 종류라는 안내를 추가함.
- 상태 4종과 자료 4종의 모든 조합에 공통 정렬을 적용함.
- 변경 전 동일 쪽 순서 테스트 실패를 확인한 뒤 최소 수정함.

## p.63 조사

- 로컬 원본 PDF 82쪽 중 p.63을 실제 이미지로 확인함. 제목은 뇌동맥류 : 인터벤션이며 시술 전·후, 병합 셀과 Prepare 안쪽 표가 있는 구조임.
- p.63 JSON이 이미 존재함. autoGenerated=true, needs_review, draft-nonstandard-page 표시를 확인함. 저장 누락이나 관리자 목록 제외가 아니라 기존 분류·상태 필터의 영향임.
- 관리자용 목록 변환 결과에서 p.63이 수술·검토 필요로 포함됨. 검사 및 시술 필터 또는 공개 필터에서는 제외됨.
- p.62 신루설치술 PCN과 p.64 디지털 감산 뇌혈관 조영술 : TFCA는 검사 및 시술·공개 상태임. 상태·자료 전체에서 p.62 → p.63 → p.64 순서를 확인함.
- DB 시스템 기록의 체크리스트 관련 이벤트 1개를 조사했으며 p.63을 가리키는 실패 기록은 찾지 못함. 과거 추출의 정확한 시각·시도 횟수·최초 반환 개수는 현재 기록만으로 확인 불가함. 저장된 자동 생성 초안은 확인됨.
- 이미 저장된 항목이므로 추출기 재실행·수정·재저장·공개 처리를 하지 않음. 자료 분류도 변경하지 않음.

## 검증

- 관리자 정렬·저장·자동 공개·버전 승계 관련 테스트 40/40 통과함. JSX 화면 코드 문법 검사 통과함.
- 실제 로컬 체크리스트 151개로 16가지 필터 조합과 입력 순서 반전 검사를 통과함. 검사 및 시술 76개, 수술 75개, 기타 0개를 확인함.
- 검증 전후 151개 JSON의 해시가 동일함. 내용·공개 상태·원본 PDF 연결을 변경하지 않음.
- Docker schat-web, schat-chromadb, schat-safety-evaluator healthy 상태를 확인함.
- 연결 가능한 브라우저가 없어 Docker 3001 관리자 화면의 실제 클릭·배치 검증은 하지 못함. Docker 재빌드나 운영 반영을 하지 않음. 현재 실행 화면에 이번 수정이 반영됐다고 판단하지 않음.
- RAG·Citation·Chroma·직원 연결 코드는 이번 작업에서 수정하지 않음. 해당 기능 전체의 실제 실행 재검증은 하지 않음.
- 기존 미완료 변경과 체크리스트 JSON 파일을 보존함. commit·push·tag를 하지 않음.
