# 검색 거르기 수정과 재검색 방식 C 준비

## 1. 검색 거르기 수정

### 무엇이 문제였나

- 검색 마지막 거르기에서 문서가 통과하려면 둘 중 하나가 필요합니다.
  - 질문 단어의 2/3 이상이 문서에 그대로 있습니다.
  - 또는 의미 유사도가 0.7 이상입니다.
- "사진으로 보여줘", "알려줘" 같은 **요청 표현도 질문 단어로 세어서**, 문서에 근거가 있어도 2/3를 못 채우고 빠졌습니다.
- 약어 질문(PTNB 후 간호 알려줘)은 문서에 "PTNB"가 있는데도 "간호"·"알려줘"가 없어서 빠졌습니다.

### 바꾼 것

- 요청 표현은 **단어 일치율 계산에서만** 뺍니다. 검색 점수 자체는 그대로입니다.
- 기준값(2/3, 0.7)은 **바꾸지 않았습니다.**
- 질문에 3글자 이상 영문 약어가 있고 문서에 그 약어가 **단어 그대로** 있으면 통과시킵니다.
  - 예: "PTNBX"는 "PTNB"로 치지 않습니다.

### 일치율 계산에서 빼는 요청 표현

| 종류 | 표현 |
|---|---|
| 보여 달라는 말 | 사진, 그림, 이미지, 도식, 도표, 그래프, 영상, 보여줘, 보여주세요, 보여줄래, 보여줄, 보여 |
| 알려 달라는 말 | 알려줘, 알려주세요, 알려줄래, 가르쳐줘, 설명해주, 정리해줘, 요약해줘, 자세히, 간단히, 궁금해, 궁금해요, 궁금합니다, 부탁해, 부탁해요 |
| 오타 | 알랴줘, 알렺줘 |
| 대화체 끝말 | 어때, 의미야, 뭐예요, 뭔가요, 뭔지, 받아야해, 받아야할까, 받아야, 할까, 할까요, 해야해, 했는데, 했을, 됐는데, 되나요, 하나요, 있나요 |

- 요청받은 표현 외에 **직원 질문 204개에서 새로 찾은 것:** 보여줘, 자세히, 어때, 의미야, 설명해주, 받아야해, 받아야할까, 받아야, 할까, 해야해, 했는데, 했을, 됐는데, 오타 알랴줘·알렺줘.
- 질문이 요청 표현만으로 되어 있으면(예: "사진 보여줘") 원래대로 모든 단어를 셉니다.
- 내용 단어의 오타(수헐, 진절 등)와 붙여 쓴 말(통증척도 등)은 이번에 손대지 않았습니다.

### 검색 결과 변화 (25개 질문)

- 바뀐 것은 3개뿐이고, 나머지 22개는 전과 같습니다.
  - PTNB 후 간호: 근거 없음 → 검사 및 시술 p.15
  - 혈액제제 종류를 사진으로: 근거 없음 → p.125
  - 수혈 세트 그림: 근거 없음 → p.125~127, p.116과 이미지 1개
- 지침서에 없는 질문 5개(스케일링, TAVI, 라식, 치아 미백, 골프 엘보)는 모두 **"확인되지 않습니다"로 답했습니다.**

### 결과

- **Q05(PTNB 후 간호): 해결.** 정상 답변하고 p.15를 출처로 붙입니다.
- **Q09·Q10은 아직 "확인되지 않습니다"로 답합니다.** 남은 원인은 다른 곳에 있습니다.
  - Q09(혈액제제 종류 사진)
    - "종류"라는 단어 때문에 혈액제제 표(p.113~114) 대신 "수혈세트의 종류"(p.125)가 잡힙니다.
    - 이전부터 있던 문제입니다. "혈액제제 종류"만 물어도 같습니다.
  - Q10(수혈 세트 그림)
    - 수혈 세트 사진(p.115)은 후보에 있습니다.
    - 하지만 이미지는 **같은 쪽의 글 근거가 있을 때만** 출처에 붙는 규칙 때문에 붙지 않습니다.
    - 그 결과 AI가 그림이 없다고 판단합니다.
  - 둘 다 **출처 이미지 붙이기 규칙이나 검색 순위를 바꿔야 해서**, "기존 Citation 기능을 바꾸지 말라"는 요청에 따라 승인 전까지 고치지 않았습니다.

## 2. 재검색 방식 C (준비만, 기본 꺼짐)

### 동작

- 미리 검색한 근거가 충분하면 검색 도구 없이 바로 답합니다.
- 부족하면 AI가 추가 검색을 **최대 2회**까지만 할 수 있습니다.
- 한도를 넘는 검색 요청은 코드가 실행하지 않습니다.
  - 지금까지 받은 근거만으로 답하게 다시 요청합니다.
  - 그래도 AI가 검색만 요청하면 "등록된 문서에서 확인되지 않습니다."로 답합니다.
- 켜는 설정: `SCHAT_AGENT_RESEARCH_MODE=bounded`. 기본은 꺼져 있어 지금 서비스 동작은 그대로입니다.

### "근거가 충분하다"의 기준

- 미리 검색에서 **서로 다른 근거 조각이 3개 이상** 나와야 합니다.
- 그 조각들이 **2쪽 이상에 걸쳐** 있어야 합니다.
- 조각이 1~2개뿐이거나 모두 한 쪽에서만 나오면 부족하다고 보고 추가 검색을 허용합니다.

### 비교 결과 (15개 질문 × 현재·방식 C 각 1회)

| 구분 | 방식 | 첫 글자까지 | 답변 완료 | 추가 검색 | 입력 토큰 |
|---|---|---|---|---|---|
| 대표 질문 10개 | 현재 | 8.5초 | 10.7초 | 1.6회 | 5,857 |
| 대표 질문 10개 | 방식 C | 6.2초 | 8.2초 | 1.3회 | 4,287 |
| 없는 질문 5개 | 현재 | 10.5초 | 10.6초 | 3.0회 | 55,333 |
| 없는 질문 5개 | 방식 C | 5.7초 | 5.7초 | 1.6회 | 3,107 |

- 방식 C는 모든 실행에서 추가 검색이 **2회 이하**였습니다. 현재 방식은 최대 4회였습니다.
- 한도를 지키는 동작은 자동 테스트로도 확인했습니다. AI가 계속 검색을 요청해도 2회만 실행합니다.
- **품질 우려: Q02(수혈 종류)**
  - 방식 C에서 "확인되지 않습니다"로 답했습니다.
  - 미리 검색 근거가 한 쪽(p.113)뿐이라 부족으로 판정됐고, 추가 검색 2회 후에도 답을 만들지 못했습니다.
- 현재 방식의 Q02도 이번에는 전보다 짧게 답했습니다(246자, 지난 측정 1,274자).
  - 검색 결과는 같았고, AI가 재검색을 몇 번 하느냐에 따라 매번 달라지는 차이입니다.
- 없는 질문은 두 방식 모두 "확인되지 않습니다"로 답했습니다.
  - 현재 방식은 N02에서 "TAVI(경도관 대동맥판막 삽입술)"처럼 문서에 없는 약어 풀이를 붙였습니다.
  - 간호 내용을 지어내지는 않았습니다.
- 한 번씩만 측정해서 결과가 흔들릴 수 있습니다. 방식 C를 켜기 전에 반복 측정이 필요합니다.
