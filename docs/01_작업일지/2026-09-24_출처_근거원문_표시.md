# 출처 상세에 근거 원문 표시

## 결과

출처 번호를 누르면 기존 문서명·페이지·항목명 아래에 해당 답변을 뒷받침한 등록 지침의 원문 범위를 함께 확인할 수 있도록 개선했습니다.

## 변경 범위

- 서버는 답변에서 실제 사용했다고 검증된 SourceUnit의 `exact_text`만 공개용 excerpt로 변환합니다.
- 공개 데이터는 문서명, 페이지, 항목명과 excerpt만 포함하며 내부 ID, 내부 경로, metadata와 SVG는 제거합니다.
- 긴 원문은 문장 또는 문단이 끝난 위치에서만 줄입니다. 안전한 경계를 찾을 수 없으면 과거 대화와 같은 metadata-only 표시를 사용합니다.
- `text`에는 `excerpt`와 같은 값을 넣어 기존 AnythingLLM 출처 화면과의 호환성을 유지했습니다.
- PC와 모바일 출처 상세에 `근거 원문` 라벨, 1.6 줄 간격과 내부 스크롤을 적용했습니다.
- 원문이 없는 과거 대화는 기존 문서명·페이지·항목명만 표시합니다.
- 한 답변 항목에 출처 번호가 여러 개면 누른 번호에 해당하는 한 출처만 표시하는 기존 연결을 유지했습니다.

## 변경하지 않은 것

- 검색, ChromaDB, BM25, Gemini prompt와 safety gate
- 답변 임상 내용, structured response와 `sourceIndexes`
- 색인과 저장 데이터

## 확인

- 서버 excerpt 공개·정제·문장 경계 축약·과거 데이터 호환 mock 3건 통과
- Gate OFF structured 응답과 검증된 SourceUnit 연결 회귀 검사 7건 통과
- 모바일 원문 표시·metadata-only 호환 렌더링 2건 통과
- 여러 출처 번호별 source 연결과 기존 presentation 회귀 검사 3건 통과
- frontend production build와 전체 Docker image build 성공
- 실제 Gemini 호출 없음
