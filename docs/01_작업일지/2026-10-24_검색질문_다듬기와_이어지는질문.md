# 검색용 질문 다듬기·이어지는 질문·계산 허용 (3001 반영)

- 날짜: 2026-10-24
- 요청 사례: ① "PC 수혈은 얼마동안 줘?"(정답) 다음 "4Pint 면 20분~30분 안에 끝나도 괜찮지?" → "등록된 문서에서 확인되지 않습니다". ② "Cag"(정상) / "Cag체크리스트" → "확인되지 않습니다", 체크리스트 버튼도 안 뜸.
- 상태: 3001 반영(코드·동의어·답변 규칙). GitHub·운영 미반영.

## 지금 흐름 (질문 → 검색 → 답)

1. 직원 질문 → `aibitat/index.js`가 검색용 질문을 만든다(`buildHospitalRetrievalQuery`). 이전 대화는 "그중·그거·그 다음·그 후"가 있을 때만 앞 질문 주제를 붙였다.
2. 간호 용어·영어 약어가 있으면 답하기 전에 문서를 먼저 찾는다(`forceHospitalRagSearch` → `memory.js` → Chroma 의미 검색 + BM25 단어 검색 75:25, 근거 4개, 기준 점수 0.25, 약한 꼬리 제거).
3. 근거가 0개면 "근거 없음" 안내로 AI가 "등록된 문서에서 확인되지 않습니다."라고 답한다. 근거가 있으면 관리자 답변 규칙(2번: 근거가 없거나 부족하면 "확인되지 않습니다"만)으로 답한다.
4. 체크리스트 버튼: 직원 화면이 질문 글자와 체크리스트 이름·찾기용 이름을 대소문자 구분 없이 비교해 띄운다. 단, 답이 "확인되지 않습니다"면 띄우지 않는다.

## 원인 (복사본에서 재현)

- ① "4Pint 면 …"은 "그중" 같은 말이 없어 앞 질문(PC 수혈) 없이 검색 → 근거 0개. "PC 수혈 4Pint 면 …"으로 찾으면 수혈 쪽이 나옴.
- ② "Cag체크리스트"는 근거 0개, "CAG 체크리스트"는 검사 및 시술 66쪽(CAG/PCI). 붙여 쓴 글자가 의미 검색을 흐림. 체크리스트 버튼은 판단 규칙은 맞지만 답이 "확인되지 않습니다"라 안 뜸.
- 고치는 중 발견: "PC 수혈은 얼마동안 줘?"는 문서 말("주입 시간")과 달라 주입 시간 표(114쪽, 1 Unit당 10분)를 못 찾음. 예전 정답은 이전 대화에서 나온 것으로 보임.
- 동의어: CAG = 관상동맥조영술은 자동 제안만 있고 "검토 필요"(미적용), Pint = Unit 없음.

## 수정

- 새 파일 `server/utils/agents/aibitat/utils/searchQuestion.js`(검색어에만 적용, 화면의 원래 질문은 그대로)
  - 정리: 영어·한글 붙은 곳 띄우기, "4Pint"→"4 Pint", 대문자가 섞인 2~4글자·소문자 3글자 약어 대문자(cag→CAG, 단위 제외), "체크리스트·준비물·알려줘·보여줘·좀" 빼기, "얼마동안 줘·몇 분 동안 줘·얼마나 빨리 줘·주입 얼마나 걸려" → "주입 시간".
  - 이어지는 질문: 앞 질문이 있고 "그럼·그거·괜찮·해도·~면" 같은 이어 말하기 표현이 있으면 답변 모델로 혼자 뜻이 통하는 검색 질문 한 문장으로 다시 씀(최대 2.5초, 실패하면 앞 질문과 이어 붙임). AI에게는 다시 쓴 질문을 먼저 보여 주고 원래 말을 함께 줌(뒤에 덧붙이면 "Pint"만 보고 RBC로 답한 일이 있었음). `SCHAT_FOLLOW_UP_REWRITE=off`로 끔.
- 동의어(3001 DB): CAG = 관상동맥조영술 = CoronaryAngiography 승인, Pint = Unit 추가.
- 관리자 답변 규칙(3001 DB, 사용자 요청) 2·3번:
  - 2. 질문과 관련된 근거가 전혀 없을 때만 "등록된 문서에서 확인되지 않습니다."라고 답하세요. 근거가 일부라도 있으면 근거에 있는 내용으로 답하고, 근거에 없는 부분만 확인되지 않는다고 밝히세요.
  - 3. 숫자, 용량, 시간, 빈도, 단위, 기준값은 문서 그대로 인용하세요. 문서 근거의 수치로 간단한 계산이나 적용(예: 단위당 시간 × 단위 수)을 할 때는 근거 수치와 계산 과정을 함께 보여 주고, 결과를 반올림하지 마세요.
