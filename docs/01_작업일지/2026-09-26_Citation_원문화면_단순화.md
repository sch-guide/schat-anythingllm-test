# 2026-09-26 · Citation 원문 화면 단순화

## 변경 내용

- 답변 아래에서 중복되던 별도 `출처` 버튼과 아이콘 묶음을 제거했습니다.
- `출처 1 · 파일명 · 페이지 · 항목명` Citation 행만 남겼습니다.
- `근거 원문 보기`를 펼쳤을 때 원문 다음에 해당 출처와 직접 연결된 이미지를 표시하는 기존 순서를 유지했습니다.
- 원문 영역은 모바일 좌우 16px, 넓은 화면 28px 여백과 최대 720px 읽기 폭, 1.7 행간, 문단 간격을 적용했습니다.
- 긴 원문의 더보기·접기와 내부 스크롤, 라이트·다크 모드 스타일을 유지했습니다.

## 보존한 기능

- `source.relatedImages` 데이터와 기존 `RelatedImages` 컴포넌트를 그대로 사용합니다.
- 직접 이미지가 없는 출처에는 이미지 영역을 표시하지 않습니다.
- 백엔드, API, DB, ChromaDB, 검색과 AgentHandler는 변경하지 않았습니다.

## 검증

- 변경 전 실패 테스트에서 중복 출처 버튼과 좁은 원문 여백을 재현했습니다.
- Citation 회귀 테스트 10개가 통과했습니다.
- production Docker image build가 통과했습니다.
