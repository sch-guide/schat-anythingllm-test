# 직원 채팅에 이미지 1장 입력 추가

## 무엇이 바뀌었나요?

직원이 SCHAT 채팅창에서 이미지 1장을 첨부하고 질문할 수 있게 준비했습니다.

- 사용할 수 있는 형식: JPG, JPEG, PNG, WebP
- 최대 크기: 5MB
- 한 번에 첨부할 수 있는 수: 1장
- 질문 글은 반드시 함께 입력해야 함

채팅창에는 환자 이름, 등록번호, 생년월일 등 개인정보가 포함된 이미지를 올리지 말라는 안내가 표시됩니다.

## 답변은 어떻게 만들어지나요?

1. 질문 글로 SCHAT에 등록된 병원 문서를 검색합니다.
2. 이미지는 질문 상황을 이해하는 보조자료로만 Gemini에 전달합니다.
3. Gemini는 검색된 병원 근거의 `SourceUnit`만 사용해 구조화된 답변 후보를 만듭니다.
4. 기존 Python 안전검사가 숫자·단위·시간·조건·금기·부정·행위·근거 연결을 검사합니다.
5. 검사에 통과한 답변만 직원 화면에 표시합니다.
6. 검사에 실패하면 Gemini 후보는 숨기고 원문 기반 안전 답변을 표시합니다.

등록 문서에서 근거를 찾지 못하면 근거 부족 안내를 표시합니다.

## 개인정보 보호

- 이미지는 병원 문서 검색용 데이터베이스에 넣지 않습니다.
- 이미지 원문과 Gemini 원본 응답을 일반 로그에 저장하지 않습니다.
- 안전 채팅 기록에는 이미지 원문을 저장하지 않습니다.
- 별도 임시파일을 만들지 않고 메모리에서 처리합니다.
- 과거 대화 전체, 직원 계정정보, 전체 데이터베이스는 Gemini에 보내지 않습니다.

## 확인한 내용

- 지원 형식, 1장 제한, 5MB 제한
- 이미지가 없는 기존 문자 질문 유지
- 이미지 후보는 Python 안전검사 통과 후에만 표시
- 근거 없는 이미지 임상 사실은 원문 기반 답변으로 대체
- 잘못된 이미지는 Gemini 호출 없이 차단
- 자동 재시도 0회
- 화면과 서버가 포함된 Docker 이미지 빌드 성공

실제 Gemini 이미지 호출은 아직 실행하지 않았습니다. 승인된 비민감 이미지로 사람이 직접 웹 검수를 하기 전까지 시범 기능 상태입니다.
