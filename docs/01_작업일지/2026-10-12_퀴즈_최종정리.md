# 퀴즈 최종 정리 (release-admin-9)

## 요청과 범위

- 사용자 최종 지시가 이전 퀴즈 지시보다 우선함. 초기화 버튼·확인 창(화면과 서버), [삭제한 퀴즈]·[되살리기], "이전 지침 기준" 배지를 제거함.
- [삭제]는 진짜 삭제: 문제와 그 문제의 직원 풀이 기록·오답노트를 바로 지우고 되살리기·별도 보관 없음. 퀴즈가 아닌 자료는 건드리지 않음.
- 이전 문서 퀴즈는 삭제 전이라도 직원 화면(문제·오답노트·풀이 기록)에서 숨기고 점수·정답률·관리자 통계에서 뺌.
- 같은 이름 문서 교체 시 근거 문장을 새 버전과 글자로 비교(AI 없음). 그대로면 새 버전에 연결, 숫자·단위 변경 또는 못 찾음이면 이전 문서.
- DB 구조 변경 금지, Gemini 호출 금지, 실제 서버 미변경.

## 먼저 확인한 것

- 퀴즈 문제 표에 근거 문장 칸(`source_excerpt`)이 이미 있고, 문제 생성 때 원문에서 찾은 근거 문장이 저장됨(못 찾으면 그 쪽 앞부분 600자). 새 표·칸이 필요하지 않음.
- 3001 실제 퀴즈 15개 모두 근거 문장 있음, 이전 문서 0개, 삭제 상태 0개(읽기만 함).
- 문서 교체는 새 문서 번호를 만들고 옛 행을 보관 표시함. 퀴즈의 문서 번호·쪽 번호만 새 값으로 바꾸면 기존 칸으로 연결 가능.

## 구현 (772c6d31)

- 서버: 초기화·안내·되살리기 기능과 경로 제거. 삭제 전 개수 확인 경로 추가, 삭제는 확인 창에서 본 개수와 같을 때만 실행. 지운 문제가 들어 있던 풀이 회차는 남은 문제로 점수 재계산(남은 문제 없으면 회차 삭제).
- 직원 화면용 계산: 지금 있는 문서의 문제만 보이게 하고 점수·정답률을 보이는 문제 기준으로 계산. 관리자 통계도 같은 기준이며 "제외한 답 N개" 표시.
- 비교 규칙(`compareEvidence`): 띄어쓰기·줄바꿈·글머리 기호 무시, 숫자 앞뒤 경계 확인("5 mg"≠"25 mg"), 쪽 경계 문장도 찾음. 숫자만 다르면 "바뀜", 그 외 불일치는 "못 찾음". 목록 번호 변경은 안전하게 "바뀜".
- 문서 교체가 끝난 직후 비교·연결하고 "퀴즈 N개 중 계속 사용 N · 이전 문서 N" 표시. 이 단계가 실패해도 끝난 교체는 되돌리지 않고 확인 안내만 남김.
