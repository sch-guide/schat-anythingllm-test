# 체크리스트 수술명으로 찾기와 한 쪽 두 양식 분리 (3001 반영)

- 날짜: 2026-10-15
- 요청: "폐엽절제술", "lobectomy"로 물으면 체크리스트가 안 뜨고 "폐암"으로 물어야 뜸. 이런 경우를 점검하고 고침.
- 상태: 3001 반영 완료. 운영 반영과 GitHub 업로드는 하지 않음.

## 원인

1. 수술 문서 체크리스트 이름은 쪽 위 병명(예: `폐암 Lung cancer`)에서만 만들어짐. 바로 아래 `수술명 : 폐엽절제술(Lobectomy), …` 줄은 이름에 들어가지 않음.
2. 한 쪽에 양식이 두 개(왼쪽·오른쪽)이고 한쪽이 `수 술 전`, 다른 쪽이 `검 사 전` 양식이면 쪽을 나누지 않아 두 양식이 하나로 합쳐지거나 하나가 빠짐. 이때 본문 글자(`Prepare`, `수술실/S-car`, `금식여부 MN NPO …`)가 체크리스트 이름에 들어가 "수술실 이동"처럼 흔한 질문에 엉뚱한 체크리스트가 뜸.
3. 일반 양식을 `수술목적`·`수술장소/이동수단`으로 적은 쪽은 양식으로 알아보지 못함. 일부만 못 읽은 경우 관리자 기록에도 남지 않음.

## 수정

- 새 파일 `server/utils/documentChecklists/sourceNames.js`: 등록 문서 쪽 글자에서 병명·수술명·시술명·검사명을 읽어 체크리스트 찾기용 이름(searchAliases)에 더함. 한 쪽에 체크리스트가 둘이면 제목이 들어 있는 부분끼리 짝지음. **저장된 체크리스트는 바꾸지 않음**(이미 등록된 문서에도 바로 적용).
- `presenter.js`: 원문 이름 더하기. 직원 화면에서는 양식 본문 글자로 된 예전 이름을 뺌(관리자 화면·저장 내용은 그대로).
- `procedureExtractor.js`: 일반 양식이 `수술 전/후`·`시술 전/후` 표시와 `수술목적`·`수술장소/이동수단` 이름도 알아봄. 두 양식이 모두 맞으면 수술 양식을 씀. 한 쪽 여러 양식 중 못 읽은 수를 셈.
- `processDocuments.js`: 일부 양식을 못 읽으면 관리자 기록에 `region-not-recognised`(한 쪽의 양식 중 일부를 읽지 못함)로 남김.
