# 2026-09-25 · SCHAT 설명 화면 자동화

날짜별 작업일지가 먼저 보이던 문서 화면을 비개발자가 SCHAT 전체 구조를 이해하기 쉬운 프로젝트 설명 화면으로 바꿨습니다.

## 바뀐 화면

- SCHAT 한눈에 보기
- 문서 등록부터 답변과 출처 확인까지의 동작 방식
- 클릭해서 역할을 확인하는 주요 폴더 구성
- 실제 Compose와 코드에서 확인한 기술 구성
- 완료·진행 중·예정 상태와 안전장치
- 기본으로 접혀 있는 날짜별 변경 이력
- 실행, 문서 등록, 필수 검사와 문제 확인 순서를 포함한 인수인계 안내

## 자동 갱신

`문서도구/SCHAT_개요데이터_만들기.py`가 안전하게 허용된 저장소 설정과 공식 문서를 읽어 `docs_view/schat-overview-data.json`을 만듭니다. 기존 `문서화면_만들기.py`는 이 데이터로 HTML을 함께 생성합니다.

frontend 개발·production build 시작 전과 Git pre-commit에서 갱신을 시도합니다. Python을 찾지 못하거나 생성에 실패하면 경고만 표시하고 앱 실행, build와 commit은 막지 않습니다.

## 보안 범위

- 실제 `.env`를 읽지 않습니다.
- API 키, 비밀번호와 token을 공개 데이터에 넣지 않습니다.
- PDF와 병원 문서 본문, ChromaDB 저장 내용과 진단 로그를 읽지 않습니다.
- 내부 ID, Git hash와 절대 경로를 기본 화면에 표시하지 않습니다.
- SCHAT 검색, 답변, embedding, ChromaDB, BM25, 업로드와 사용자 기능은 변경하지 않았습니다.

## 검증

- fixture 설정 변경이 개요 JSON에 반영되는지 확인했습니다.
- 가짜 `.env` 비밀값이 JSON과 HTML에 들어가지 않는지 확인했습니다.
- 6개 화면 섹션, 모바일 CSS, 폴더와 변경 이력 접기/펼치기를 검사했습니다.
- 자동 갱신 대상 경로와 실패 비차단 동작을 검사했습니다.
- 기존 문서 화면 분리 검사와 저장 결과 일치 검사를 유지했습니다.
