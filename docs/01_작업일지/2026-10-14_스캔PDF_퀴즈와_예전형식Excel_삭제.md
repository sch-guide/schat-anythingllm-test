# 스캔 PDF 퀴즈 안내와 예전 형식 Excel 삭제

## 운영 데이터 확인 (읽기 전용 점검, 2026-10-14)
- 「실무지침서_중심정맥관.pdf」 현재 문서(79b48e5d): 퀴즈가 현재 문서 번호를 사용하고, 검색 데이터 연결 30조각 모두 현재 번호, 남은 퀴즈 0개. 옛 문서(a540f63b)는 보관 행 15개.
- 15쪽 모두 본문이 정확히 30자(머리글), 그림 설명도 15쪽 모두 정확히 77자. '중심정맥관' 단어가 본문·그림 설명 어디에도 없음. SCHAT 안에 문서 내용이 없어 퀴즈·채팅 모두 이 문서로는 근거를 만들 수 없음(스캔·그림 글자 PDF로 추정).
- 예전 Excel 2개(`… .xlsx - Sheet:Sheet1`)는 문서 번호(document_id)가 없는 예전 형식 파일. 문서 등록 창은 이름으로 묶어 보여 주지만 안전 점검 열쇠가 없어 "안전 점검 결과가 아직 없어요"가 뜨고, 점검은 "읽을 수 없는 페이지 기록"(확인 필요)으로 막았음.

## 수정
- 퀴즈(퀴즈 생성에만 적용): 근거가 3쪽 이상인데 쪽당 평균 60자 미만이면 AI를 부르지 않고 "읽을 수 있는 본문 글자가 거의 없어 … 글자가 들어 있는 PDF로 다시 등록해 주세요"로 안내. 근거가 아예 없을 때의 기존 안내는 유지.
- 삭제 점검: 문서 번호 없이 이름이 있는 예전 형식 파일은 이름으로 묶어 점검. 등록돼 있으면 현재 사용 중, 아니면 예전 업로드(삭제 가능). 문서 번호가 없으므로 검색·퀴즈·체크리스트·과거 답변·원본이 가리킬 수 없음. 삭제 대상은 그 쪽 파일과 캐시뿐. 내용을 읽을 수 없는 파일만 계속 "확인 필요".
- 문서 등록 창: 문서 번호 없는 항목도 이름으로 안전 점검 결과를 찾음.
- 수정 파일: `server/utils/schatQuiz/generation.js`, `server/utils/schatAdmin/storageCleanup.js`, `server/utils/documentLibrary.js`, `server/endpoints/workspaces.js`, 관련 자동 검사. RAG·BM25·Vector·Hybrid·Chroma·Citation 변경 없음.
