# 엑셀 너비 맞춤과 글자 형광펜

## 기존 문제

원본 셀의 크기를 그대로 표시해 처음 열 때 표가 크게 보였습니다. 근거 표시는 셀 전체에 연두색을 겹쳐 실제 답변에 쓰인 글자를 구분하기 어려웠습니다.

## 무엇을 바꿨나

- 원본 배치·병합·너비·높이·정렬·테두리·글꼴·색은 그대로 두고 화면 표시만 축소합니다. 기본 대기 배율 75%, 실제 너비 확인 후 최대 80%·최소 65%로 맞춥니다. 작은 화면에서 너무 작게 줄이는 대신 내부 스크롤을 유지합니다.
- 축소된 실제 크기의 감싸개로 불필요한 빈 스크롤 영역을 막고 바깥 뷰어는 가로·세로 스크롤을 제공합니다.
- 직접 근거 앞 두 행을 함께 읽고, 처음 사용한 근거 글자가 뷰어 상단 24픽셀 가까이에 오도록 내부 위치를 맞춥니다. 전체 채팅 화면을 강제로 스크롤하지 않습니다.
- 셀·행 전체의 연두색 배경과 강조 테두리를 제거했습니다. 근거 문자열만 작은 연두색 mark로 감싸며 원본 글자색을 상속합니다.
- 기존 직접 인용, 출처의 행/열 이름과 값, 원본 값, 실제 답변 내용을 교차 확인합니다. 목록 답변은 도입문 대신 답변 항목에서 쓰인 문구만 강조합니다.
- 같은 셀의 `간호교육파트 교대제 / 교육담당` 중 답변에 쓰인 `간호교육파트 교대제`만 표시할 수 있습니다. 모호한 위치나 다른 번호의 일부는 임의로 표시하지 않습니다.
- 관리자 문서 등록과 직원 PC·모바일은 같은 뷰어를 사용합니다. 관리자 단순 원본 보기에는 인용과 답변이 없어 형광펜이 없습니다. 단일 시트 UI 숨김·긴 설명 제거·다운로드 금지를 유지합니다.

## 실제 사례 확인

저장된 `간호부 번호` 답변과 실제 원본을 읽기 전용으로 대조했습니다. 150행부터 근처 문맥을 준비하고 152~155행의 아래 8개 문자열만 mark로 표시됨을 확인했습니다.

- 간호교육파트 교대제 / 6741
- 간호교육파트장 / 2834
- 간호교육파트 간호간병 / 2616
- 간호교육파트 필수의료 / 2617

도입문의 `간호부`와 귀코목센터·이비인후과·다른 전화번호는 칠하지 않습니다. 셀 태그에 연두색 배경·그라데이션·강조 테두리를 추가하지 않음을 렌더링 검사로 확인했습니다. 새 AI 답변은 생성하지 않았습니다.

## 검사와 보호 범위

- 배율 상한/하한, 셀 일부 문자열, 직접 인용만 표시, 반복 번호, 열 이름/번호 뒤바뀜 제외, 도입문 제외 검사를 통과했습니다.
- 실제 컴포넌트를 DOM에 붙이고 PC 너비 1000픽셀·모바일 너비 320픽셀로 모사했습니다. 80%·65% 배율, 내부 가로·세로 이동, 원래 셀 색 유지, 관리자 무강조를 확인했습니다. 이 검사는 모사이며 실제 브라우저 화면을 본 것은 아닙니다.
- 브라우저 연결 조회 결과 앱·브라우저 모두 없어 PC/모바일 직접 클릭은 미검증입니다.

- 서버 파일은 이번 이미지에서 교체하지 않고 화면 파일만 반영합니다. 원본 파일·DB 구조·검색 인덱스·다운로드 정책은 그대로 유지합니다.
