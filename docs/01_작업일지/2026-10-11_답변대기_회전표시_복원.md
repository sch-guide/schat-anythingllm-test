# 답변 대기 회전 표시 복원 — 2026-10-11

사용자가 고정 준비 문구 대신 기존 회전 원과 변경되는 문구를 요청했다. 기존 StatusResponse는 회전 원과 ‘문서를 찾는 중…’, ‘문서를 한 번 더 찾는 중…’, ‘답변을 작성하는 중…’을 이미 제공한다. ChatHistory의 연결 준비 전용 고정 문구 분기를 제거하여 질문 직후부터 같은 표시를 사용한다. 문구는 실제 상태에 따라 바뀌며 시간을 기준으로 임의로 순환하지 않는다.

변경 코드: frontend/src/components/WorkspaceChat/ChatContainer/ChatHistory/index.jsx

대기 순번 안내, 서버 연결·입장 처리, 90초 자동 중단 기준, RAG/캐시/검색/답변 생성 로직은 바꾸지 않는다. StatusResponse에는 중단 콜백을 추가하지 않아 입장 전 대기에서 새로운 중단 동작을 만들지 않는다.

관련 상태 표시·단계 판정 자동 검사 10개 통과. 실제 Gemini 호출·병원 자료 사용 없이 검사했다. 실제 브라우저에서 질문하여 확인하는 과정은 미실시다. commit/push/tag 없음. 다른 작업의 미커밋 변경은 보존한다.

화면 빌드 통과. 로컬 3001 화면 파일을 반영하고 빌드 파일과 실행 파일의 해시 일치를 확인했다. 문서 검사 11개 통과. 서버 재시작·DB 변경은 하지 않았다.
