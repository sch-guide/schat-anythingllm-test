# 검사·시술 체크리스트 일반화와 로고 크기 조정

## 1. 검사·시술 체크리스트

### 무엇이 바뀌었나
- Renal biopsy 한 건에만 있던 체크리스트를 `검사 및 시술(26.04.07).pdf`의 표준 양식 페이지 전체로 넓혔습니다.
- 원본 PDF의 글자 위치를 읽어 칸 폭 때문에 두 줄로 나뉜 문장을 한 문장으로 되살리고, ①② 번호만 하위 항목으로 나눕니다. 내용은 원문을 옮긴 것이며 새 문장을 만들지 않았습니다(Gemini 사용 없음).
- 만든 모든 제목·항목·세부 문장은 해당 페이지 원문과 같은 순서로 있는지 대조합니다. 하나라도 맞지 않거나 칸 안에 작은 표가 한 번 더 들어 있어 읽는 순서가 불확실하면 `검토 필요`로 두고 직원 화면에 보이지 않게 했습니다.
- `※`로 시작하는 줄과 괄호로만 된 설명 줄은 체크박스 없는 참고 문장으로 보입니다.
- 검사목적, 검사장소/이동수단, `-`만 적힌 행은 체크박스가 없습니다.

### 결과
- 표준 양식 63쪽: 직원에게 보이는 체크리스트 54개 새로 생성 + 기존 Renal biopsy 1개 = 55개, 검토 필요 9개(p.8, 9, 10, 11, 33, 35, 59, 66, 82).
- 만들지 않은 페이지: 분기형(p.14, 52, 53, 68, 76), 수술·시술·축약 양식과 행 누락 페이지 10쪽, 정보 페이지 3쪽.
- 따로 만든 검사 스크립트로 저장된 55개를 원문과 다시 대조했고 불일치는 0건이었습니다.
- Renal biopsy 체크리스트 파일은 작업 전후 해시가 같아 한 글자도 바뀌지 않았습니다.
- 등록된 PDF에는 재색인 없이 적용했습니다. 원문 페이지 파일만 읽었고 BM25·ChromaDB·본문 벡터는 건드리지 않았습니다. 처리 결과 요약은 원문 없이 `server/storage/schat-diagnostics/procedure-checklists-backfill.json`에 남겼습니다.

### 직원 화면
- 질문에 검사 이름이 있으면 `〈검사명〉 체크리스트 보기` 버튼이 나옵니다. Renal biopsy 버튼 문구는 그대로입니다.
- `CT`처럼 짧은 영문 약어는 다른 단어 안에서 걸리지 않게 단어 단위로만 찾고, 한글 이름은 단어 시작에서만 찾습니다. 더 긴 검사명이 우선합니다. 실제 체크리스트 55개의 모든 별칭으로 확인한 결과 누락 0건, 다른 체크리스트 오탐 0건이었습니다.
- 여러 체크리스트를 동시에 띄울 수 있습니다. 각 작업창의 위치·크기·최소화·체크·접힘 상태는 따로 유지되고, 누른 작업창이 앞으로 옵니다. 별도 창도 체크리스트마다 따로 열립니다.

### 관리자 화면
- PDF 행 아래 `체크리스트 64개 · 검토 필요 9개`를 펼치면 페이지별 목록이 나오고, 각 항목에서 기존 보기·수정·원본 보기를 그대로 사용합니다. 승인 버튼은 없습니다.

### 확인
- Docker 안 브라우저: 신루설치술 PCN, 경피적 폐세침 조직검사 PTNB, ERCP, 위내시경점막하박리술 G-ESD/G-EMR, 24시간 홀터 심전도, Renal biopsy에서 73개 항목 통과. Renal biopsy 기존 회귀 48개 항목 통과(Citation p.56, PDF 원문 보기, 관리자 모달 포함).
- 서버 테스트 25개, 프런트엔드 테스트 93개 통과.

## 2. SCH 로고 크기와 선명도
- 프로젝트 안에 더 큰 SCH 원본이 없어(원본 188×68px) 화면에서 원본보다 크게 늘리지 않도록 표시 크기를 줄였습니다.
  - 로그인 왼쪽 약 77×28px, 오른쪽 약 89×32px, 모바일은 둘 다 약 61×22px.
  - 일반·2배 화면과 3배 휴대폰 화면 모두 확대 없이 표시되는 것을 실제 Chrome에서 확인했습니다.
- 탭 아이콘은 128px 정사각 이미지를 원본 픽셀 그대로 쓰고, 16·32·48px는 단계적으로 줄여 다시 만들었습니다. 새로 연 실제 Chrome 탭에서 선명하게 표시됐습니다.
- 로고 디자인·색·비율은 바꾸지 않았고 채팅 화면에 로고를 다시 넣지 않았습니다.

## 3. SCH 로고 가장자리와 간격
- 로고 좌우에 보이던 흰 테두리는 CSS가 아니라 제공받은 이미지 자체의 가장자리(왼쪽 1px 밝은 선, 오른쪽 2px 흰색에 가까운 띠) 때문이었습니다.
- 이미지 파일은 바꾸지 않고, 화면에 그릴 때만 그 3개 열을 가렸습니다. 로고 비율은 원본 그대로이고 확대하지 않습니다. `H` 오른쪽 세로획은 원본에서도 이미지 끝에 닿아 있어 로그인 화면 기준 1px 미만만 줄었습니다.
- 로고와 옆 글자 간격을 왼쪽 12→9px, 오른쪽 14→10px(모바일 10→8px)로 조금 줄였습니다.
- 실제 Chrome으로 PC(2배 화면)와 모바일(3배 화면)을 확대 캡처해 흰 띠가 사라지고 글자 잘림·흐림이 없는 것을 확인했습니다.

## 남은 일
- 검토 필요 9쪽과 분기형·수술 양식 페이지는 별도 설계가 필요합니다.
- 관리자가 검토 필요 체크리스트를 수정해도 상태는 그대로이며, 직원 공개로 바꾸는 방법은 아직 없습니다.
- 별칭은 원문 제목에서만 만들기 때문에 `뇌혈관조영술`처럼 제목 일부만 쓴 질문에는 버튼이 나오지 않을 수 있습니다.
