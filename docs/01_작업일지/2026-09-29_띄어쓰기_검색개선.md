# 띄어쓰기가 달라도 찾는 검색

## 문제

- 지침서 원문은 띄어쓰기가 빠진 경우가 많습니다(예: "투석관삽입술").
- 직원이 "투석관 삽입술"로 물으면 단어 일치 검색이 못 찾았습니다. 반대 경우도 있었습니다.

## 바꾼 것 (Gemini 호출 없음)

- 문서마다 띄어쓰기를 모두 뺀 글을 한 번 만들어 둡니다.
- 한글 단어는 **똑같은 단어가 없을 때만** 띄어쓰기를 뺀 글 안에 들어 있는지도 봅니다.
  - 3글자 이상 단어(투석관, 흉수천자, 위내시경)는 이 방법으로 찾습니다.
  - 2글자 단어(관찰, 준비)는 그 문서가 질문의 3글자 이상 단어와 이미 맞을 때만 보조로 셉니다.
  - "방법·종류·절차·주의사항" 같은 일반 단어와 1글자 단어는 긴 단어 안에서 세지 않습니다.
  - 똑같은 단어가 있는 문서의 점수는 전과 같습니다.
- **같은 규칙을 쓰는 곳**
  - 단어 일치 검색(BM25)
  - 마지막 거르기의 단어 일치 비율
  - 사진 질문의 주제 단어 확인
  - 동의어(여러 단어로 된 한글 동의어 포함)
- 체크리스트 연결은 원래부터 한글 이름의 띄어쓰기를 무시하고 있어, 테스트로 다시 확인했습니다.

## 확인

- **대상 질문을 실제 채팅으로 확인**
  - "HD 투석관 삽입술": p.58·59
  - "흉수천자 후 관찰": p.19·18
  - "위내시경 전 준비": p.32
  - "투석관삽입술 준비": p.58
  - 모두 출처와 함께 답했습니다.
- **같은 질문 벡터로 수정 전·후 비교**
  - 대표 질문 25개 중 20개는 같았습니다.
  - 바뀐 5개 중 3개는 관련 쪽이 더해졌습니다: 혈액제제 종류 p.113, 적혈구 제제 보관 p.114, 수액 세트 그림 p.266.
  - 2개는 순서만 바뀌거나 관련 없는 쪽 하나가 바뀌었습니다: 수혈 부작용, 수혈 세트 그림.
- **지침서에 없는 질문 5개:** 모두 같았습니다.
- **속도:** 단어 일치 검색 1회 약 8~9ms로 차이가 없었습니다.
- **처음 시도에서 생긴 문제와 해결**
  - 2글자 단어까지 긴 단어 안에서 세게 했더니 "항생제 피부반응검사 방법"의 정답 쪽(p.222)이 빠졌습니다.
  - 위 제한을 넣어 수정 전과 같아졌습니다.
- **자동 테스트:** 서버 305개, 화면 136개가 통과했습니다.
