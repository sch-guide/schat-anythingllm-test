# 관리자 로그인 아이디 변경

## 한 일

- 기존 관리자 계정이 한 개이고 새 아이디와 중복되는 계정이 없는지 확인했습니다.
- 변경 전에 계정 데이터베이스의 복구용 사본을 만들었습니다.
- 비밀번호, 역할, 작업공간, 문서와 대화 데이터는 바꾸지 않고 관리자 로그인 아이디만 변경했습니다.
- 보안을 위해 실제 로그인 아이디와 비밀번호는 이 문서에 기록하지 않았습니다.

## 확인 결과

- 변경된 계정의 역할은 계속 관리자입니다.
- 계정은 정지되지 않은 활성 상태입니다.
- SCHAT 웹, ChromaDB, 안전검사 서비스가 모두 정상 상태입니다.

## 로그인 방법

- 브라우저에서 SCHAT 로그인 화면을 엽니다.
- 새 관리자 아이디와 기존 비밀번호를 입력합니다.
- 비밀번호는 이번 작업에서 변경하지 않았습니다.
