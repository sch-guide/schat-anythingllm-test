# SCH 로고 통일과 탭 아이콘 교체

## 바뀐 점

- 로그인 화면 왼쪽 `순천향대학교 부속 천안병원` 옆과 오른쪽 `병원 실무지침 AI` 옆에 제공받은 파란색 SCH 로고를 표시합니다. 두 곳 모두 같은 이미지 파일 하나를 사용합니다.
- 오른쪽의 초록색 십자 로고와 작은 `SCH` 글자, 가운데 `웰컴!` 문구를 제거했습니다. `SCHAT에 로그인하세요.` 문구와 로그인 입력창·버튼은 그대로입니다.
- 채팅 화면 왼쪽 위의 흰색 `SCHC` 배지를 제거하고 `SCHAT` 이름만 남겼습니다. 기능 버튼 아이콘은 그대로입니다.
- 브라우저 탭에 보이던 AnythingLLM 기본 아이콘(검은 사각형)을 SCH 아이콘으로 바꿨습니다. 가로형 로고를 탭 크기에서 알아볼 수 있도록, 원본 로고의 글자 왼쪽 파란 여백을 잘라내고 위쪽을 원본의 같은 파란 배경으로 채운 정사각형을 사용합니다. 새 모양이나 색은 추가하지 않았습니다.
- 모바일 로그인 화면에서 카드 안 내용이 화면 폭을 넘던 문제를 함께 고쳤습니다.

## 확인 결과

- 실제 Chrome으로 로그인 화면(PC·모바일)과 채팅 화면을 캐시 없이 열어 확인했습니다. 로고 두 곳 표시, 초록 십자·`웰컴!`·`SCHC` 없음, 로그인 입력창 2개와 로그인 버튼 정상.
- 새로 연 실제 Chrome 창의 탭에 SCH 아이콘이 표시됐습니다.
- Docker 안 브라우저 회귀 검증 48개 항목 통과: 체크리스트 작업창·별도 창, Citation p.56, PDF 원문 보기, 관리자 체크리스트 모달.
- 프런트엔드 테스트 84개 통과, Docker production build 성공.

## 참고

- 이미 열어 둔 브라우저 탭은 예전 아이콘을 기억하고 있을 수 있습니다. 강력 새로고침(Ctrl+Shift+R)이나 탭을 새로 열면 바뀝니다.
- 제공받은 SCH 로고는 원본에서도 `SCH` 글자 아래쪽이 이미지 가장자리에서 잘려 있는 디자인이며, 그대로 사용했습니다.
- 백엔드, 검색, 답변, Citation, PDF viewer, 체크리스트, 로그인 인증 방식은 바꾸지 않았습니다.
