# 예전 문서 삭제 규칙과 퀴즈 재생성 근거 보완

## 요청
- 「3-3. 실무지침서_중심정맥관.pdf」 예전 문서가 "과거 답변 출처나 퀴즈가 이 문서를 가리키고 있어 삭제하지 않습니다."로 지워지지 않음.
- 같은 문서로 퀴즈(중심정맥관 · 10문항 · 중급 · 객관식)를 지우고 버전을 올린 뒤 다시 만들면 `no_evidence`로 실패함.

## 원인
1. 삭제 차단: 삭제 점검이 과거 답변·퀴즈 세트·퀴즈 문제·퀴즈 생성 기록을 모두 더해 1건이라도 있으면 막았다. 퀴즈 문제를 지워도 생성 기록과 빈 세트는 남으므로, 현재 퀴즈가 0개여도 계속 막혔다.
2. 과거 답변 수 누락: 요즘 답변의 출처는 문서 번호 대신 `pdfRef`(문서 번호로 계산한 값)만 저장한다. 점검은 문서 번호만 찾아서 최근 과거 답변을 0건으로 셌다.
3. 판정 저장값: 삭제 판정 결과를 최대 10분 저장해 두는데, 비교 기준에 퀴즈 수가 없어 퀴즈를 지운 뒤에도 최대 10분간 "삭제 불가"로 보였다.
4. 퀴즈 근거: 주제가 문서 제목 자체(진정간호·중심정맥관)이면 본문에서 그 단어가 첫 쪽에만 적혀 있어 첫 쪽(약 900자)만 근거로 잡혔다. 10문항 중급을 그 근거로 만들 수 없어 AI가 "근거 부족"으로 답하고 생성 기록에 `no_evidence`가 남았다. 3001 진정간호 문서로 같은 현상을 확인했다(근거 1쪽 → 수정 후 1~10쪽).
   - 생성 기록 `no_evidence`는 "근거를 못 찾음"과 "AI가 근거 부족으로 문제를 만들지 않음" 두 경우에 모두 남는다(기록 방식은 바꾸지 않음).
   - 문서 번호 연결(예전 업로드 번호가 남은 문단)은 10-13 수정으로 이미 현재 등록 행 기준으로 찾는다.

## 수정
- 삭제 규칙: 현재 퀴즈 문제가 있을 때만 막는다("현재 퀴즈 N문항이 이 문서를 근거로 하고 있어 삭제하지 않습니다."). 생성 기록·빈 세트·지운 문제는 막지 않는다. 현재 등록·검색·Chroma·체크리스트·이미지 사용 판정은 그대로다.
- 과거 답변만 있으면: 확인 창에 "이 문서는 과거 답변 N건의 출처로 사용되었습니다. 삭제하면 해당 과거 답변에서 원본을 다시 열 수 없습니다."를 보여 주고 버튼을 [취소] [그래도 삭제]로 바꾼다. 과거 답변은 지우지 않는다.
- 과거 답변 수는 문서 번호와 `pdfRef`를 모두 센다.
- 삭제 직전 서버가 다시 점검(미리보기 → 삭제 → 삭제 후 현재 자료 비교)하는 기존 절차를 그대로 쓴다. 원본을 지우기 전에 "삭제됨" 표시를 남긴다.
- 과거 답변에서 지운 출처를 열면 "이 출처는 이전 버전 문서로 현재 원문을 확인할 수 없습니다."와 저장된 근거 문장을 보여 준다(PC·모바일).
- 판정 저장값 비교 기준에 현재 퀴즈 문제 수를 넣었다.
- 퀴즈 근거(퀴즈 생성에만 적용): 주제가 문서 제목에 들어 있으면 찾은 쪽 다음에 나머지 본문 쪽을 쪽 순서로 이어 붙인다(최대 10쪽·12,000자 기존 한도). 제목은 찾는 데만 쓰고 문제는 본문으로만 만든다. 그림 설명은 계속 뺀다. 한글 주제는 띄어쓰기가 달라도 찾는다(중심정맥관 ↔ 중심 정맥관). 제목과 무관하고 본문에도 없는 주제는 지금처럼 근거 없음이다.

수정 파일: `server/utils/schatAdmin/storageCleanup.js`, `server/endpoints/schatAdmin.js`, `server/utils/schatQuiz/generation.js`, 문서 등록 창 `Directory/index.jsx`, Citation `index.jsx`·`MobileSourceScreen.jsx`, 관련 자동 검사. 운영 점검용 읽기 전용 파일 `검사/운영_예전문서_퀴즈_점검.node.js`를 추가했다.

변경하지 않음: RAG·BM25·Vector·Hybrid 75:25·Chroma·Citation 출처 선택·체크리스트·동의어·사용자·DB 구조.

## 검증
- 서버 자동 검사(이미지 안): 퀴즈·저장공간 정리·원본 관련 113개 통과. 문서 업데이트 검사의 실패는 이전 이미지에서도 같은 Node 18 `node:sqlite` 미지원 문제다.
- 화면 자동 검사: 문서 목록·정리 관련 11개 통과.
- 3001 실제 흐름(가상 테스트 PDF 「zz-테스트_실무지침서_중심정맥관.pdf」, 3쪽, '중심정맥관'은 1쪽 제목에만 적음):
  1. 1판 등록 → 퀴즈 생성 6문항(가상 3쪽이라 10개를 다 못 채움) → 퀴즈 삭제(문제 0, 빈 세트 1, 생성 기록 1 남음).
  2. 같은 이름 2판 업데이트 → 같은 조건으로 재생성 10/10문항, 모두 현재 문서 번호로 연결.
  3. 2판을 작업공간에서 뺌 → 현재 퀴즈 10문항 때문에 삭제 버튼 없음·사유 표시 → 퀴즈 삭제 직후 삭제 버튼 표시.
  4. 확인 창에 과거 답변 1건 경고와 [그래도 삭제] 표시 → 서버 재점검 후 삭제 완료.
  5. 과거 답변에서 지운 1판 출처를 열면 410 응답 → 오류 없이 안내 문구와 근거 문장 표시. 과거 답변 보존.
- 테스트 자료(가상 PDF, 퀴즈 세트·기록, 테스트 대화·계정·부서, 동의어 제안 기록, 업데이트 작업 기록, 삭제 표시)는 모두 지웠다. 삭제 감사 기록 2개는 남겼다. 기존 등록 문서 597행은 그대로다.
- 3001 반영: 반영 전 백업 `schat-local-backups/3001-olddoc-delete-20261014`(4,325개, 불일치 0). 이미지 `schat-admin-build:olddoc-delete-20261014f`.
- AI 호출: 퀴즈 생성 2회, 채팅 질문 2회, 문서 등록 임베딩·동의어 제안 소량.
- 운영 서버 변경·commit·push·tag 없음.

## 남은 확인
- 운영 서버의 실제 「3-3. 실무지침서_중심정맥관.pdf」 상태는 아직 보지 못했다. 운영에서 `검사/운영_예전문서_퀴즈_점검.node.js`(읽기 전용)를 실행하면 삭제 차단 사유·퀴즈 연결·과거 답변 수·근거 쪽을 확인할 수 있다.
- 같은 이름 업데이트로 보관된 이전 버전은 문서 목록에 나오지 않고 정리 대상도 아니다(기존 설계 유지).
