# 사진 질문 수정, 방식 C 보완, 검사·시술 체크리스트 연결

## 1. 사진·그림 질문(Q09·Q10) 수정

사진·그림·이미지·도식·도표·그래프를 요청하는 질문에만 적용합니다. 일반 질문의 검색과 출처(Citation) 동작은 그대로입니다.

### 원인

- **Q09 "혈액제제 종류를 사진으로 보여줘"**
  - 혈액제제 계통도 그림(p.113)과 종류 표(p.114)가 의미 검색 1·2위였습니다.
  - 하지만 "종류"라는 단어가 없어 마지막 거르기에서 빠졌습니다.
  - 대신 "수혈세트의 종류"(p.125)가 남았습니다.
- **Q10 "수혈 세트 그림 보여줘"**
  - 수혈 세트 사진(p.115, p.125)은 후보에 있었습니다.
  - 하지만 사진은 **같은 쪽 글 근거가 있을 때만** 출처에 붙는 규칙 때문에 붙지 않았습니다.

### 바꾼 것 (사진 질문일 때만)

1. **검색 순위**
   - "종류·방법·주의사항" 같은 일반 단어를 뺀 **주제 단어**(예: 혈액제제)를 모두 가진 조각을 통과시킵니다.
   - 단, 의미 검색 최상위권(1위와 0.05 이내, 유사도 0.6 이상)이어야 합니다.
2. **같은 쪽 사진**
   - 이미 근거로 뽑힌 쪽의 사진은 질문의 가장 구체적인 주제 단어(문서에 가장 드물게 나오는 단어, 예: "세트")가 있으면 붙입니다.
3. **다른 쪽 사진**
   - 주제 단어를 모두 가지고 근거 쪽과 2쪽 이내에 있으면, 자기 쪽수를 가진 사진 출처로 붙입니다.
4. **AI에게 전달**
   - AI에게도 붙은 사진의 설명과 "사진은 답변 아래 출처에 표시된다"는 안내를 근거로 전달합니다.
5. **화면**
   - 사진이 있고 질문 주제 단어가 들어간 출처는 숨기지 않습니다.

기준값(2/3, 0.7)은 그대로입니다.

### 확인 결과

- **검색 결과 비교(질문 30개, 수정 전·후 같은 질문 벡터):**
  - 바뀐 것은 사진 질문 4개뿐입니다.
  - 나머지 26개(일반 질문 20개, 지침서에 없는 질문 5개 포함)는 **완전히 같습니다.**
  - Q09: p.125 → p.113 혈액제제 계통도 + 사진
  - Q10: 수혈 세트 사진 p.125·p.115 추가
  - 수액 세트 그림 질문에 엉뚱한 사진이 붙던 문제는 "근거와 2쪽 이내" 조건으로 막았습니다.
- **실제 답변:** Q09·Q10 모두 정상 답변하고 출처에 사진이 붙었습니다(자세한 수치는 아래 2장).

## 2. 재검색 방식 C 보완 (기본 꺼짐 유지)

### 바꾼 것

- **한도에 걸렸을 때**
  - AI에게 "질문과 관련된 근거가 일부라도 있으면 그 내용으로 답하고, 관련 근거가 하나도 없을 때만 확인되지 않습니다라고 답하라"고 지시합니다.
  - 그래도 AI가 검색만 요청하면 짧은 형태(질문+근거+지시)로 한 번 더 요청합니다.
  - 끝까지 안 되면 근거가 있을 때는 "관련 근거를 찾았으니 아래 출처를 확인해 달라"고, 근거가 없을 때만 "확인되지 않습니다"로 답합니다.
  - 이 안내 문구는 임상 내용을 만들지 않습니다.
- **"근거 충분" 기준:**
  - 장식 이미지(병원 로고 등)를 뺀 **서로 다른 근거 조각 3개 이상**이면 충분으로 봅니다.
  - 한 쪽 안에서만 나와도 됩니다. 한 번에 최대 4개를 찾는데 그중 3개가 한 쪽이면, 그 쪽이 질문 전용 내용일 가능성이 높기 때문입니다.
  - 전에는 "2쪽 이상"이 조건이었습니다. 이번 15개 질문에서는 이 차이로 판정이 바뀐 질문이 없었습니다.
  - 로고 이미지를 근거로 세던 문제는 고쳤습니다(Q02 수혈 종류가 p.113 글 1개 + 로고 1개였음).

### 3회 반복 비교

- 대표 질문 10개와 지침서에 없는 질문 5개를 [현재 / 방식 C] 각 3회, 모두 90회 실행했습니다.
- **측정 도중 Gemini 선불 잔액이 소진되어 3회차 대부분(25회)이 오류로 실패했습니다.** 실패한 회차는 평균에서 뺐습니다. 유효 65회이고, 대부분의 질문은 2회 평균입니다.
- "추가 검색"은 미리 검색 1회를 뺀, 실제로 실행된 검색 수입니다.

| 묶음 | 방식 | 유효 횟수 | 첫 글자까지 | 답변 완료 | 추가 검색(최대) | 입력 토큰 |
|---|---|---|---|---|---|---|
| 대표 질문 10개 | 현재 | 21 | 7.5초 | 10.2초 | 1.0회 (4) | 8,188 |
| 대표 질문 10개 | 방식 C | 22 | 6.3초 | 8.2초 | 0.59회 (2) | 3,635 |
| 없는 질문 5개 | 현재 | 11 | 16.2초 | 16.3초 | 3.27회 (11) | 101,530 |
| 없는 질문 5개 | 방식 C | 11 | 6.6초 | 6.6초 | 0.45회 (1) | 15,678 |

- **방식 C 한도:** 모든 실행에서 추가 검색이 2회 이하였습니다. AI가 3번째 검색을 요청한 경우도 실행하지 않았습니다.
- **Q02(수혈 종류):**
  - 현재 방식은 2회 모두 정상 답변했습니다(1,355자, 1,392자).
  - 방식 C는 1회차 정상(356자, p.113·114·119)이었고, 2회차는 추가 검색에서 같은 p.113만 다시 나와 "종류 항목 제목만 있고 세부 내용은 확인되지 않는다"고 답했습니다. 지어낸 내용은 없지만 답이 부족했습니다.
- **Q09·Q10:** 두 방식 모두 정상 답변했고 출처에 사진이 붙었습니다.
  - Q09: 혈액제제 계통도 1장
  - Q10: 수혈 세트 사진 2장
  - 화면에서 출처를 펼쳐 사진이 보이는 것도 확인했습니다.
  - 답변에 "사진을 직접 띄울 수 없다"는 말이 섞여, 사진이 출처에 표시된다는 안내를 AI 근거에 추가했습니다. 2026-09-29 잔액 충전 후 Q09·Q10을 두 방식으로 1회씩 다시 확인했습니다. 네 답변 모두 "사진을 띄울 수 없다"는 말 없이 "원본 사진은 아래 출처에서 확인"하도록 안내했고, 사진(Q09 1장, Q10 2장)이 붙었습니다.
- **없는 질문 5개:** 두 방식 모두 "확인되지 않습니다"로 답했습니다.
  - 현재 방식은 TAVI 질문에서 문서에 없는 약어 풀이를 한 번 붙였습니다.
- 답변 전문 비교 문서는 로컬 전용 폴더(`workspace/데이터_검수/2026-09-28_방식C_3회비교/`)에만 있습니다.
- 비용: Gemini 답변 호출 187회, 입력 약 154만·출력과 thinking 약 4만 5천 토큰입니다. 약 1.3달러(약 1,800원, 1달러≈1,400원)입니다.

## 3. 검사·시술 체크리스트

### 체크리스트가 뜨는 기준

- 질문 문장 안에 체크리스트의 **이름(별칭)** 중 하나가 그대로 들어 있으면 뜹니다. 답변 내용과는 관계없습니다.
  - 한글 이름은 띄어쓰기를 무시하고, 단어 시작에서만 맞춥니다("뇌혈관조영술" 안의 "혈관조영술"은 안 맞음).
  - 영문 약어는 단어 단위로만 맞춥니다("CT"가 다른 단어 안에서 맞지 않음).
  - 긴 이름이 짧은 이름보다 우선합니다.
- 직원 화면에는 **공개(active)** 상태만 나오고, **검토 필요** 상태는 관리자 문서 화면에서만 보입니다.

  - 흔히 부르는 이름·약어가 이름 목록에 없음: 폐생검, 간생검, 신장생검, 홀터, 심장 CT, 돌발성 난청, chemoport, EGD, perm cath 등
  - "Thrombectomy, Thrombolysis"처럼 이름 두 개가 한 칸에 묶여 둘 다 있어야 맞음
  - 긴 영문 이름만 있음(예: "Chemoport insertion")

### 바꾼 것

- **A(연결)**
  - 흔히 부르는 이름 표 `server/utils/documentChecklists/commonNames.js`를 새로 만들었습니다.
  - 묶인 이름은 나눠서 인식합니다.
  - 이 이름들은 체크리스트를 **찾을 때만** 쓰고, 체크리스트 내용·기존 이름·출처(Citation) 거르기는 그대로입니다.
  - 헷갈리는 이름("EMR", "LP", "pacemaker", "ESD", "피크" 등)은 일부러 넣지 않았습니다.
  - 흔히 부르는 이름 253개 시험: 연결 130개 → 197개(나머지는 숨겨진 9개 관련 44개와 일부러 뺀 헷갈리는 이름)
  - 관계없는 일반 간호 질문 50개: 체크리스트가 뜬 것은 "신루관"이 들어간 1개(PCN과 실제 관련)
- **B(초안)**
  - 체크리스트가 없는 16개는 지침서 줄을 **그대로 옮긴** 초안을 "검토 필요" 상태로 저장했습니다(직원에게 숨김).
  - 모든 칸 이름과 내용은 해당 쪽 원문에 있는지 자동 대조를 통과했습니다.
  - 갈래가 있는 쪽(C-EBUS/R-EBUS, AF/AFL/PSVT RFCA)은 섞지 않고 갈래 제목 아래에 나눴습니다.
