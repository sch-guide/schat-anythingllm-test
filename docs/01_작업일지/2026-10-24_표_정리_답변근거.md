# 표 정리를 답변 근거에 함께 넘기기 (3001 시험 반영)

- 날짜: 2026-10-24
- 계기: 운영에서 PC 수혈 질문 뒤 "antibody는"에 "PC 수혈 시 Antibody screening test는 입원 후 첫 수혈 시, 수혈 시작 기점으로 72시간 유효"라고 틀리게 답함(출처 `3-11. 실무지침서_수혈간호.pdf` 9쪽). 원문 표에서 72시간 유효는 RBC 칸에만 해당하고, PC·FFP·CRYO는 합친 칸 "입원 후 첫 수혈 시, 비예기항체는 RBC에만 존재하기 때문에 혈장제제는 주기적으로 시행할 필요 없음".
- 상태: 3001에 코드 반영, 2026실무지침서 113~128쪽(수혈 부분)만 표 정리 생성. GitHub·운영 미반영.

## 원인

- 문서 등록 때 PDF에서 글자만 순서대로 뽑아 저장해 표의 행·열이 사라짐. 3001의 같은 표(2026실무지침서 121쪽)도 "RBCPCFFP CRYO … Antibody screening test / 입원 후 첫 수혈 시 / 수혈 시작 기점으로 72시간 유효"처럼 이어 붙어 저장돼 있음.
- 같은 근거로 시험(3.5-lite, 3번): 지금 글만 주면 "antibody는"에 2번 "확인되지 않습니다", 1번 72시간(틀림). 표 정리를 함께 주면 3번 모두 "입원 후 첫 수혈 시, 혈장제제는 주기적 시행 불필요"로 정답.
- 표가 있는 쪽을 글자 위치나 선 개수로 찾는 방법은 맞지 않았음(실무지침서는 거의 모든 쪽에 테두리 상자, 글자 배치 규칙은 121쪽 표를 놓침).

## 수정

- 검색 자료(Chroma·BM25)·등록 문서는 바꾸지 않음(재색인 없음).
- `server/utils/documentTables/store.js`: 쪽별 표 정리를 `storage/document-tables/<문서 번호 해시>/<쪽>.json`에 저장·읽기("표 없음"도 기록).
- `server/scripts/schatBackfillTableTranscriptions.js`: 원본 PDF 쪽을 그림으로 만들어 그림 설명 모델(기본 3.8)에게 데이터 표만 행·열대로 옮기게 함. 합친 칸은 해당 행·열 모두에 적게 함. 이미 확인한 쪽은 건너뜀(`--force`로 다시), `--pages`, `--dry-run`.
- `ragSources.js` `buildRagContext`: 근거 쪽에 표 정리가 있으면 그 쪽 근거 뒤에 "[이 쪽의 표를 행·열대로 옮긴 정리]"로 한 번 붙임.
