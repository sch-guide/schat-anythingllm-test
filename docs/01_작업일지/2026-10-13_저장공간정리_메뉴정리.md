# 저장공간 정리 메뉴 정리와 예전 문서 삭제 (release-admin-9, 미커밋)

## 요청
- 관리자 메뉴의 `저장공간 정리` 제거, 그 화면의 `현재 사용 중` 요약만 `답변 근거 보기` 위로 이동.
- 문서 등록 창에서 현재 사용 중 문서와 예전 문서를 나누고, 예전 문서만 안전하게 삭제.
- 문서 등록·검색 기능과 운영 데이터는 그대로 유지. DB 구조 변경 없음.

## 기존 코드 구분
| 구분 | 내용 |
|---|---|
| A. 재사용 | 서버 점검 `storage-cleanup`(보고서·미리보기·삭제): 삭제 직전 다시 점검, 삭제 후 운영 숫자 비교, 관리자만. |
| B. 내부 유지 | 연결 정보가 없는 원본 PDF 점검·삭제 API(`storage-cleanup/originals/*`). 화면에는 없음. 자동 삭제 없음. |
| C. 화면에서만 제거 | 관리자 메뉴 `저장공간 정리`, 화면 연결. 예전 주소 `/settings/schat/storage`는 답변 근거 보기로 이동. |
| D. 삭제한 코드 | `sections/Storage.jsx`(저장공간 정리 화면), 원본 PDF 정리 화면용 모델 함수 2개, 그 화면만 검사하던 화면 검사(originalReview, 원본 PDF 화면 검사 1개). |

## 바뀐 점
- 답변 근거 보기 맨 위 `현재 사용 중`: 등록 문서·총 페이지·검색 데이터(본문·이미지 설명)·체크리스트. 기존 계산 그대로 사용. 계산에 약 20초 걸려 저장해 두고, 등록 문서·체크리스트·쪽 파일 수가 바뀌면 자동으로 다시 계산. "다시 계산" 버튼도 있음.
- 문서 등록 창 왼쪽: `현재 사용 중`(원본 보기만, 삭제 없음)과 `예전 문서 · 등록 전 문서`(원본 보기·삭제·등록 목록에 추가). 쪽 수·체크리스트 수 표시.
- 삭제: 관리자만. 확인창("이 예전 문서를 삭제하시겠습니까? / 현재 SCHAT에서 사용되지 않는 자료만 삭제됩니다. / 삭제 후 복구할 수 없습니다.") → 서버 재점검 → 삭제 → 삭제 후 운영 숫자 확인.
- 서버 점검 보완: 예전 업로드도 과거 답변 출처(Citation)·퀴즈가 가리키면 삭제 불가. 연결 확인에 실패해도 삭제하지 않음. (기존: 작업공간·검색 데이터·Chroma·체크리스트·이미지·원본 보기 연결 확인)
- 예전(등록 안 된) 문서 원본 보기는 관리자·매니저만. 직원 원본 보기 규칙은 그대로.
- 삭제 범위: 그 문서의 쪽 파일, 검색 임시 파일, 이미지 폴더, 원본 PDF와 정보 파일만.

## 추가: 전화번호부 검색

원인 두 가지(3001에 올린 붙임 1·2 전화번호부로 확인, 내용은 숫자·이름을 가린 형태로만 확인):
1. **PDF 표 칸이 공백 없이 붙어 읽힘.** PDF 글자를 줄 단위로 이을 때 같은 줄의 조각을 공백 없이 붙임 → "이름12345678다음이름…", 이름이 한 글자씩 띄어진 경우("이 문 수")도 있어 AI가 이름·번호를 짝짓지 못함.
2. **"먼저 문서 찾기" 규칙에 연락처 질문이 빠짐.** 병원·간호·지침·검사 같은 단어가 있을 때만 검색을 먼저 했는데, "시설팀 전화번호 알려줘"에는 그런 단어가 없어 AI가 검색 없이 "확인되지 않습니다"로 답함. "병원장님"은 문서의 "병원장"과 글자가 안 맞음.

수정:
- 제목에 "전화번호부"가 있는 PDF만 표 칸 간격을 공백으로 살려 읽고, 한 글자씩 띄어진 이름을 붙임(collector `directoryText.js`). 다른 지침 문서는 기존 방식 그대로(검색·청크 영향 없음). 실제 원본 기준 붙은 8자리 이상 숫자 126·32개 → 0.
- 전화·번호·내선·연락처가 들어간 질문도 문서를 먼저 찾음. 이 먼저 찾기 검색어에서만 존칭 "님"을 뺌("병원장님" → "병원장"). BM25·Vector·Hybrid 설정은 바꾸지 않음.
- 업데이트 확인창 문구를 체크리스트 재생성에 맞게 수정(3001 미반영, 다음 반영 때 포함).

확인(3001, 백업 `3001-admin9-20261013-202438-phone`): 두 전화번호부를 같은 이름으로 다시 올려(업데이트) 새 방식으로 읽음. 실제 채팅: 시설팀(주간·야간 번호), 비뇨의학과(비뇨의학센터 번호), 이문수(내선 번호) 답변 성공. 병원장님은 문서를 찾지만 표에서 "병원장" 칸과 사람·번호가 떨어져 있어 "확인되지 않습니다"(틀린 번호를 지어내지 않음). 시험 대화 7건·임시 계정 삭제. 검사: collector 3, 서버 75(이미지 안), 화면 200/201(기존 실패 1).

운영 반영 시: 새 코드 반영 후 전화번호부 2개를 같은 이름으로 다시 올려야 새 방식으로 읽힘.
