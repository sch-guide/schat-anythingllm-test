# 체크리스트 기구 사용 질문 제외

## 문제

- "MRI는 PICC 사용 가능해?"라는 질문에 PICC 삽입 체크리스트 버튼이 표시됨.
- 체크리스트 표시 규칙이 질문에 체크리스트 이름(PICC)만 있으면 무조건 표시했기 때문임. PICC는 시술 이름이면서 기구 이름이라, 기구를 쓰는 질문에도 시술 체크리스트가 붙음.

## 결정 (사용자 선택: 기구 사용 질문만 숨김)

- 질문에 사용 표현이 있고 시술 표현이 없으면 체크리스트를 표시하지 않음. 모든 체크리스트에 같은 규칙을 적용함.
  - 사용 표현: 사용, 써도, 쓸 수, 써야, 채혈, 주입, 연결
  - 시술 표현: 삽입, 거치, 설치, 시술, 준비, 간호, 동의서, 체크리스트, insertion, insert, 낱말로 쓰인 전/후
- 숨김 예: "MRI는 PICC 사용 가능해?", "PICC로 채혈 가능해?", "PICC 조영제 주입 돼?", "PICC 써도 돼?"
- 표시 유지 예: "PICC", "PICC 삽입 준비", "PICC 시술 후 간호", "PICC 삽입 후 MRI 사용 가능해?", "검사 전 PICC 사용 확인"
- 답변 내용, 검색, Citation은 바꾸지 않음. 체크리스트 버튼 표시 여부만 바뀜.

## 바뀐 파일

- `frontend/src/utils/checklistMatcher.js`: `asksDeviceUseOnly` 추가
- `frontend/src/utils/checklistMatcher.node.test.mjs`: 숨김 5개·표시 8개 질문 검사 추가

## 확인

- 체크리스트 표시 규칙 검사 11개 통과, eslint 통과
- frontend 전체 node 테스트 260개 중 256개 통과. 실패 4개(관리자 메뉴 아이콘 `answer-cache`, 모바일 Citation PDF 보기, 원본 PDF 목록 화면 2개)는 같은 시간에 진행 중인 다른 작업 파일에서 난 것이며 이번 변경과 관계없음
- Docker 3001: 사용자 승인 후 로컬 schat-web을 다시 빌드함. 시작할 때 `20261011020000_checklist_personal_state` migration 1개가 적용되어 새 표 1개만 추가됨(기존 자료 변경 없음). 운영 서버는 바꾸지 않음.
- 실제 채팅 화면 확인: Gemini를 호출하지 않도록 대화 기록과 체크리스트 목록만 가짜 데이터로 넣어 3001번 채팅 화면을 열었음. "MRI는 PICC 사용 가능해?"·"PICC로 채혈 가능해?" 답변에는 체크리스트 버튼이 없고, "PICC 삽입 준비"·"PICC 드레싱 주기" 답변에는 PICC 체크리스트 버튼이 표시됨을 확인함.

## 추가 수정: "MRI PICC 가능해?"

- "사용"이라는 말 없이 "MRI PICC 가능해?"라고 물으면 체크리스트가 계속 표시됨.
- 사용 표현에 `가능`, `괜찮`, `안전`, `허용`을 추가함. 관리 질문이 숨겨지지 않도록 시술 표현에 `드레싱`, `교체`를 추가함.
- 숨김 예 추가: "MRI PICC 가능해?", "MRI 찍을 때 PICC 괜찮아?", "CT 조영제 PICC로 가능?", "PICC 있는 환자 MRI 안전해?"
- 표시 유지 예 추가: "PICC 삽입 가능한 시간", "PICC 드레싱 교체 가능해?"
- 주의: 시술 표현 없이 "가능/괜찮/안전"만 붙은 질문은 다른 체크리스트에서도 숨겨짐. 예: "Renal biopsy 가능한 환자?"
- 확인: 규칙 검사 11개 통과, eslint 통과. Docker 3001을 다시 빌드함(새 DB 변경 없음). 가짜 대화 기록으로 연 채팅 화면에서 위 숨김 3개에는 버튼이 없고 "PICC 삽입 준비"·"PICC 드레싱 교체 가능해?"에는 버튼이 표시됨.

## 추가 수정: 드레싱 질문 제외 (사용자 선택)

- 실제 PICC 체크리스트(검사 전·검사 후, 관찰사항의 주기적 소독 한 줄)에는 드레싱 항목이 없음. 드레싱은 이미 넣은 관의 관리라 삽입 체크리스트와 맞지 않음.
- `드레싱`을 사용 표현으로 옮기고, 시술 표현에서 `드레싱`, `교체`를 뺌.
- 이제 "PICC 드레싱 주기", "PICC 드레싱 교체 가능해?"에는 체크리스트를 띄우지 않음. "PICC 삽입 후 드레싱"처럼 시술 표현이 함께 있으면 표시함.
- 확인: 규칙 검사 11개 통과, eslint 통과. Docker 3001 다시 빌드(새 DB 변경 없음) 후 가짜 대화 기록 채팅 화면에서 "MRI PICC 가능해?"·드레싱 질문 2개는 버튼 없음, "PICC 삽입 준비"·"PICC"는 버튼 표시를 확인함.
