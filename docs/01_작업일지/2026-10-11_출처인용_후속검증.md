# 출처 인용 후속 검증

- 다른 창에서 남긴 실제 원문 인용 저장·표시 후속 변경을 검토함. Agent가 근거 ID와 원문 인용을 답변 뒤에 반환하도록 안내를 추가하며, 인용이 해당 원문에 유일하게 존재하는 경우만 저장함. 내부 인용 블록은 직원 답변에서 숨김. 추가 Gemini 호출은 없지만 모델에 보내는 인용 안내 문장은 추가됨.
- PDF 근거는 공백·줄바꿈 차이를 허용하되 애매하거나 없는 위치는 표시하지 않음. 여러 근거와 회전된 페이지를 검사함. 기존 후속 작업의 연한 파란색 표시와 실무지침 문서만 표시하는 규칙을 유지함. 다른 PDF는 원문 조회만 제공함.
- 합성 원문 인용·PDF 왕복·출처 화면 검사 44개 통과함. 별도 네트워크 차단 컨테이너에서 Agent 스트리밍/일반 답변→출처→대화 저장 연결 검사 2개 통과함. 실제 DB 저장은 이 Agent 검사에서 대체함. 외부 모델 목록·가격 조회는 네트워크 차단으로 실패하는 예상 경고가 있었음.
- 같은 작업 코드의 Vite production build 통과함. PC·모바일 실제 브라우저 조작은 도구 연결 실패로 수행하지 않았음. PDF 검사에서 Node 환경 DOMMatrix/Path2D/OffscreenCanvas 경고가 있어 실제 화면 확인은 별도로 필요함.
- 사용자 확인(앱 반영 후): PC에서 실무지침 출처를 열어 인용한 줄만 표시되는지 확인 → 좁은 모바일 화면에서도 출처 열기·첫 근거 이동 확인 → 실무지침이 아닌 PDF는 표시 없이 원문이 열리고 TXT는 PDF 지원 안내가 나오는지 확인함.
- 기존 3001·3002·3003은 재시작·갱신하지 않았으므로 위 최신 변경의 확인 주소로 단정하지 않음. 시험 PDF·계정·DB·preview-storage와 별도 체크박스 CSS, 문서 업데이트용 summarize 변경은 이 기능 커밋에서 제외함. 실제 Gemini 호출·push 없음.
