# 답변 일관성 설정

## 관리자 화면

관리자 설정 → 답변 설정 → 고급 설정에서 확인함. 이 기능은 관리자용이며 직원의 검색 방식·지침 내용·계정은 바꾸지 않음.

- **현재 적용 값**: 선택한 작업 공간에 저장된 답변 표현 다양성(temperature)을 표시함. 이번 로컬 확인값은 0.7이며 자동 변경하지 않음.
- **답변 표현 다양성**: 0~2의 숫자를 입력하고 저장함. 빈칸은 저장하지 않음. 0도 유효한 값이지만 정확성이나 답변 고정을 보장하는 값은 아님.
- **반복 답변 기준값(seed)**: 현재 사용 안 함. `gemini-3.8-flash`의 현재 호환 연결에서 seed 포함 요청은 거절되고 제외한 요청은 성공하여, 실패하는 옵션을 직원 답변에 추가하지 않았음. 다른 모델은 지원 미확인으로 안내함.

Google은 Gemini 3 계열에 temperature 1.0을 권장함. 간호 지침 안내에서도 무조건 0으로 낮추기보다 **1.0을 비교 시험의 기준으로 권장**함. 실제 지침의 정확성은 출처와 근거 일치 여부로 검토해야 하며 온도만으로 보장하지 않음. 기존 0.7은 관리자가 변경하기 전까지 유지함. [Google 공식 설명](https://ai.google.dev/gemini-api/docs/gemini-3#temperature)

기본 Gemini API에 seed가 있다는 것과 SCHAT이 현재 사용하는 호환 연결에서 받아 준다는 것은 다름. 이번 작업에서는 연결 방식 전체를 바꾸지 않았음. [기본 API 설정](https://ai.google.dev/api/generate-content), [호환 연결 안내](https://ai.google.dev/gemini-api/docs/openai)

## 직접 확인할 방법

새 코드로 로컬 Docker를 빌드한 뒤 진행함. 현재 실행 중인 3001에 자동 반영되는 것은 아님.

1. 관리자 로그인 후 답변 설정의 고급 설정을 엶.
2. 현재 값과 seed 사용 안 함·사유가 표시되는지 확인함.
3. 온도 입력을 비우면 저장할 수 없는지 확인함.
4. 테스트 작업 공간에서 원하는 값을 저장하고 새로고침 후 유지되는지 확인함. 확인 후 원래 값으로 되돌릴 수 있음.
5. 작업 공간을 바꾸면 이전 공간의 미저장 값이 따라오지 않는지 확인함.

화면 설정 확인 자체는 Gemini를 호출하지 않음. 질문 전송은 실제 호출 비용·한도를 사용할 수 있음. 이번 개발 확인은 합성 질문 3회만 요청했으며 2회 거절·1회 성공함. 다섯 답변의 일치도를 검증한 결과는 아님.
