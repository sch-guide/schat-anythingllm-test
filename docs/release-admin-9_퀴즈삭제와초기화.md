# 퀴즈 삭제와 문서 교체 뒤 퀴즈

2026-10-12 최종 정리 기준이에요. 이전에 만들었던 **퀴즈 기록 초기화**, **삭제한 퀴즈 되살리기**, **"이전 지침 기준" 배지**는 모두 없앴어요.

## 삭제는 진짜 삭제

| 작업 | 지워지는 것 | 그대로인 것 |
| --- | --- | --- |
| 한 문제 [삭제] | 그 문제, 그 문제에 대한 직원 풀이 기록·오답노트 | 퀴즈가 아닌 모든 자료(대화 기록, 문서, 동의어, 계정, 👎 기록 등) |
| [이전 문서 퀴즈 모두 삭제(N개)] | 목록의 이전 문서 문제 전부와 그 풀이 기록·오답노트 | 위와 같음 |

- 삭제 전 확인 창에 지울 개수를 먼저 보여 줘요. 예: "이 문제와 직원 풀이 기록 3건을 지워요. 되돌릴 수 없어요."
- 확인 창을 연 뒤 기록 수가 바뀌면 지우지 않고 다시 확인하라고 안내해요.
- 되살리기와 별도 보관은 없어요. 지운 문제가 들어 있던 직원 풀이 회차는 남은 문제만으로 점수를 다시 맞춰요. 남은 문제가 없으면 그 회차 기록도 지워져요.

## 이전 문서 퀴즈는 직원 화면에서 바로 숨김

- 퀴즈의 문서가 "이전 문서"가 되면 관리자가 지우기 전이라도 직원 화면의 문제 목록, 오답노트, 풀이 기록 목록에서 보이지 않아요. 배지는 쓰지 않아요.
- 직원 점수와 정답률은 지금 보이는 문제만으로 다시 계산해요.
- 관리자 통계도 이전 문서 문제는 빼고 계산하고, 통계 화면에 "기준: 이전 문서 퀴즈의 풀이는 빼고 계산합니다"라고 작게 적어요.
- 기록 자체는 관리자가 [삭제]를 누를 때만 지워져요.

## 같은 이름 문서를 새 버전으로 바꾸면

퀴즈를 만들 때 저장해 둔 **근거 문장**(`source_excerpt`)을 새 버전 문서에서 찾아 비교해요. AI 없이 글자로만 비교해요.

- 쪽 번호가 아니라 문장 내용으로 찾아요. 쪽이 바뀌면 새 쪽 번호로 고쳐요.
- 띄어쓰기, 줄바꿈, 글머리 기호(•, -, ①, 가. 등) 차이는 같은 것으로 봐요.
- 숫자나 단위가 하나라도 다르면 "바뀜"이에요. 예: 100 mL → 120 mL, 38℃ → 37.5℃, mL/kg → mL, "5 mg"과 "25 mg"도 다르게 봐요.
- 낱말이 바뀐 경우와 목록 번호(1. → 2.)가 바뀐 경우도 안전하게 "바뀜/못 찾음"으로 봐요.

| 결과 | 처리 |
| --- | --- |
| 그대로 | 새 버전에 자동 연결해서 계속 써요. 직원 기록도 그대로 이어져요. |
| 바뀜 또는 못 찾음 | "이전 문서"로 남아요. 직원 화면에서 사라지고, 관리자가 [삭제]할 수 있어요. |

문서 교체가 끝나면 관리자 화면에 "퀴즈 N개 중 계속 사용 N · 이전 문서 N"이 보여요. 체크리스트와 과거 답변 출처는 예전처럼 자동으로 옮기지 않아요.

## 확인 결과 (2026-10-12)

- 가짜 자료 검사: 숫자만 바꾼 문장(100→120 mL, 38→37.5℃), 단위만 바꾼 문장, 띄어쓰기·글머리 기호만 다른 문장, 쪽 경계에 걸친 문장을 각각 확인했어요.
- 빈 SQLite에 실제 DB 구조를 적용한 일회용 환경에서 연결·진짜 삭제·점수 재계산을 확인했고, 퀴즈가 아닌 모든 표가 전후 같았어요.
- 3001의 실제 퀴즈 15개는 읽기만 해서 현재 문서와 비교했고 15개 모두 "그대로", 같은 쪽으로 나왔어요. 3001에는 이미 "이전 문서"가 된 퀴즈가 없어서 되살릴 대상도 없어요.
- PC 1440px·휴대폰 390px에서 삭제 확인 창, 취소, 통계 문구, 직원 화면을 확인했어요. 문서 올리기는 원래 PC 전용이라 교체 결과 문구는 PC에서 확인했어요.
- DB 구조 변경은 없어요. 기존 칸(`document_id`, `source_page`, `source_excerpt`)만 써요.
