# 퀴즈 삭제와 기록 초기화

## 두 버튼의 차이

| 작업 | 없어지는 것 | 남는 것 |
| --- | --- | --- |
| 일반 삭제 | 관리자 목록과 새 퀴즈 출제 대상에서 문제를 제외해요. | 과거 풀이, 점수, 오답노트와 그 기록에 연결된 문제를 보존해요. |
| 퀴즈 기록 초기화 | 모든 직원의 풀이·점수·오답노트, 삭제된 문제와 이전 문서 문제를 완전히 지워요. | 현재 문서의 문제, 대화, 지침, 동의어, 계정, 답변 평가를 남겨요. |

일반 삭제는 기록 초기화가 아니에요. 이전 문서 문제는 직원에게 새로 출제하지 않아요. 현재 문서의 문제는 아직 공개하지 않았거나 사용을 멈춘 문제도 초기화에서 보존하는 설계예요.

## 초기화 전 확인

- 관리자가 직접 버튼을 누르고 `초기화`를 입력할 때만 실행하는 기능이에요. 시작할 때나 정해진 시간에 자동 실행하지 않아요.
- 확인 창의 직원 수와 풀이 기록 수를 먼저 확인해요. 초기화한 기록은 앱에서 되돌릴 수 없어요.
- 별도 엑셀 파일로 기록을 내보내지 않아요. 이미 만들어진 스냅샷·백업은 손대지 않고 기존 보관 기간을 따라요.

## 구현·시험 상태

2026-10-12 일반 삭제는 428088bd로 구현해 3001에 반영했어요. 실제 SQLite의 가짜 문제로 답변·풀이·오답노트와 관련 없는 자료 보존을 확인했어요. PC·휴대폰에서 합성 응답으로 필터와 삭제 확인창을 눌러 확인했어요. 초기화 기능은 아직 구현 전이며 실제 직원 기록을 초기화하는 시험은 하지 않아요.

3001에서는 **관리자 → 퀴즈 관리 → 전체 / 사용 중 / 이전 문서** 순서로 확인해요. 삭제 확인창은 취소할 수 있어요. 휴대폰에서는 표를 좌우로 밀어 작업 버튼을 볼 수 있어요.
